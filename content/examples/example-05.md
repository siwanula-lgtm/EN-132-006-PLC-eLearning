## ตัวอย่างโจทย์และวิธีทำ

![Infographic: เครือข่าย PLC – HMI – คอมพิวเตอร์](/images/infographic/u05_network.png)

### ตัวอย่างที่ 1 การตั้ง IP Address ให้สื่อสารกันได้

**โจทย์** PLC FX5U มี IP 192.168.3.250 และ HMI มี IP 192.168.3.18 ใช้ Subnet mask 255.255.255.0 ทั้งคู่ ถ้าคอมพิวเตอร์ตั้ง IP เป็น 192.168.1.10 จะเขียนโปรแกรมผ่าน Ethernet ได้หรือไม่ และควรแก้อย่างไร

<details><summary>วิธีทำและเฉลย</summary>

- Subnet mask 255.255.255.0 หมายความว่า 3 ส่วนแรกของ IP ต้องเหมือนกันจึงจะอยู่เครือข่ายเดียวกัน
- คอมพิวเตอร์อยู่วง 192.168.**1**.x แต่ PLC อยู่วง 192.168.**3**.x **จึงสื่อสารกันไม่ได้**
- แก้โดยตั้ง IP ของคอมพิวเตอร์เป็นเลขในวง 192.168.3.x ที่ไม่ซ้ำกับอุปกรณ์อื่น เช่น **192.168.3.10**

</details>

### ตัวอย่างที่ 2 วางแผนจับคู่ Device ระหว่าง HMI และ PLC

**โจทย์** หน้าจอ HMI ต้องมีปุ่ม Start และ Stop หลอดแสดงสถานะมอเตอร์ และช่องแสดงความเร็ว (rpm) จงกำหนด Device ของ PLC ให้แต่ละวัตถุบนหน้าจอ

<details><summary>วิธีทำและเฉลย</summary>

| วัตถุบน HMI | ชนิด | Device ใน PLC | เหตุผล |
|---|---|---|---|
| ปุ่ม Start | Bit Switch (Momentary) | M0 | ใช้รีเลย์ภายใน M แทน X เพราะ HMI เขียนค่า X ซึ่งเป็นอินพุตจริงไม่ได้ |
| ปุ่ม Stop | Bit Switch (Momentary) | M1 | ใช้ M0 และ M1 ต่อขนานกับปุ่มจริงในโปรแกรม Ladder |
| หลอดมอเตอร์ | Bit Lamp | Y0 | อ่านสถานะเอาต์พุตจริงโดยตรง |
| ความเร็ว | Numerical Display | D100 | เก็บค่าตัวเลขขนาด 16 บิต |

</details>
