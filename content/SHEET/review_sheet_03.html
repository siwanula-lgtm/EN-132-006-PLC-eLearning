⚙️ Review Sheet หน่วยที่ 3 — การใช้งาน PLC
EN-132-006 Programmable Logic Controller (PLC) · Using the PLC with GX Works3
สัปดาห์ที่ 3 · ท 2 / ป 3 ชม. · CLO1
ใบงานปฏิบัติ 1 ใบงาน
📌 1. สาระสำคัญ

การใช้งาน PLC ในระบบอุตสาหกรรมจำเป็นต้องอาศัยโปรแกรม GX Works3 ของ Mitsubishi Electric ซึ่งเป็นซอฟต์แวร์ที่ใช้เขียนและจัดการโปรแกรมควบคุม PLC ตระกูล MELSEC iQ-F และ iQ-R การเรียนรู้ในหน่วยนี้ครอบคลุมตั้งแต่การติดตั้งโปรแกรม การทำความเข้าใจส่วนประกอบต่าง ๆ ของโปรแกรม การเชื่อมต่อ PLC กับคอมพิวเตอร์ผ่าน Ethernet การเขียนและอ่านข้อมูลจาก PLC การจำลองการทำงานโดยไม่ต้องใช้ PLC จริง และการตรวจสอบการทำงานแบบเรียลไทม์ ซึ่งทักษะเหล่านี้เป็นพื้นฐานสำคัญสำหรับการประยุกต์ใช้ PLC ในงานอุตสาหกรรมจริง จุดประสงค์การเรียน …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 3.1 เข้าใจส่วนประกอบและขั้นตอนการติดตั้งโปรแกรม GX Works3 ได้
  • 3.2 เข้าใจการเชื่อมต่อ การเขียน-อ่านข้อมูล และการตรวจสอบแบบ เรียลไทม์ของ PLC ได้
  • 3.3 ปฏิบัติการเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3 ได้ถูกต้อง
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 3.1 ขั้นตอนการติดตั้งและระบุส่วนประกอบของโปรแกรม GX Works3
  • 3.2 งานเชื่อมต่อ การเขียน-อ่านข้อมูล และการตรวจสอบแบบเรียลไทม์ของ PLC
  • 3.3 งานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3
📝 4. บทสรุป

โปรแกรม GX Works3 ใช้สำหรับเขียน ตรวจสอบ และถ่ายโอนโปรแกรมของ PLC ตระกูล MELSEC iQ-F การทำงานเริ่มจากติดตั้งโปรแกรม สร้างโปรเจกต์ เลือกรุ่น CPU ตั้งค่าการเชื่อมต่อผ่าน Ethernet แล้วจึงเขียนโปรแกรม (Write) และอ่านโปรแกรม (Read) จาก PLC นอกจากนี้ยังสามารถใช้ Simulation ทดสอบโปรแกรมโดยไม่ต้องต่อ PLC จริง และใช้ Monitor ตรวจสอบสถานะของอุปกรณ์แบบเรียลไทม์ เพื่อค้นหาข้อผิดพลาดได้อย่างรวดเร็ว

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงอธิบายขั้นตอนการสร้างโปรเจกต์ใหม่ในโปรแกรม GX Works3
  • จงอธิบายขั้นตอนการเชื่อมต่อ PLC กับคอมพิวเตอร์ผ่านพอร์ต Ethernet
  • จงเปรียบเทียบความแตกต่างระหว่างการเขียนข้อมูลลง PLC (Write) และการอ่านข้อมูลจาก PLC (Read)
  • จงอธิบายประโยชน์ของการจำลองการทำงานของ PLC ด้วยโปรแกรม GX Simulator3
  • จงอธิบายการใช้งานโหมด Monitor ในการตรวจสอบและติดตามการทำงานของระบบ PLC แบบเรียลไทม์
  • จงอธิบายขั้นตอนและข้อกำหนดเบื้องต้น (System Requirement) ในการติดตั้งโปรแกรม GX Works3 ลงในเครื่องคอมพิวเตอร์
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • เตรียมความพร้อมและปฏิบัติตามข้อควรระวังด้านความปลอดภัย
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 3

งานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3
