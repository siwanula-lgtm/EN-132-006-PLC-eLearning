📌 1. สาระสำคัญ

โปรแกรมเมเบิลลอจิกคอนโทรลเลอร์ (PLC) เป็นอุปกรณ์ควบคุมเชิงดิจิทัลที่ออกแบบสําหรับงาน อุตสาหกรรม ประกอบด้วยส่วนสําคัญ ได้แก่ หน่วยประมวลผลกลาง (CPU) หน่วยความจํา ส่วนอินพุต ส่วน เอาต์พุต และระบบจ่ายไฟ PLC มีความแตกต่างจากการควบคุมด้วยรีเลย์แบบเดิม ตรงที่สามารถปรับเปลี่ยน การทํางานได้โดยการเขียนโปรแกรม มีความทนทานต่อสภาพแวดล้อมอุตสาหกรรม และสามารถเชื่อมต่อ กับระบบเครือข่าย HMI และ SCADAได้ ลักษณะงานที่เหมาะสมสําหรับการใช้ PLC คืองานที่ต้องการ ควบคุมแบบลําดับขั้นตอนและกระบวนการผลิตต่อเนื่อง

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 1.1 เข้าใจความหมายและพัฒนาการของ PLC ได้
  • 1.2 เข้าใจโครงสร้างภายในและข้อมูลจำเพาะของ PLC ได้
  • 1.3 เข้าใจการเชื่อมต่อวงจรอินพุตและเอาต์พุตของ PLC ได้
  • 1.4 เข้าใจภาษาโปรแกรม วงจรไฟฟ้า และอุปกรณ์ที่เกี่ยวข้องกับ PLC ได้
  • 1.5 ปฏิบัติการสำรวจและต่อวงจรไฟฟ้าของ PLC ได้ถูกต้องและปลอดภัย
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 1.1 ความหมายและพัฒนาการของ PLC
  • 1.2 โครงสร้างภายในและการอ่านข้อมูลจำเพาะของ PLC
  • 1.3 การเชื่อมต่อวงจรอินพุตและเอาต์พุตของ PLC
  • 1.4 ภาษาโปรแกรมและอธิบายวงจรไฟฟ้ากับอุปกรณ์ที่เกี่ยวข้องกับ PLC
  • 1.5 การสำรวจและต่อวงจรไฟฟ้าของ PLC
📝 4. บทสรุป

PLC เป็นอุปกรณ์ควบคุมดิจิทัลสำหรับงานอุตสาหกรรม ประกอบด้วย CPU หน่วยความจำ อินพุต เอาต์พุต และแหล่งจ่ายไฟ สามารถปรับการทำงานได้ด้วยการเขียนโปรแกรม ต่างจากรีเลย์แบบเดิม นิยมใช้ภาษา Ladder Diagram (LD) ตามมาตรฐาน IEC 61131-3 การเลือกใช้งานควรพิจารณาจำนวน I/O ชนิดโหลด ซอฟต์แวร์ และสภาพแวดล้อมใช้งาน

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงบอกความหมายของโปรแกรมเมเบิลลอจิกคอนโทรลเลอร์ (PLC)
  • จงอธิบายโครงสร้างภายในของ PLC และหน้าที่ของแต่ละส่วนประกอบ
  • จงเปรียบเทียบความแตกต่างระหว่าง Sink Type และ Source Type ในการเชื่อมต่ออินพุต ของ PLC
  • จงบอกประเภทของเอาต์พุตของ PLC พร้อมอธิบายข้อดีและข้อจํากัดของแต่ละประเภท
  • จงอธิบายประเภทของ PLC แบบคอมแพกต์ (Compact PLC) และแบบโมดูลาร์ (Modular PLC) …
  • จงยกตัวอย่างผู้ผลิต (Brand) PLC ที่นิยมใช้งานในภาคอุตสาหกรรมอย่างน้อย 3 ยี่ห้อ …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • รับชุดฝึก ตรวจความพร้อมของอุปกรณ์ และอ่านข้อควรระวังด้านความปลอดภัยร่วมกับครูผู้สอน
  • เตรียมความพร้อมและปฏิบัติตามข้อควรระวังด้านความปลอดภัย
