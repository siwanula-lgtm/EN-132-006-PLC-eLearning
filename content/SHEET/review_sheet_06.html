EN-132-006 Programmable Logic Controller (PLC) · Basic HMI Operation

ใบงานปฏิบัติที่ 6
📌 1. สาระสำคัญ

Human Machine Interface (HMI) เป็นตัวกลางที่เชื่อมต่อระหว่างผู้ปฏิบัติงานกับเครื่องจักรในระบบควบคุมอัตโนมัติ โดยใช้ซอฟต์แวร์ GT Designer3 ของ Mitsubishi ในการออกแบบหน้าจอ ประกอบด้วยวัตถุหลัก ได้แก่ Bit Switch สำหรับสั่งงาน Bit Lamp สำหรับแสดงสถานะ Numerical Display สำหรับแสดงค่าตัวเลข และ Numerical Input สำหรับรับค่าจากผู้ใช้ ซึ่งทั้งหมดสื่อสารกับ PLC ผ่านหลักการ Read/Write ในรูปแบบ Master–Slave Communication ช่วยเพิ่มประสิทธิภาพ ความปลอดภัย และความยืดหยุ่นของระบบอุตสาหกรรม จุดประสงค์การเรียน (จุดประสงค์ทั่วไป) …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • อธิบายหลักการ Read/Write ข้อมูลระหว่าง PLC และ HMI
  • อธิบายหลักการและใช้งาน Bit Switch บนหน้าจอ HMI
  • อธิบายการแสดงสถานะอุปกรณ์ผ่าน Bit Lamp
  • อธิบายการแสดงค่าตัวเลขจาก PLC ด้วย Numerical Display
  • อธิบายการรับค่าตัวเลขจากผู้ใช้ผ่าน Numerical Input สู่ PLC

📝 4. บทสรุป

การออกแบบหน้าจอ HMI พื้นฐานประกอบด้วย Bit Switch สำหรับสั่งงานบิต Bit Lamp สำหรับแสดงสถานะ Numerical Display สำหรับแสดงค่าตัวเลข และ Numerical Input สำหรับป้อนค่า โดยอ้างอิงอุปกรณ์ภายใน PLC ตามที่กำหนดใน Read/Write การสร้างหน้าจอหลายหน้าและการสลับหน้าจอช่วยจัดระเบียบการใช้งาน หน้าจอที่ดีต้องอ่านง่าย สื่อสถานะชัดเจน และคำนึงถึงความปลอดภัยของผู้ใช้งาน

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายหลักการทำงานของการ Read/Write ระหว่าง HMI และ PLC ว่ามีความสำคัญอย่างไรต่อระบบควบคุมอัตโนมัติ …
  • จงอธิบายลักษณะการสื่อสารแบบ Master–Slave Communication ระหว่าง HMI กับ PLC …
  • อธิบายประเภทของการเชื่อมต่อระหว่าง HMI และ PLC ได้แก่ RS-232, RS-485 และ Ethernet …
  • อธิบายขั้นตอนการออกแบบหน้าจอ Read/Write HMI ในโปรแกรม GT Designer3 …
  • อธิบายความหมายและหลักการทำงานของ Bit Switch พร้อมยกตัวอย่างการใช้งานในงานควบคุม เช่น …
  • จากตารางรูปแบบการทำงานของ Bit Switch (Momentary, Alternate, Set/Reset) …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ถอดปลั๊กแหล่งจ่ายไฟหรือกดสวิตช์ฉุกเฉินก่อนต่อ/แก้ไขสายไฟทุกครั้ง และจ่ายไฟได้เมื่อครูผู้สอนตรวจสอบแล้วเท่านั้น
  • ตรวจสอบแรงดันและขั้วของแหล่งจ่ายให้ตรงกับที่ระบุในคู่มือชุดฝึกก่อนจ่ายไฟ ห้ามต่อสายขณะมีไฟ
  • สวมรองเท้าหุ้มส้น ไม่สวมเครื่องประดับโลหะ และไม่วางของเหลวบนโต๊ะปฏิบัติงาน
  • ตรวจสอบอุปกรณ์เอาต์พุตที่ต่ออยู่ก่อนกดปุ่มบนหน้าจอ เพราะการกด Bit Switch สั่งงานเอาต์พุตจริงทันที
