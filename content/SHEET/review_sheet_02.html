📌 1. สาระสำคัญ

ระบบอินพุตและเอาต์พุตของ PLC ประกอบด้วยอุปกรณ์หลากหลายชนิดที่ทำหน้าที่รับสัญญาณจากสภาพแวดล้อมและแสดงผลการทำงาน โดยฝั่งอินพุต ได้แก่ Push Button, Proximity Sensor และ Encoder ส่วนฝั่งเอาต์พุต ได้แก่ Pilot Lamp, Tower Lamp, Relay และ Motor ซึ่งการเข้าใจหลักการทำงานและการเชื่อมต่ออุปกรณ์เหล่านี้อย่างถูกต้องถือเป็นพื้นฐานสำคัญของการออกแบบและบำรุงรักษาระบบควบคุมอัตโนมัติในงานอุตสาหกรรม โดยมีจุดประสงค์การเรียนรู้ (จุดประสงค์ทั่วไป) และจุดประสงค์เชิงพฤติกรรมดังนี้

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • บอกลักษณะและหน้าที่ของ Push Button และ Emergency Stop ที่ใช้เป็นอินพุตของ PLC
  • อธิบายหลักการทำงานและประเภทของ Proximity Sensor และ Photoelectric Sensor
  • อธิบายหลักการทำงานของ Encoder ในระบบควบคุมตำแหน่งและความเร็ว
  • ระบุหน้าที่และความหมายของสีใน Pilot Lamp และ Tower Lamp
  • อธิบายโครงสร้างและหลักการทำงานของ Relay ในวงจรควบคุม
  • จำแนกประเภทของมอเตอร์และเลือกใช้งานในระบบอัตโนมัติได้

📝 4. บทสรุป

อุปกรณ์อินพุตทำหน้าที่ส่งสัญญาณจากภายนอกเข้าสู่ PLC เช่น Push Button, Proximity Sensor และ Encoder ส่วนอุปกรณ์เอาต์พุตรับคำสั่งจาก PLC เช่น Pilot Lamp, Tower Lamp, Relay และมอเตอร์ การเลือกและต่ออุปกรณ์ต้องให้สอดคล้องกับชนิดของอินพุตและเอาต์พุตของ PLC รวมถึงแรงดันและกระแสของโหลด การใช้รีเลย์ช่วยแยกวงจรควบคุมออกจากวงจรกำลัง ทำให้ควบคุมโหลดที่มีกระแสสูงได้อย่างปลอดภัย

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายหลักการทำงานของ Push Button แบบ NO (Normally Open) และ NC (Normally Closed) …
  • เปรียบเทียบความแตกต่างระหว่าง Push Button ทั่วไปกับ Emergency Stop Switch (E-Stop) …
  • อธิบายหลักการทำงานของ Proximity Sensor ทั้ง 3 ประเภท คือ Inductive, Capacitive และ Photoelectric …
  • ใน Proximity Sensor แบบ 3 สาย มีการต่อสัญญาณแบบ NPN และ PNP จงอธิบายความแตกต่างและการเลือกใช้งานให้เหมาะสมกับ …
  • อธิบายหน้าที่และการทำงานของ Encoder ในระบบควบคุม โดยระบุหน้าที่ของสัญญาณ Channel A, B และ Z …
  • จงอธิบายความหมายของสีต่าง ๆ ใน Pilot Lamp และ Tower Lamp ว่ามีความหมายอย่างไรในเชิงสัญญาณควบคุม …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ถอดปลั๊กแหล่งจ่ายไฟหรือกดสวิตช์ฉุกเฉินก่อนต่อ/แก้ไขสายไฟทุกครั้ง และจ่ายไฟได้เมื่อครูผู้สอนตรวจสอบแล้วเท่านั้น
  • ตรวจสอบแรงดันและขั้วของแหล่งจ่ายให้ตรงกับที่ระบุในคู่มือชุดฝึกก่อนจ่ายไฟ ห้ามต่อสายขณะมีไฟ
  • สวมรองเท้าหุ้มส้น ไม่สวมเครื่องประดับโลหะ และไม่วางของเหลวบนโต๊ะปฏิบัติงาน
  • สาย Proximity Sensor แบบ 3 สายมีสีน้ำตาลเป็นขั้วบวก สีน้ำเงินเป็นขั้วลบ และสีดำเป็นสัญญาณ ต้องต่อให้ถูกขั้วก่อนจ่ายไฟ
