⚙️ Review Sheet หน่วยที่ 7 — การสื่อสารระหว่าง PLC กับอุปกรณ์อื่น ๆ
EN-132-006 Programmable Logic Controller (PLC) · Communication between PLC and Other Devices
สัปดาห์ที่ 9 · ท 2 / ป 3 ชม. · CLO2
ใบงานปฏิบัติ 1 ใบงาน
📌 1. สาระสำคัญ

ในระบบอัตโนมัติ การสื่อสารข้อมูลของ PLC มีบทบาทสำคัญในการเชื่อมโยงระหว่างหน่วยควบคุมกับอุปกรณ์อื่นในกระบวนการผลิต การสื่อสารแบบอนุกรม RS-232 เหมาะกับการเชื่อมต่อแบบ Point-to-Point ระยะสั้นไม่เกิน 15 เมตร ส่วน RS-485 รองรับ Multi-Drop Bus สูงสุด 32 อุปกรณ์ ระยะไกลถึง 1,200 เมตร Protocol Modbus เป็นมาตรฐานเปิด (Open Protocol) ใช้หลักการ Master–Slave รองรับทั้ง Modbus RTU ผ่าน RS-485 และ Modbus TCP ผ่าน Ethernet และ V-net IoT เชื่อมต่อ PLC กับ Cloud เพื่อตรวจสอบและวิเคราะห์ข้อมูลแบบเรียลไทม์ …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 7.1 เข้าใจหลักการสื่อสารแบบอนุกรมและความแตกต่างของ RS-232 กับ RS-485 ได้
  • 7.2 เข้าใจหลักการของโปรโตคอล Modbus และระบบ V-net IoT ได้
  • 7.3 ปฏิบัติการสื่อสารข้อมูลระหว่าง PLC กับอุปกรณ์ภายนอกได้ ถูกต้อง
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 7.1 หลักการสื่อสารแบบอนุกรมและความแตกต่างของ RS-232 กับ RS-485
  • 7.2 โปรโตคอล Modbus และระบบ V-net IoT
  • 7.3 สื่อสารข้อมูลระหว่าง PLC กับอุปกรณ์ภายนอก
📝 4. บทสรุป

การสื่อสารระหว่าง PLC กับอุปกรณ์อื่นทำได้หลายรูปแบบ เช่น Ethernet, RS-232 และ RS-485 โดย RS-485 รองรับการเชื่อมต่อหลายอุปกรณ์และระยะทางไกลกว่า RS-232 โปรโตคอล MODBUS ใช้แลกเปลี่ยนข้อมูลระหว่าง Master และ Slave ผ่านรีจิสเตอร์ ส่วน V-net IoT ช่วยนำข้อมูลของ PLC ขึ้นสู่ระบบ Cloud เพื่อเฝ้าสังเกตผ่านอุปกรณ์เคลื่อนที่ ผู้ใช้ต้องตั้งค่าพารามิเตอร์ให้ตรงกัน และคำนึงถึงความปลอดภัยของข้อมูล

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายความสำคัญของการสื่อสารข้อมูลในระบบอัตโนมัติ (Automation System) และบทบาทของ PLC …
  • อธิบายหลักการทำงานของการสื่อสารแบบอนุกรม (Serial Communication) พร้อมเปรียบเทียบลักษณะการเชื่อมต่อของ RS-232 …
  • จากตารางการเปรียบเทียบ RS-232 และ RS-485 จงอธิบายข้อดีและข้อจำกัดของแต่ละระบบ …
  • ให้นักศึกษาวาดแผนผังหรืออธิบายลำดับการเชื่อมต่อของ PLC กับอุปกรณ์ภายนอก ผ่านพอร์ต RS-232 และ RS-485 …
  • อธิบายหลักการสื่อสารของ Modbus Protocol ในรูปแบบ RTU และ TCP ว่ามีความแตกต่างกันอย่างไร …
  • อธิบายโครงสร้างของเฟรมข้อมูล (Data Frame) ในระบบ Modbus พร้อมระบุหน้าที่ของส่วนประกอบหลัก เช่น Address, …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • การนำข้อมูล PLC ขึ้น Cloud มีประโยชน์และความเสี่ยงด้านความปลอดภัยของข้อมูลอย่างไร
  • เตรียมความพร้อมและปฏิบัติตามข้อควรระวังด้านความปลอดภัย
