EN-132-006 Programmable Logic Controller (PLC) · PLC Applications for Controlling Devices
สัปดาห์ที่ 10–13 · ท 8 / ป 12 ชม. · CLO1
ใบงานปฏิบัติที่ 8
📌 1. สาระสำคัญ

การประยุกต์ใช้ PLC ควบคุมอุปกรณ์อื่น ๆ เป็นพื้นฐานสำคัญของระบบอัตโนมัติทางอุตสาหกรรม โดยประกอบด้วยอุปกรณ์ตรวจจับ (Sensors) เช่น Inductive, Capacitive, Photo Proximity Sensor, Fiber Optic Sensor และ Encoder ที่ทำหน้าที่ส่งสัญญาณให้ PLC ประมวลผล และอุปกรณ์ขับเคลื่อน (Actuators) เช่น Tower Lamp, Relay, DC Motor, Stepper Motor, Servo Motor และ Solenoid Valve ที่ทำหน้าที่แปลงสัญญาณเป็นการกระทำจริง การเข้าใจหลักการทำงานและการต่อใช้งานร่วมกับ PLC ถือเป็นทักษะสำคัญของงาน Mechatronics จุดประสงค์การเรียน (จุดประสงค์ทั่วไป) …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • อธิบายหลักการทำงานของเซนเซอร์ประเภทต่าง ๆ ที่ใช้ร่วมกับ PLC
  • อธิบายหลักการทำงานและการต่อใช้งาน Inductive, Capacitive, Photo และ Fiber Optic Sensor
  • อธิบายหลักการทำงานของ Encoder และการประยุกต์ใช้วัดตำแหน่งและความเร็ว
  • อธิบายการควบคุม Tower Lamp, Relay, DC Motor, Stepper Motor และ Servo Motor ด้วย PLC
  • อธิบายหลักการทำงานและการควบคุม Solenoid Valve ในระบบนิวเมติกส์ด้วย PLC

📝 4. บทสรุป

PLC สามารถควบคุมอุปกรณ์อื่นได้หลากหลาย ทั้งเซนเซอร์ตรวจจับชนิดต่าง ๆ Encoder Tower Lamp Relay และมอเตอร์ชนิด DC, Stepper และ Servo รวมถึง Solenoid Valve การเลือกอุปกรณ์และวิธีต่อต้องสอดคล้องกับชนิดของอินพุตและเอาต์พุตของ PLC การควบคุมตำแหน่งและความเร็วของมอเตอร์ใช้คำสั่งเฉพาะ เช่น DDRVI และ DDRVA และการใช้ Inverter ช่วยควบคุมความเร็วของมอเตอร์ไฟฟ้ากระแสสลับได้อย่างมีประสิทธิภาพ

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายหลักการทำงานของ Inductive Proximity Sensor …
  • เปรียบเทียบความแตกต่างระหว่าง Inductive Proximity Sensor และ Capacitive Proximity Sensor …
  • อธิบายหลักการทำงานของ Photoelectric Sensor และอธิบายลักษณะของการติดตั้งแบบ Through-beam, Retro-reflective และ …
  • อธิบายการทำงานของ Fiber Optic Sensor …
  • อธิบายหลักการทำงานของ Encoder และยกตัวอย่างการประยุกต์ใช้ Encoder ในระบบควบคุมการเคลื่อนไหว เช่น …
  • อธิบายหน้าที่ของ Tower Lamp ในระบบอัตโนมัติ และอธิบายความหมายของแต่ละสี (แดง เหลือง เขียว) …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ถอดปลั๊กแหล่งจ่ายไฟหรือกดสวิตช์ฉุกเฉินก่อนต่อ/แก้ไขสายไฟทุกครั้ง และจ่ายไฟได้เมื่อครูผู้สอนตรวจสอบแล้วเท่านั้น
  • ตรวจสอบแรงดันและขั้วของแหล่งจ่ายให้ตรงกับที่ระบุในคู่มือชุดฝึกก่อนจ่ายไฟ ห้ามต่อสายขณะมีไฟ
  • สวมรองเท้าหุ้มส้น ไม่สวมเครื่องประดับโลหะ และไม่วางของเหลวบนโต๊ะปฏิบัติงาน
  • ตรวจสอบว่าไม่มีสิ่งกีดขวางรอบแกนมอเตอร์ก่อนสั่งงาน และอยู่ห่างจากส่วนที่หมุน
  • ทดสอบด้วยความเร็วต่ำก่อนเสมอ และให้สวิตช์ฉุกเฉินอยู่ในตำแหน่งที่เอื้อมถึง
