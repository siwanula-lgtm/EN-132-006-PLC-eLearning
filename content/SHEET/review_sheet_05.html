⚙️ Review Sheet หน่วยที่ 5 — บทนำเกี่ยวกับ HMI (Human Machine Interface)
EN-132-006 Programmable Logic Controller (PLC) · Introduction to HMI
สัปดาห์ที่ 6 · ท 2 / ป 3 ชม. · CLO2
ใบงานปฏิบัติ 1 ใบงาน
📌 1. สาระสำคัญ

Human Machine Interface (HMI) คืออุปกรณ์ที่ทำหน้าที่เป็นสื่อกลางระหว่างผู้ใช้งานกับเครื่องจักรหรือระบบอัตโนมัติ เพื่อให้ผู้ควบคุมสามารถตรวจสอบสถานะและสั่งงานระบบได้อย่างสะดวก โดยทั่วไป HMI จะทำงานร่วมกับ PLC เพื่อแสดงผลข้อมูลจากระบบในรูปแบบกราฟิก เช่น ปุ่มกดเสมือน หรือไฟแสดงสถานะ ประกอบด้วยส่วนสำคัญ ได้แก่ จอแสดงผล หน่วยประมวลผล หน่วยความจำ และพอร์ตสื่อสาร ซอฟต์แวร์ GT Designer3 ใช้สำหรับออกแบบและจัดการหน้าจอของ HMI ตระกูล GOT Series ของ Mitsubishi Electric การเชื่อมต่อ PLC กับ HMI สามารถทำได้ผ่านพอร์ต RS-232, …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 5.1 เข้าใจหลักการของ HMI และข้อดีข้อเสียของ HMI ได้
  • 5.2 เข้าใจส่วนประกอบของโปรแกรม GT Designer3 และวิธีการเชื่อมต่อ HMI กับ PLC ได้
  • 5.3 ปฏิบัติเชื่อมต่อ HMI กับ PLC และใช้งานโปรแกรม GT Designer3 ได้ถูกต้อง
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 5.1 หลักการของ HMI และเปรียบเทียบข้อดีข้อเสียของ HMI
  • 5.2 ส่วนประกอบของโปรแกรม GT Designer3 และการเชื่อมต่อ HMI กับ PLC
  • 5.3 การเชื่อมต่อ HMI กับ PLC และใช้งานโปรแกรม GT Designer3
📝 4. บทสรุป

HMI (Human Machine Interface) เป็นอุปกรณ์แสดงผลและรับคำสั่งจากผู้ปฏิบัติงานผ่านหน้าจอสัมผัส ช่วยให้ควบคุมและเฝ้าสังเกตระบบได้สะดวกกว่าสวิตช์และหลอดไฟแบบเดิม แต่มีข้อจำกัดด้านต้นทุนและการบำรุงรักษา การใช้งานเริ่มจากเลือกรุ่น HMI ติดตั้งโปรแกรม GT Designer3 กำหนด Controller Setting ตั้งค่า IP Address และเชื่อมต่อกับ PLC ผ่านพอร์ตสื่อสาร จากนั้นจึงโอนถ่ายโปรเจกต์เข้าสู่ HMI

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายความหมายของ HMI และบทบาทของ HMI …
  • ยกตัวอย่างการใช้งาน HMI ร่วมกับ PLC ในงานอุตสาหกรรมจริง …
  • วิเคราะห์ข้อดีและข้อจำกัดของการใช้ HMI เมื่อเทียบกับการควบคุมเครื่องจักรแบบใช้สวิตช์จริง (Manual Control)
  • จากบทเรียน 'ส่วนประกอบ HMI' ให้อธิบายหน้าที่ของ จอแสดงผล (Display Unit), หน่วยประมวลผล (CPU Unit) และ …
  • อธิบายหลักการทำงานของ HMI ในกระบวนการ 'รับข้อมูล - ประมวลผล - แสดงผล' …
  • อธิบายขั้นตอนการติดตั้งและอัปเดตโปรแกรม GT Designer3 ให้ถูกต้อง …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • เตรียมความพร้อมและปฏิบัติตามข้อควรระวังด้านความปลอดภัย
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 5
