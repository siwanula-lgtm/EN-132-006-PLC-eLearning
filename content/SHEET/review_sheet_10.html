EN-132-006 Programmable Logic Controller (PLC) · PLC Troubleshooting and Maintenance
สัปดาห์ที่ 16 · ท 2 / ป 3 ชม. · CLO3
ใบงานปฏิบัติที่ 10
📌 1. สาระสำคัญ

การตรวจสอบและบำรุงรักษา PLC เป็นกระบวนการสำคัญที่ครอบคลุมทั้งการค้นหาและแก้ไขข้อผิดพลาด (Troubleshooting) การป้องกันความเสียหายจากปัจจัยแวดล้อม เช่น ไฟกระชาก ความร้อน ความชื้น และสัญญาณรบกวนทางไฟฟ้า รวมถึงแนวทางการบำรุงรักษาเชิงป้องกัน (Preventive Maintenance) และเชิงคาดการณ์ (Predictive Maintenance) การดูแลรักษา PLC อย่างเป็นระบบช่วยลด Downtime ยืดอายุการใช้งาน และรักษาความต่อเนื่องของกระบวนการผลิตในโรงงานอุตสาหกรรม จุดประสงค์การเรียน (จุดประสงค์ทั่วไป) จุดประสงค์เชิงพฤติกรรม

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • วิเคราะห์สาเหตุและตรวจสอบแก้ไขข้อผิดพลาดของระบบ PLC ได้อย่างเป็นระบบ
  • อธิบายหลักการและวิธีการป้องกันความเสียหายของ PLC จากปัจจัยแวดล้อมต่าง ๆ
  • อธิบายแนวทางการบำรุงรักษาเชิงป้องกัน (Preventive) และเชิงคาดการณ์ (Predictive) ได้
  • สามารถจัดทำตารางและบันทึกการบำรุงรักษา PLC เพื่อใช้ในการวางแผนดูแลระบบได้

📝 4. บทสรุป

ระบบ PLC อาจทำงานผิดพลาดได้จากสาเหตุด้านไฟฟ้า การติดตั้ง โปรแกรม และสภาพแวดล้อม การตรวจสอบอย่างเป็นระบบช่วยให้พบสาเหตุได้รวดเร็ว การป้องกันความเสียหายทำได้โดยออกแบบการติดตั้งที่ปลอดภัย ควบคุมสภาพแวดล้อม และใช้อุปกรณ์ป้องกัน ส่วนการบำรุงรักษาเชิงป้องกันและเชิงคาดการณ์ช่วยยืดอายุการใช้งานและลดความเสียหายที่อาจเกิดขึ้น พร้อมบันทึกผลเป็นหลักฐานเพื่อวางแผนในระยะยาว

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายความสำคัญของการตรวจสอบและบำรุงรักษา PLC ในระบบควบคุมเครื่องจักรอัตโนมัติ …
  • จากเนื้อหาในบทเรียน จงอธิบายความแตกต่างระหว่าง การบำรุงรักษาเชิงป้องกัน (Preventive Maintenance) …
  • อธิบายขั้นตอนการตรวจสอบและแก้ไขข้อผิดพลาดของระบบ PLC (Troubleshooting) …
  • จากภาพการตรวจสอบสถานะการทำงานของ PLC ด้วย GX Works3 Monitor ให้อธิบายว่าการตรวจสอบสถานะ Input และ Output …
  • ยกตัวอย่างสาเหตุของความผิดพลาด (Error Cause) ของระบบ PLC อย่างน้อย 3 กรณี …
  • อธิบายหลักการป้องกันความเสียหายของ PLC ที่เกิดจากไฟกระชาก ความร้อน และสัญญาณรบกวนทางไฟฟ้า …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ถอดปลั๊กแหล่งจ่ายไฟหรือกดสวิตช์ฉุกเฉินก่อนต่อ/แก้ไขสายไฟทุกครั้ง และจ่ายไฟได้เมื่อครูผู้สอนตรวจสอบแล้วเท่านั้น
  • ตรวจสอบแรงดันและขั้วของแหล่งจ่ายให้ตรงกับที่ระบุในคู่มือชุดฝึกก่อนจ่ายไฟ ห้ามต่อสายขณะมีไฟ
  • สวมรองเท้าหุ้มส้น ไม่สวมเครื่องประดับโลหะ และไม่วางของเหลวบนโต๊ะปฏิบัติงาน
  • ตัดแหล่งจ่ายไฟและตรวจสอบด้วยมัลติมิเตอร์ว่าไม่มีแรงดันค้างก่อนจับต้องจุดต่อสายทุกครั้ง
  • ไม่ถอดหรือเปลี่ยนอุปกรณ์ใด ๆ โดยไม่ได้รับอนุญาตจากครูผู้สอน
