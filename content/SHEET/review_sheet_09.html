⚙️ Review Sheet หน่วยที่ 9 — การประยุกต์ใช้ PLC และ HMI ควบคุมงานทางด้านเมคคาทรอนิกส์
EN-132-006 Programmable Logic Controller (PLC) · PLC and HMI Applications in Mechatronics
สัปดาห์ที่ 14–15 · ท 4 / ป 6 ชม. · CLO2
ใบงานปฏิบัติที่ 9
📌 1. สาระสำคัญ

การประยุกต์ใช้ PLC และ HMI ในการควบคุมงานทางด้านเมคคาทรอนิกส์ถือเป็นหัวใจสำคัญของอุตสาหกรรมยุค Industry 4.0 โดยระบบสายพานลำเลียง (Conveyor System) ใช้ PLC ควบคุมการเริ่ม-หยุดมอเตอร์ ตรวจจับวัตถุด้วย Sensor และนับจำนวนชิ้นงาน ส่วนระบบบรรจุผลิตภัณฑ์อัตโนมัติ (Automatic Packing System) ใช้ PLC ควบคุมลำดับการทำงาน เช่น การตรวจจับภาชนะ การจ่ายสินค้า การชั่งน้ำหนักด้วย Load Cell การซีลบรรจุภัณฑ์ และการนับจำนวน ทั้งสองระบบเชื่อมต่อกับ HMI เพื่อแสดงสถานะแบบเรียลไทม์ และสามารถเชื่อมโยงกับ IoT สู่ Cloud …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • อธิบายหลักการทำงานของระบบสายพานลำเลียงและบทบาทของ PLC ในการควบคุมได้
  • เขียนโปรแกรมควบคุมการทำงานของสายพานลำเลียง เช่น การเริ่ม-หยุด การตรวจจับวัตถุ และการนับชิ้นงานได้
  • อธิบายโครงสร้างและหลักการทำงานของระบบบรรจุผลิตภัณฑ์อัตโนมัติที่ควบคุมด้วย PLC ได้
  • เขียนโปรแกรมควบคุมลำดับการทำงานของระบบบรรจุ เช่น การจ่ายสินค้า การชั่งน้ำหนัก และการซีลบรรจุภัณฑ์ได้
  • อธิบายประโยชน์และวิธีการเชื่อมต่อ PLC – HMI – IoT ในระบบอัตโนมัติได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 9.1 ระบบสายพานลำเลียง (Conveyor System)
  • 9.2 ระบบบรรจุผลิตภัณฑ์อัตโนมัติ (Automatic Packing System)
📝 4. บทสรุป

การประยุกต์ใช้ PLC ร่วมกับ HMI ในงานเมคคาทรอนิกส์ เช่น ระบบสายพานลำเลียงและระบบบรรจุผลิตภัณฑ์อัตโนมัติ ต้องเริ่มจากการวิเคราะห์ลำดับการทำงาน กำหนดอินพุตและเอาต์พุต เขียนโปรแกรมควบคุม และออกแบบหน้าจอแสดงสถานะ ระบบที่ดีต้องมีมาตรการความปลอดภัย เช่น ปุ่มหยุดฉุกเฉิน การตรวจจับความผิดปกติ และการทดสอบการทำงานโดยรวมก่อนใช้งานจริง

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายบทบาทของ PLC ในการควบคุมระบบสายพานลำเลียง และระบุเหตุผลว่าทำไมจึงนิยมใช้ PLC …
  • อธิบายหลักการทำงานของระบบสายพานลำเลียง (Conveyor System) ตั้งแต่การตรวจจับวัตถุ การนับจำนวนชิ้นงาน …
  • ยกตัวอย่างอุปกรณ์ Sensor ที่ใช้ในระบบสายพานลำเลียง พร้อมอธิบายหน้าที่และตำแหน่งที่เหมาะสมในการติดตั้ง
  • อธิบายการทำงานของระบบสายพานที่เชื่อมต่อกับ HMI ว่ามีประโยชน์อย่างไรในการเฝ้าดูสถานะและควบคุมเครื่องจักร
  • เขียนแนวคิดหรือแผนผังลำดับการทำงาน (Flow Diagram) ของระบบสายพานลำเลียงอัตโนมัติที่ตรวจจับวัตถุ นับจำนวน …
  • อธิบายโครงสร้างและหลักการทำงานของระบบบรรจุผลิตภัณฑ์อัตโนมัติ (Automatic Packing System) โดยระบุอุปกรณ์หลัก …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ถอดปลั๊กแหล่งจ่ายไฟหรือกดสวิตช์ฉุกเฉินก่อนต่อ/แก้ไขสายไฟทุกครั้ง และจ่ายไฟได้เมื่อครูผู้สอนตรวจสอบแล้วเท่านั้น
  • ตรวจสอบแรงดันและขั้วของแหล่งจ่ายให้ตรงกับที่ระบุในคู่มือชุดฝึกก่อนจ่ายไฟ ห้ามต่อสายขณะมีไฟ
  • สวมรองเท้าหุ้มส้น ไม่สวมเครื่องประดับโลหะ และไม่วางของเหลวบนโต๊ะปฏิบัติงาน
  • ห้ามนำมือหรือสิ่งของเข้าใกล้สายพานและลูกกลิ้งขณะระบบทำงาน
  • ต้องทดสอบปุ่มหยุดฉุกเฉินให้ใช้งานได้ก่อนเริ่มทดสอบระบบทุกครั้ง
