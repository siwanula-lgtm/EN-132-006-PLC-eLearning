EN-132-006 Programmable Logic Controller (PLC) · Basic PLC Programming Instructions
สัปดาห์ที่ 4–5 · ท 4 / ป 6 ชม. · CLO1
ใบงานปฏิบัติ 2 ใบงาน
📌 1. สาระสำคัญ

การเขียนโปรแกรมควบคุมด้วยคำสั่งพื้นฐานของ PLC ในโปรแกรม GX Works3 ประกอบด้วยคำสั่งหลัก ได้แก่ AND, OR, Interlock Input/Output, Self Holding, SET/RESET, Zone Reset, Timer, Counter, Rising Edge, Falling Edge และ MOV ซึ่งเป็นพื้นฐานสำคัญในการออกแบบระบบควบคุมอัตโนมัติทางอุตสาหกรรม การเข้าใจหลักการทำงานของคำสั่งเหล่านี้ทำให้สามารถเขียนโปรแกรมควบคุมกระบวนการผลิตได้อย่างมีประสิทธิภาพและปลอดภัย จุดประสงค์การเรียน (จุดประสงค์ทั่วไป) จุดประสงค์เชิงพฤติกรรม

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 4.1 เข้าใจหลักการทำงานของคำสั่งตรรกะและการล็อกเงื่อนไขของ PLC ได้
  • 4.2 ปฏิบัติการเขียนโปรแกรมด้วยคำสั่งตรรกะและการล็อก เงื่อนไขได้ถูกต้อง
  • 4.3 เข้าใจหลักการทำงานของคำสั่งควบคุมสถานะ เวลา และการนับได้
  • 4.4 ปฏิบัติเขียนโปรแกรมควบคุมด้วยคำสั่งพื้นฐานของ PLC และตรวจหาข้อผิดพลาดของโปรแกรมได้ถูกต้อง
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 4.1 หลักการทำงานของคำสั่งตรรกะและการล็อกเงื่อนไขของ PLC
  • 4.2 เขียนโปรแกรมด้วยคำสั่งตรรกะและการล็อกเงื่อนไข
  • 4.3 หลักการทำงานของคำสั่งควบคุมสถานะ เวลา และการนับ
  • 4.4 โปรแกรมควบคุมด้วยคำสั่งพื้นฐานของ PLC และตรวจหาข้อผิดพลาดของโปรแกรม
📝 4. บทสรุป

คำสั่งพื้นฐานของ PLC ได้แก่ AND, OR, Interlock, Self Holding, SET/RESET, Zone Reset, Timer, Counter, Rising, Falling และ MOV คำสั่งเหล่านี้ใช้ประกอบกันเป็นโปรแกรมควบคุมตามลำดับและเงื่อนไข เช่น การเริ่ม-หยุดมอเตอร์ การหน่วงเวลา และการนับชิ้นงาน การออกแบบโปรแกรมที่ดีต้องคำนึงถึงความปลอดภัย เช่น การทำ Interlock เพื่อไม่ให้เอาต์พุตที่ขัดแย้งกันทำงานพร้อมกัน และการทดสอบด้วย Monitor ก่อนใช้งานจริงทุกครั้ง

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายหลักการทำงานของคำสั่ง AND Gate และยกตัวอย่างการใช้งานในโปรแกรม GX Works3 …
  • อธิบายคำสั่ง OR Gate พร้อมวาดตัวอย่าง Ladder Diagram ที่ใช้อินพุตแบบขนาน …
  • อธิบายหลักการของคำสั่ง Interlock Input (IL / ILC) …
  • อธิบายหลักการของคำสั่ง Self Holding พร้อมวาดวงจร Ladder Diagram สำหรับระบบ Start/Stop Motor …
  • อธิบายความแตกต่างของคำสั่ง SET, RESET และ Zone Reset (ZRST) …
  • อธิบายการทำงานของคำสั่ง Timer (T) และระบุความแตกต่างระหว่าง ON Delay Timer กับ OFF Delay Timer …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • เหตุใดการทำ Interlock ที่เอาต์พุตของมอเตอร์หมุนซ้าย/ขวาจึงมีความสำคัญต่อความปลอดภัย
  • เตรียมความพร้อมและปฏิบัติตามข้อควรระวังด้านความปลอดภัย
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 4
