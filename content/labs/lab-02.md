### 1. ลำดับขั้นการปฏิบัติงาน

| ขั้นที่         | กิจกรรมการปฏิบัติงาน                                                                           | เวลา (นาที) |
|-------------|--------------------------------------------------------------------------------------------|------------|
| 1           | รับชุดฝึก ตรวจความพร้อม และอ่านข้อควรระวังด้านความปลอดภัย                                           | 10         |
| 2           | ศึกษาตำแหน่งขั้วต่ออินพุต X เอาต์พุต Y และ Wiring Diagram ของชุดฝึก                                   | 20         |
| 3           | ต่อวงจร Push Button แบบหน้าสัมผัส NO เข้า X0 และแบบ NC เข้า X1 พร้อมบันทึกผลการวัดด้วยมัลติมิเตอร์        | 25         |
| 4           | ต่อ Proximity Sensor แบบ 3 สายเข้า X2 ตรวจสอบชนิด NPN/PNP และรูปแบบการต่ออินพุตให้สอดคล้องกัน        | 35         |
| 5           | ต่อ Pilot Lamp เข้า Y0 และขดลวดรีเลย์เข้า Y1 ตามแผนภาพการต่อวงจร                                 | 30         |
| 6           | ให้ครูตรวจสอบความถูกต้องของการต่อวงจรก่อนจ่ายไฟ                                                   | 10         |
| 7           | โหลดโปรเจกต์ทดสอบ เปิดโหมด Monitor กด Push Button และนำวัตถุเข้าใกล้เซนเซอร์ แล้วบันทึกสถานะ X และ Y | 40         |
| 8           | สรุปผล ส่งแบบบันทึกผล เก็บอุปกรณ์ และทำความสะอาดพื้นที่ปฏิบัติงาน                                        | 10         |
| รวมเวลาทั้งสิ้น |                                                                                            | 180        |

### 2. แบบบันทึกผลการปฏิบัติงาน

| รายการตรวจสอบ                      | ผลที่คาดหวัง                      | ผลที่ได้จริง | ผ่าน/ไม่ผ่าน |
|------------------------------------|--------------------------------|----------|-----------|
| X0 (Push Button NO) เมื่อกด          | สถานะ ON เมื่อกด และ OFF เมื่อปล่อย |          |           |
| X1 (Push Button NC) เมื่อกด          | สถานะตรงข้ามกับ X0               |          |           |
| X2 (Proximity Sensor) เมื่อตรวจจับวัตถุ | สถานะ ON เมื่อพบวัตถุ              |          |           |
| Y0 (Pilot Lamp) เมื่อสั่ง ON           | หลอดสว่างตรงกับสถานะใน Monitor   |          |           |
| Y1 (Relay) เมื่อสั่ง ON                | ได้ยินเสียงหน้าสัมผัสทำงาน           |          |           |
