## ใบงานปฏิบัติหน่วยเรียนที่ 6 เรื่องจัดทำหน้าจอควบคุมพื้นฐานด้วย HMI และเชื่อมต่อกับ PLC

### 1. ลำดับขั้นการปฏิบัติงาน

| ขั้นที่         | กิจกรรมการปฏิบัติงาน                                                                | เวลา (นาที) |
|-------------|---------------------------------------------------------------------------------|------------|
| 1           | รับชุดฝึก ตรวจความพร้อม และตรวจสอบการเชื่อมต่อ HMI กับ PLC                              | 10         |
| 2           | ออกแบบหน้าจอที่ 1 ใช้ Bit Switch ปุ่ม Start/Stop ควบคุมหลอดไฟ และใช้ Bit Lamp แสดงสถานะ | 30         |
| 3           | สร้างหน้าจอที่ 2 และตั้งค่าปุ่ม GO TO Screen เพื่อสลับระหว่างหน้าจอทั้งสองหน้า                   | 30         |
| 4           | เพิ่ม Numerical Display แสดงค่าปัจจุบันของ Timer หรือ Counter จากรีจิสเตอร์ D ของ PLC     | 25         |
| 5           | เพิ่ม Numerical Input สำหรับกำหนดค่าตั้งของ Timer หรือ Counter จากหน้าจอ HMI            | 30         |
| 6           | เขียนโปรแกรม PLC ที่สอดคล้องกับหน้าจอ แล้วโอนถ่ายข้อมูลและทดสอบการทำงานร่วมกัน              | 35         |
| 7           | ปรับแก้ตำแหน่งและรูปแบบหน้าจอให้อ่านง่ายและใช้งานสะดวก                                   | 10         |
| 8           | สรุปผล ส่งแบบบันทึกผล และเก็บอุปกรณ์                                                   | 10         |
| รวมเวลาทั้งสิ้น |                                                                                 | 180        |

|-----------------------|--------------------------------------|----------|-----------|
| Bit Switch Start/Stop | สั่งงาน/หยุดงานเอาต์พุตได้ถูกต้อง            |          |           |
| Bit Lamp แสดงสถานะ    | สถานะบนจอตรงกับเอาต์พุตจริง              |          |           |
| GO TO Screen          | สลับหน้าจอได้ทั้งไป-กลับ                   |          |           |
| Numerical Display     | แสดงค่าตรงกับค่าใน PLC                  |          |           |
| Numerical Input       | ค่าที่ป้อนมีผลต่อการทำงานของ Timer/Counter |          |           |
