รหัสวิชา: EN-132-006 ชื่อวิชา: Programmable Logic Controller (PLC) สัปดาห์ที่ 3

หน่วยที่: 3 ชื่อหน่วย: การใช้งาน PLC จำนวน: 5 ชม

### สาระสำคัญ
การใช้งาน PLC ในระบบอุตสาหกรรมจำเป็นต้องอาศัยโปรแกรม GX Works3 ของ Mitsubishi Electric ซึ่งเป็นซอฟต์แวร์ที่ใช้เขียนและจัดการโปรแกรมควบคุม PLC ตระกูล MELSEC iQ-F และ iQ-R การเรียนรู้ในหน่วยนี้ครอบคลุมตั้งแต่การติดตั้งโปรแกรม การทำความเข้าใจส่วนประกอบต่าง ๆ ของโปรแกรม การเชื่อมต่อ PLC กับคอมพิวเตอร์ผ่าน Ethernet การเขียนและอ่านข้อมูลจาก PLC การจำลองการทำงานโดยไม่ต้องใช้ PLC จริง และการตรวจสอบการทำงานแบบเรียลไทม์ ซึ่งทักษะเหล่านี้เป็นพื้นฐานสำคัญสำหรับการประยุกต์ใช้ PLC ในงานอุตสาหกรรมจริง จุดประสงค์การเรียน (จุดประสงค์ทั่วไป) จุดประสงค์เชิงพฤติกรรม

### กิจกรรมการเรียนการสอน
นักศึกษาทําแบบทดสอบก่อนเรียน

ขั้นนําเข้าสู่บทเรียน

1\. แจ้งจุดประสงค์การเรียนเรื่องการใช้งาน PLC การวัดผล ประเมินผลและการเข้าเรียน

2\. ครูนำเข้าสู่บทเรียนโดยพูดถึงเนื้อหาโดยรวมของการใช้งาน PLC ด้วยโปรแกรม GX Works3 และครูตั้งคำถามเพื่อให้นักศึกษาร่วมกันอภิปรายจากประสบการณ์

2.1 นักศึกษาเคยใช้โปรแกรมสำหรับเขียน PLC มาก่อนหรือไม่

2.2 GX Works3 แตกต่างจากโปรแกรมอื่น ๆ ที่ใช้เขียน PLC อย่างไร

ขั้นสอน/ประกอบกิจกรรม

1\. ครูอธิบายเนื้อหาโดยใช้สื่อ PowerPoint และสื่อวีดิทัศน์สอนประกอบการบรรยายเพื่อให้นักศึกษาอธิบายเนื้อหาสาระของการเรียนรู้เรื่องการใช้งาน PLC

1.1 ขั้นตอนการติดตั้งและระบุส่วนประกอบของโปรแกรม GX Works3

1.2 งานเชื่อมต่อ การเขียน-อ่านข้อมูล และการตรวจสอบแบบเรียลไทม์ของ PLC

1.3 นักศึกษาปฏิบัติงานตามใบงานปฏิบัติหน่วยเรียนที่ 3 เรื่องงานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3 ใช้เวลา 3 ชั่วโมง (180 นาที)

> อุปกรณ์: ชุดฝึกการเขียนโปรแกรมควบคุมอุปกรณ์ไฟฟ้าด้วยพีแอลซี / Notebook ที่ติดตั้งโปรแกรม GX Works3 พร้อมสาย LAN / เอกสารประกอบการสอนชุดฝึก เรื่อง Introduction + How to connect PLC / ใบความรู้ หน่วยเรียนที่ 3
>
> ขั้นตอนการทดลอง:
>
> ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อม และเปิดโปรแกรม GX Works3 (10 นาที)
>
> ขั้นที่ 2 สร้างโปรเจกต์ใหม่ เลือกชุดและรุ่น CPU ให้ตรงกับ PLC ของชุดฝึก แล้วบันทึกโปรเจกต์ (25 นาที)
>
> ขั้นที่ 3 ตั้งค่า Connection Destination แบบ Ethernet และทดสอบการสื่อสารด้วย Connection Test (30 นาที)
>
> ขั้นที่ 4 เขียนโปรแกรม Ladder อย่างง่าย LD X0 OUT Y0 แล้วทำการ Convert และตรวจสอบข้อผิดพลาด (25 นาที)
>
> ขั้นที่ 5 Write โปรแกรมลง PLC แล้ว Read กลับมาเปรียบเทียบกับโปรแกรมในคอมพิวเตอร์ (30 นาที)
>
> ขั้นที่ 6 สั่ง RUN และใช้โหมด Monitor ตรวจสอบสถานะ X0 และ Y0 พร้อมใช้ Watch Window (20 นาที)
>
> ขั้นที่ 7 ทดสอบโปรแกรมด้วย Simulation โดยไม่ต่อกับ PLC แล้วเปรียบเทียบผลกับการทดสอบจริง (30 นาที)
>
> ขั้นที่ 8 สรุปผล ส่งแบบบันทึกผล และเก็บอุปกรณ์ (10 นาที)
>
> การวัดผล: แบบบันทึกผลการปฏิบัติงาน คำถามท้ายใบงาน และเกณฑ์การประเมินผล 20 คะแนน (คิดเป็น 2 คะแนนของรายวิชา)

ขั้นสรุป

1\. ครูอธิบายสรุปเนื้อหา เรื่องการใช้งาน PLC ด้วยโปรแกรม GX Works3 และสรุปผลการปฏิบัติงานตามใบงานปฏิบัติพร้อมทั้งเสนอแนะแนวทางการปฏิบัติงานของแต่ละกลุ่ม

2\. นักศึกษาทำแบบฝึกหัด เรื่องการใช้งาน PLC จากนั้นครูและนักศึกษาร่วมกันเฉลยตรวจคำตอบเพื่อประเมินผลการเรียน

3\. ทำแบบทดสอบหลังเรียน

สื่อการเรียนการสอน

สื่อสิ่งพิมพ์

1\. เอกสารประกอบการสอนวิชา Programmable Logic Controller (PLC)

2\. หนังสือเรียนวิชา PLC

3\. แบบฝึกหัดพร้อมเฉลย

4\. แบบทดสอบก่อนเรียน/หลังเรียนพร้อมเฉลย

5\. ใบงานปฏิบัติหน่วยเรียนที่ 3 เรื่องงานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3 พร้อมแบบบันทึกผลและเกณฑ์การประเมิน

สื่อโสตทัศนูปกรณ์

1\. สื่อ PowerPoint ประกอบการสอน เรื่องการใช้งาน PLC ด้วยโปรแกรม GX Works3

2\. เครื่องคอมพิวเตอร์

3\. สื่อของจริง ตัวอย่าง PLC รุ่น Mitsubishi FX5UJ, FX5UJJ และอุปกรณ์เชื่อมต่อ

4\. วีดิทัศน์การติดตั้งและการใช้งาน GX Works3

5\. ทีวีอัจฉริยะ

### การวัดผลและประเมินผล
1\. คะแนนจากแบบฝึกหัดหน่วยที่ 3 เรื่องการใช้งาน PLC

2\. คะแนนจากแบบทดสอบก่อนเรียน/หลังเรียน หน่วยที่ 3 เรื่องการใช้งาน PLC

3\. คะแนนจากแบบสังเกตพฤติกรรมระหว่างการเรียนและการปฏิบัติงาน

4\. คะแนนจากใบงานปฏิบัติหน่วยเรียนที่ 3 ตามเกณฑ์การประเมินผล 20 คะแนน (คิดเป็น 2 คะแนนของรายวิชา)

3\. ข้อมูลจากอินเทอร์เน็ต

4\. เอกสาร/คู่มือ GX Works3 จาก Mitsubishi Electric

>

>
> 3.1.1 ส่วนประกอบหลักของโปรแกรม GX Works3

>
> 3.2.3 หลักการจำลองการทำงานของโปรแกรมและ การตรวจสอบแบบเรียลไทม์

>
> 3.3.1 งานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3
>
> 3.3.2 ผลการทดสอบด้วย Simulation กับ PLC จริง และสรุปข้อแตกต่าง
