ภาพที่ 2.1 Push Button NO

ในระบบ ควบคุมอัตโนมัติ (Automation Control System) หรือ ระบบ PLC (Programmable Logic Controller) อุปกรณ์ที่ใช้รับสัญญาณจากผู้ใช้งานหรือจากกระบวนการทำงานจริงเรียกว่า “อุปกรณ์อินพุต (Input Device)” หนึ่งในอุปกรณ์ที่สำคัญและใช้กันอย่างแพร่หลายคือ Push Button Switch (สวิตช์กดปุ่ม) ซึ่งใช้สำหรับสั่ง “เริ่มต้น (Start)” หรือ “หยุด (Stop)” การทำงานของเครื่องจักรหรือวงจรควบคุมต่าง ๆ ภาพที่แสดงนี้เป็น Push Button Switch ยี่ห้อ IDEC รุ่น YW1B-M1E10 ขนาด 22 มิลลิเมตร ซึ่งเป็นสวิตช์คุณภาพสูงจากญี่ปุ่น นิยมใช้ในงานอุตสาหกรรมทั่วไป เช่น ตู้ควบคุมมอเตอร์, เครื่องจักร, และระบบ PLC ในภาพด้านซ้ายเป็นตัวปุ่มกดจริงของ IDEC รุ่น YW-E10 สีเขียว ซึ่งโดยทั่วไปใช้เป็นปุ่ม Start เนื่องจากสีเขียวเป็นสัญลักษณ์ของ การเริ่มต้น

ส่วนภาพด้านขวาเป็นด้านหลังของตัวโมดูลคอนแทค (Contact Block) ที่ต่ออยู่กับปุ่ม โดยสังเกตเห็นคำว่า NO (Normally Open) อยู่บริเวณด้านบนขวา พร้อมมีหมายเลขขั้วต่อ หมายเลข 3 และ 4 แสดงจุดที่ใช้ต่อสายไฟเข้าสู่วงจรควบคุม

NO (Normally Open) หมายถึง วงจรเปิดอยู่ในสภาวะปกติ (ไม่มีไฟฟ้าไหลผ่าน)

เมื่อผู้ใช้กดปุ่ม Contact ภายในจะปิดลง ทำให้กระแสไฟฟ้าไหลผ่านและส่งสัญญาณไปยัง PLC

เมื่อปล่อยปุ่ม Contact จะกลับมาเปิดอีกครั้ง ตัดกระแสไฟฟ้าออก  
ดังนั้น ปุ่มนี้จะเหมาะกับการใช้งานประเภท สั่งเริ่ม (Start) เช่น สั่งให้มอเตอร์หมุน สั่งให้ Conveyor ทำงาน หรือใช้เป็นปุ่มเริ่มในวงจรการทำงานของระบบอัตโนมัติ นอกจากนี้ บริเวณตัวคอนแทคยังมีสัญลักษณ์มาตรฐาน เช่น

CE / UL / CCC — หมายถึง ได้รับมาตรฐานความปลอดภัยทางไฟฟ้าสากล

A600 Ui 600V 10A — ระบุค่ากระแสและแรงดันไฟสูงสุดที่ใช้งานได้

ปุ่มหยุดฉุกเฉิน (Emergency Stop Switch) หรือที่เรียกย่อว่า E-Stop จากยี่ห้อ IDEC รุ่น YW-E01 ซึ่งเป็นอุปกรณ์ควบคุมที่มีความสำคัญในระบบควบคุมอัตโนมัติ เช่น ระบบ PLC, เครื่องจักรอุตสาหกรรม และสายการผลิต โดยมีหน้าที่หลักในการ หยุดการทำงานของเครื่องจักรทันทีเมื่อเกิดเหตุฉุกเฉิน เพื่อป้องกันอันตรายต่อผู้ใช้งานและความเสียหายต่ออุปกรณ์

ภาพด้านซ้ายแสดงตัวปุ่มฉุกเฉินจริงของ IDEC รุ่น YW-E01 ซึ่งมีลักษณะเด่น คือ หัวปุ่มสีแดงขนาดใหญ่ ใช้มือกดได้สะดวกฐานสีดำและคอนแทคสีชมพูมีกลไก ล็อกค้าง (Lock) เมื่อกดลง เพื่อให้มั่นใจว่าเครื่องจะหยุดทำงานแน่นอนต้องหมุนหรือดึงปุ่มกลับเพื่อ รีเซ็ต (Reset) ก่อนใช้งานอีกครั้ง

ภาพด้านขวาแสดงส่วนของ คอนแทคบล็อก (Contact Block) โดยจะเห็นสัญลักษณ์ NC”(Normally Closed) ที่มีหมายเลขขา 1 – 2 กำกับไว้ ซึ่งหมายถึงเป็นคอนแทคที่ วงจรปิดอยู่ในสภาวะปกติ

### 2.1.2 หลักการทำงานของ Proximity Sensor แต่ละประเภท

PROXIMITY SENSOR เป็นตัวตรวจจับวัตถุ โดยไม่ต้องสัมผัสกับวัตถุ โดยอาศัยหลักการเหนี่ยวนำ ซึ่งจะแบ่งเป็น 2 ประเภทหลัก ๆ คือ

1\. INDUCTIVE PROXIMITY จะใช้หลักการสนามแม่เหล็กไฟฟ้า สำหรับตรวจจับวัตถุที่เป็น “โลหะ” โดยเซนเซอร์จะปล่อยสนามแม่เหล็กความถี่สูงออกมา หากมีวัสดุที่เป็นโลหะผ่านเข้ามาในบริเวณของสนามแม่เหล็กก็จะส่งผลให้ค่าความเหนี่ยวนำเกิดการเปลี่ยนแปลง ทำให้ทราบถึงตำแหน่งของวัตถุ หรือสามารถระบุได้ว่าขณะนั้นมีวัตถุใดผ่านเข้ามาในตำแหน่งที่กำหนดไว้หรือไม่

ภาพที่ 2.11 Encoder

เอนโค้ดเดอร์ (Encoder) เป็นอุปกรณ์ตรวจวัดตำแหน่ง มุมการหมุน หรือความเร็วรอบของเพลาในระบบอัตโนมัติและเครื่องจักรกล โดยจะแปลงการเคลื่อนไหวเชิงกลให้เป็นสัญญาณไฟฟ้าแบบดิจิทัล ส่งต่อไปยัง PLC หรือไมโครคอนโทรลเลอร์เพื่อใช้ในการควบคุมทิศทาง การนับรอบ หรือการกำหนดตำแหน่งที่แม่นยำ เหมาะสำหรับงานควบคุมมอเตอร์ เซอร์โว และระบบฟีดแบ็ก (Feedback Control System) ออปติคัลเอนโค้ดเดอร์ (Optical Encoder) ซึ่งมีหลักการทำงานโดยใช้ แผ่นดิสก์ (Code Disk) ที่มีช่องโปร่งแสง (Transparent) และทึบแสง (Opaque) สลับกัน เมื่อตัวเพลา (Shaft) หมุน แสงจาก LED จะส่องผ่านช่องบนดิสก์ไปยัง Photodetector ซึ่งตรวจจับการสลับของแสงและสร้างสัญญาณดิจิทัลออกมาเป็นพัลส์ (Pulse) ในภาพยังแสดงให้เห็นโมดูลเอนโค้ดเดอร์แบบอินฟราเรดขนาดเล็ก (เช่น H206 หรือรุ่นคล้ายกัน) ซึ่งใช้หลักการตรวจจับลำแสงแบบเดียวกัน เหมาะสำหรับงานต้นแบบหรือการใช้งานกับไมโครคอนโทรลเลอร์ เช่น Arduino หรือ PLC รุ่นเล็ก สัญญาณเอาต์พุตจากเอนโค้ดเดอร์มักประกอบด้วย 3 ช่องสัญญาณ ได้แก่ Channel A → สัญญาณพัลส์หลัก ใช้สำหรับการนับตำแหน่ง

Channel B → สัญญาณที่มีเฟสต่างจาก Channel A เพื่อบอกทิศทางการหมุน (CW หรือ CCW)

Channel Z → สัญญาณอ้างอิง (Index Pulse) ที่เกิดขึ้นเพียงครั้งเดียวต่อการหมุนครบ 1 รอบ เพื่อระบุตำแหน่งเริ่มต้น

สัญญาณทั้งสามช่องจะมีลักษณะเป็นพัลส์สี่เหลี่ยม (Square Wave) ตามภาพ ซึ่ง PLC หรือไมโครคอนโทรลเลอร์จะนับจำนวนพัลส์และคำนวณความเร็วหรือมุมหมุนได้อย่างแม่นยำ

เอนโค้ดเดอร์เป็นอุปกรณ์สำคัญในระบบอัตโนมัติที่ใช้ในการตรวจวัดตำแหน่งและความเร็วโดยอาศัยหลักการของการขัดขวางแสง (Optical Interruption) ให้เป็นพัลส์ไฟฟ้า มีทั้งแบบโมดูลตรวจจับขนาดเล็กและแบบเพลาหมุน (Rotary Encoder) ที่ใช้งานในระดับอุตสาหกรรม สามารถเชื่อมต่อกับ PLC เพื่อควบคุมตำแหน่งของมอเตอร์ ระบบขับเคลื่อน หรือแขนกลได้อย่างแม่นยำและเสถียร

## 2.2 ประเภทของอุปกรณ์เอาต์พุตของ PLC

### 2.2.1 หน้าที่ของสีต่าง ๆ ใน Pilot Lamp และ Tower Lamp

Pilot Lamp

ไฟสัญญาณแสดงสถานะ (Pilot Lamp) เป็นอุปกรณ์ไฟฟ้าที่ใช้แสดงผลการทำงานของวงจรหรือเครื่องจักรในระบบอัตโนมัติ เช่น แสดงสถานะการเปิด–ปิดเครื่อง การทำงานปกติ หรือการเกิดข้อขัดข้อง โดยมักติดตั้งบนตู้ควบคุม (Control Panel) ร่วมกับปุ่มกด (Push Button) และอุปกรณ์ อื่น ๆ เพื่อให้ผู้ใช้งานสามารถมองเห็นและรับรู้สถานของระบบได้อย่างรวดเร็ว

![ภาพที่ 2.12 Pilot Lamp](/images/book/image34.jpg)

ไฟสัญญาณชนิด Pilot Lamp แบบ LED ขนาด 22 มิลลิเมตร ซึ่งมีให้เลือกหลายสี โดยแต่ละสีมักถูกกำหนดให้แสดงสถานะที่แตกต่างกันตามมาตรฐานสากล เช่น

สีแดง (Red) — ใช้แสดงสถานะอันตราย หรือ เครื่องจักรกำลังทำงาน

สีเขียว (Green) — ใช้แสดงว่าเครื่องพร้อมใช้งาน หรือ การทำงานปกติ

สีน้ำเงิน (Blue) — มักใช้แสดงสถานะพิเศษ เช่น การทำงานของโหมดอัตโนมัติ

สีเหลือง/ส้ม (Yellow/Amber) — ใช้แสดงการเตือน หรือ เครื่องอยู่ในโหมดรอ

สีขาว (White) — ใช้แสดงไฟเลี้ยงเปิด หรือ ระบบพร้อมจ่ายพลังงาน

ไฟสัญญาณชนิดนี้มักใช้แรงดันไฟฟ้า 12VDC, 24VDC หรือ 110 – 120VAC และ 220 – 240VAC ตามชนิดของระบบควบคุม และมีโครงสร้างภายในเป็นหลอด LED ซึ่งให้ความสว่างสูง ใช้พลังงานต่ำ และมีอายุการใช้งานยาวนานกว่าแบบหลอดไส้

Tower Lamp

ไฟสัญญาณเสา (Tower Lamp) หรือที่เรียกว่า Stack Light เป็นอุปกรณ์แสดงสถานะในระบบอัตโนมัติที่ได้รับความนิยมอย่างแพร่หลาย โดยเฉพาะในโรงงานอุตสาหกรรมและสายการผลิต ใช้สำหรับแสดงสถานะการทำงานของเครื่องจักรหรือกระบวนการ เช่น กำลังทำงาน ปกติ หยุด หรือเกิดข้อขัดข้อง เพื่อให้ผู้ควบคุมสามารถรับรู้สถานะได้จากระยะไกลอย่างชัดเจน

![](/images/book/image35.jpg)

ภาพที่ 2.13 Tower Lamp

ในระบบควบคุมอัตโนมัติ การเชื่อมต่อสัญญาณจากอุปกรณ์ตรวจจับ (Sensor) เข้าสู่ PLC Input เป็นขั้นตอนสำคัญ เนื่องจากแต่ละอุปกรณ์มีรูปแบบการส่งสัญญาณต่างกัน การเข้าใจการต่อสายแบบ Sink Type และ Source Type จะช่วยให้สามารถเลือกใช้งานได้อย่างถูกต้อง ปลอดภัย และสอดคล้องกับชนิดของเซนเซอร์หรืออุปกรณ์อินพุตที่ใช้ในโรงงานอุตสาหกรรม ไฟสัญญาณเสาแบบหลายชั้น (Multi-Layer Tower Lamp) ซึ่งสามารถติดตั้งได้ทั้งแบบ ตั้งโต๊ะ, ติดผนัง หรือบนเครื่องจักร โดยแต่ละชั้นของหลอดไฟจะมีสีแตกต่างกันเพื่อบ่งบอกสถานะเฉพาะของระบบ ได้แก่

สีแดง (Red) – แสดงสถานะอันตราย หรือ เครื่องขัดข้องต้องหยุดการทำงานทันที

สีเหลือง (Yellow) – แสดงสถานะ “เตือน” หรือ “เครื่องกำลังอยู่ในภาวะเสี่ยง

สีเขียว (Green) – แสดงสถานะปกติ หรือ เครื่องจักรกำลังทำงานได้ตามปกติ

สีน้ำเงิน (Blue) – มักใช้แสดงว่าเครื่องรอการยืนยัน หรือ อยู่ในโหมดพิเศษ

สีขาว (White) – ใช้แสดงสถานะทั่วไป เช่น ระบบพร้อมทำงาน หรือ อยู่ในโหมดสแตนด์บาย

ไฟสัญญาณชนิดนี้อาจมาพร้อม เสียงเตือน (Buzzer) เพื่อเพิ่มความชัดเจนในกรณีที่เกิดเหตุฉุกเฉิน และสามารถทำงานได้กับแรงดันไฟฟ้า 24 VDC หรือ 220 VAC ตามการออกแบบของระบบควบคุม ไฟสัญญาณเสา (Tower Lamp) เป็นอุปกรณ์แสดงผลที่ช่วยเพิ่มความปลอดภัยและประสิทธิภาพในการทำงานในโรงงานอุตสาหกรรม ทำให้ผู้ควบคุมสามารถตรวจสอบสถานะของเครื่องจักรได้อย่างรวดเร็วจากระยะไกล ลดโอกาสเกิดความเสียหายและเพิ่มความต่อเนื่องในการผลิต

### 2.2.2 โครงสร้างและหน้าที่ขาของ Relay

![](/images/book/image36.png)

รีเลย์เป็นอุปกรณ์ควบคุมไฟฟ้าที่ใช้หลักการของ แม่เหล็กไฟฟ้า (Electromagnet) เพื่อเปิด–ปิดหน้าสัมผัสของวงจรโดยอัตโนมัติ เมื่อขดลวดภายในได้รับแรงดันไฟฟ้า จะสร้างสนามแม่เหล็กดึงคอนแทค (Contact) ให้เปลี่ยนสถานะจาก NC (Normally Closed) → เปิด หรือจาก NO (Normally Open) → ปิด ซึ่งเหมาะสำหรับควบคุมวงจรที่ต้องการแยกไฟควบคุมแรงดันต่ำออกจากวงจรโหลดแรงดันสูง เช่น มอเตอร์ หรือหลอดไฟ เป็นต้น ภาพนี้แสดงให้เห็น รีเลย์ชนิด Electromagnetic Relay แบบ 8 ขา (8-pin relay) และ ฐานซ็อกเก็ต Omron PYF08A-E ที่ใช้ในการติดตั้งรีเลย์บนรางหรือแผงควบคุม โดยมีชื่อขาและหน้าที่ดังนี้

![ภาพที่ 2.14 Relay](/images/book/image37.jpg)

ในรูปแสดงโครงสร้างและการทำงานของรีเลย์พร้อมฐานซ็อกเก็ต โดยรีเลย์จะประกอบด้วย 2 ส่วนหลัก ได้แก่ ขดลวด (Coil) เมื่อได้รับแรงดัน เช่น 24VDC จะเกิดสนามแม่เหล็กไฟฟ้าดึงหน้าสัมผัสให้เปลี่ยนสถานะหน้าสัมผัส (Contact) ทำหน้าที่สวิตช์เชื่อมต่อหรือแยกวงจรไฟฟ้า ประกอบด้วย

NC (Normally Closed) หน้าสัมผัสปกติปิด วงจรจะเปิดเมื่อรีเลย์ทำงาน

NO (Normally Open) หน้าสัมผัสปกติเปิด วงจรจะปิดเมื่อรีเลย์ทำงาน

C (Common) จุดต่อกลางระหว่าง NO และ NC

ส่วนฐานซ็อกเก็ต (Socket) เช่นรุ่น Omron PYF08A-E ใช้เป็นจุดเชื่อมต่อระหว่างรีเลย์กับสายไฟ เพื่อความสะดวกในการติดตั้งและถอดเปลี่ยน มีการกำหนดขาไว้ชัดเจน ดังตารางที่ 2.1

ตารางที่ 2.1 แสดงหมายเลขและหน้าที่ของขารีเลย์

| หมายเลขขา | ชื่อขา                       | หน้าที่ของขา                                                   |
|-----------|----------------------------|-------------------------------------------------------------|
| 2, 7      | Coil (+ / -)               | ขดลวดแม่เหล็กไฟฟ้า ใช้ต่อแรงดันควบคุม เช่น 24 VDC เพื่อสร้างสนามแม่เหล็ก |
| 1, 3      | Common (COM1, COM2)        | ขากลางของหน้าสัมผัส ใช้เป็นจุดเชื่อมระหว่าง NO/NC                    |
| 4, 6      | Normally Open (NO1, NO2)   | หน้าสัมผัสปกติเปิด จะต่อวงจรเมื่อรีเลย์ทำงาน                          |
| 5, 8      | Normally Closed (NC1, NC2) | หน้าสัมผัสปกติปิด จะตัดวงจรเมื่อรีเลย์ทำงาน                           |

รีเลย์เป็นหัวใจสำคัญของระบบควบคุมไฟฟ้าในงานอุตสาหกรรม เพราะสามารถควบคุมการทำงานของวงจรไฟฟ้าได้อย่างปลอดภัยและมีประสิทธิภาพ การใช้ฐานซ็อกเก็ตช่วยให้การต่อวงจรและบำรุงรักษาเป็นไปอย่างสะดวก รวดเร็ว และลดความเสี่ยงต่อความเสียหายของอุปกรณ์ควบคุมอื่น ๆ ในระบบ

### 2.2.3 ประเภทของมอเตอร์และการใช้งาน

มอเตอร์เป็นอุปกรณ์แปลงพลังงานไฟฟ้าให้เป็นพลังงานกล โดยมีบทบาทสำคัญในระบบอัตโนมัติ เครื่องจักร และอุปกรณ์ควบคุมต่าง ๆ ภาพนี้แสดงการจำแนกประเภทของมอเตอร์ออกเป็น 3 กลุ่มใหญ่ตามแหล่งจ่ายไฟและลักษณะการทำงาน ได้แก่ มอเตอร์กระแสสลับ (AC Motors), มอเตอร์กระแสตรง (DC Motors) และ มอเตอร์ชนิดพิเศษ (Special Motors) ซึ่งแต่ละชนิดมีโครงสร้างและหลักการทำงานเฉพาะตัว

1\. มอเตอร์กระแสสลับ (AC Motors)

เป็นมอเตอร์ที่ใช้พลังงานไฟฟ้ากระแสสลับ (AC) โดยทั่วไปใช้ในโรงงานอุตสาหกรรมและเครื่องจักรขนาดใหญ่ แบ่งออกเป็น Synchronous Motor หมุนด้วยความเร็วคงที่สัมพันธ์กับความถี่ของกระแสไฟ ใช้ในงานที่ต้องการความแม่นยำของความเร็วสูง เช่น เครื่องกลึงอัตโนมัติ หรือระบบควบคุมตำแหน่ง Induction Motor เป็นมอเตอร์ที่นิยมมากที่สุด ใช้งานง่าย ดูแลรักษาน้อย มีทั้งแบบเฟสเดียวและสามเฟส เหมาะสำหรับพัดลม เครื่องสูบน้ำ และสายพานลำเลียง

2\. มอเตอร์กระแสตรง (DC Motors)

ใช้พลังงานไฟฟ้ากระแสตรง (DC) เหมาะสำหรับงานที่ต้องการปรับความเร็วหรือแรงบิดได้ง่าย แบ่งเป็น Brushed DC Motor มีแปรงถ่านสัมผัสกับคอมมิวเตเตอร์เพื่อเปลี่ยนทิศทางกระแสในขดลวด ใช้งานทั่วไปในของเล่น เครื่องมือไฟฟ้า หรือระบบควบคุมขนาดเล็ก Brushless DC Motor (BLDC) ไม่มีแปรงถ่าน ใช้การควบคุมด้วยวงจรอิเล็กทรอนิกส์ ให้ประสิทธิภาพสูง เสียงรบกวนน้อย ใช้ในโดรน พัดลม และเครื่องจักรความเร็วสูง

3\. มอเตอร์ชนิดพิเศษ (Special Motors)

![](/images/book/image38.jpg)

ออกแบบมาเพื่อการควบคุมเฉพาะด้าน เช่น การหมุนตามมุมที่แม่นยำหรือการตอบสนองรวดเร็ว Stepper Motor หมุนแบบเป็นขั้น (Step) เหมาะสำหรับการควบคุมตำแหน่ง เช่น เครื่องพิมพ์ 3D หรือ CNC Servo Motor มีระบบควบคุมตำแหน่ง ความเร็ว และแรงบิดที่แม่นยำ ใช้ในแขนกล หุ่นยนต์ และระบบควบคุมอัตโนมัติ

ภาพที่ 2.15 ประเภทของมอเตอร์

มอเตอร์แต่ละประเภทมีคุณสมบัติและการใช้งานที่แตกต่างกัน ขึ้นอยู่กับความต้องการของระบบ เช่น หากต้องการแรงบิดสูงและความทนทานนิยมใช้ Induction Motor, หากต้องการควบคุมความเร็วและตำแหน่งอย่างละเอียดจะเลือกใช้ Stepper หรือ Servo Motor การเข้าใจประเภทของมอเตอร์จึงเป็นพื้นฐานสำคัญในการออกแบบระบบควบคุมและอัตโนมัติให้มีประสิทธิภาพสูงสุด

| Stepper Motor             | \- หมุนเป็นขั้น (Step) ควบคุมมุมได้ละเอียด- ไม่ต้องใช้ feedback sensor- ตอบสนองรวดเร็ว      | \- แรงบิดลดลงเมื่อความเร็วสูง- อาจสั่นเมื่อควบคุมไม่เหมาะสม                        | เครื่องพิมพ์ 3D, เครื่อง CNC, ระบบวางตำแหน่งอัตโนมัติ          |
| Servo Motor               | \- ควบคุมความเร็วและมุมได้แม่นยำสูง- มีระบบ Feedback (Encoder)- แรงบิดคงที่ตลอดช่วงการหมุน  | \- ราคาสูง- ต้องใช้วงจรควบคุมซับซ้อน                                          | แขนกล, หุ่นยนต์อุตสาหกรรม, ระบบควบคุมตำแหน่ง               |

## 2.3 การต่อวงจรอุปกรณ์อินพุตและเอาต์พุตกับ PLC และ ทดสอบด้วยโหมด Monitor

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 2 เรื่องต่อวงจรอุปกรณ์อินพุตและเอาต์พุตกับ PLC และทดสอบด้วยโหมด Monitor ใช้เวลา 3 ชั่วโมง (180 นาที) ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริงกับชุดฝึก และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อม และอ่านข้อควรระวังด้านความปลอดภัย (10 นาที)

ขั้นที่ 2 ศึกษาตำแหน่งขั้วต่ออินพุต X เอาต์พุต Y และ Wiring Diagram ของชุดฝึก (20 นาที)

ขั้นที่ 3 ต่อวงจร Push Button แบบหน้าสัมผัส NO เข้า X0 และแบบ NC เข้า X1 พร้อมบันทึกผลการวัดด้วยมัลติมิเตอร์ (25 นาที)

ขั้นที่ 4 ต่อ Proximity Sensor แบบ 3 สายเข้า X2 ตรวจสอบชนิด NPN/PNP และรูปแบบการต่ออินพุตให้สอดคล้องกัน (35 นาที)

ขั้นที่ 5 ต่อ Pilot Lamp เข้า Y0 และขดลวดรีเลย์เข้า Y1 ตามแผนภาพการต่อวงจร (30 นาที)

ขั้นที่ 6 ให้ครูตรวจสอบความถูกต้องของการต่อวงจรก่อนจ่ายไฟ (10 นาที)

ขั้นที่ 7 โหลดโปรเจกต์ทดสอบ เปิดโหมด Monitor กด Push Button และนำวัตถุเข้าใกล้เซนเซอร์ แล้วบันทึกสถานะ X และ Y (40 นาที)

ขั้นที่ 8 สรุปผล ส่งแบบบันทึกผล เก็บอุปกรณ์ และทำความสะอาดพื้นที่ปฏิบัติงาน (10 นาที)

### 2.3.1 งานต่อวงจรอุปกรณ์อินพุตและเอาต์พุตกับ PLC

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถสังเกตุการต่อวงจรอุปกรณ์อินพุตและเอาต์พุตกับ PLC ตามผังวงจรที่กำหนดได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 2 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 2.3.2 งานทดสอบด้วยโหมด Monitor

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถดำเนินการการทดสอบการทำงานของอุปกรณ์อินพุตและ เอาต์พุต ด้วยโหมด Monitor ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 2 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

## บทสรุป

อุปกรณ์อินพุตทำหน้าที่ส่งสัญญาณจากภายนอกเข้าสู่ PLC เช่น Push Button, Proximity Sensor และ Encoder ส่วนอุปกรณ์เอาต์พุตรับคำสั่งจาก PLC เช่น Pilot Lamp, Tower Lamp, Relay และมอเตอร์ การเลือกและต่ออุปกรณ์ต้องให้สอดคล้องกับชนิดของอินพุตและเอาต์พุตของ PLC รวมถึงแรงดันและกระแสของโหลด การใช้รีเลย์ช่วยแยกวงจรควบคุมออกจากวงจรกำลัง ทำให้ควบคุมโหลดที่มีกระแสสูงได้อย่างปลอดภัย

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้โดยใช้ความรู้จากบทเรียน พร้อมยกตัวอย่างประกอบ หากสามารถอธิบายพร้อมวาดภาพวงจรหรือแผนผังการต่อสายได้จะได้รับคะแนนเพิ่ม

**1. อธิบายหลักการทำงานของ Push Button แบบ NO (Normally Open) และ NC (Normally Closed) รวมทั้งยกตัวอย่างการใช้งานแต่ละแบบในระบบ PLC**

<details><summary>เฉลย</summary>

NO (Normally Open): วงจรเปิดในสภาวะปกติ เมื่อกดปุ่ม Contact ปิดลง กระแสไฟฟ้าไหลผ่านไปยัง PLC Input เหมาะสำหรับ ปุ่ม Start เช่น สั่งให้มอเตอร์หมุน หรือ Conveyor ทำงาน

NC (Normally Closed): วงจรปิดในสภาวะปกติ เมื่อกดปุ่ม Contact เปิดออก ตัดกระแสไฟฟ้า เหมาะสำหรับ ปุ่ม Stop หรือ Emergency Stop เพื่อให้ระบบหยุดทำงานเมื่อกด

</details>

**2. เปรียบเทียบความแตกต่างระหว่าง Push Button ทั่วไปกับ Emergency Stop Switch (E-Stop) และอธิบายเหตุผลที่ต้องมีระบบล็อกค้างในปุ่ม E-Stop**

<details><summary>เฉลย</summary>

Push Button ทั่วไปจะคืนสถานะเมื่อปล่อยมือ แต่ Emergency Stop (E-Stop) มีกลไกล็อกค้าง (Latch) เมื่อกดลง เพื่อให้เครื่องจักรหยุดทำงานอย่างแน่นอนและปลอดภัย ต้องหมุนหรือดึงปุ่มกลับเพื่อ Reset ก่อนใช้งานอีกครั้ง เหตุผลที่ต้องมีกลไกล็อกเพื่อป้องกันไม่ให้ระบบกลับมาทำงานโดยไม่ได้รับอนุญาต ลดความเสี่ยงต่ออุบัติเหตุ

</details>

**3. อธิบายหลักการทำงานของ Proximity Sensor ทั้ง 3 ประเภท คือ Inductive, Capacitive และ Photoelectric พร้อมยกตัวอย่างการใช้งานในอุตสาหกรรม**

<details><summary>เฉลย</summary>

Inductive Proximity ใช้สนามแม่เหล็กไฟฟ้าตรวจจับเฉพาะวัตถุโลหะ เช่น ตรวจนับชิ้นส่วนโลหะบนสายพาน

Capacitive Proximity ใช้หลักการประจุไฟฟ้าตรวจจับทั้งโลหะและอโลหะ เช่น ตรวจระดับของเหลวในถัง

Photoelectric ใช้แสง Emitter–Receiver ตรวจจับวัตถุ มี 3 แบบ คือ Through Beam (ระยะไกลสุด), Retro-reflective (ใช้ Reflector), และ Diffuse-reflective (สะท้อนจากตัววัตถุ) เช่น ตรวจนับกล่องสินค้า

</details>

**4. ใน Proximity Sensor แบบ 3 สาย มีการต่อสัญญาณแบบ NPN และ PNP จงอธิบายความแตกต่างและการเลือกใช้งานให้เหมาะสมกับ PLC ที่ใช้**

<details><summary>เฉลย</summary>

NPN (Sink Type) เมื่อ Sensor ตรวจจับวัตถุ OUT จะดึงกระแสลง GND (สัญญาณ LOW) เหมาะกับ PLC ที่ใช้ Source Type Input

PNP (Source Type) เมื่อ Sensor ตรวจจับวัตถุ OUT จะจ่ายกระแสออก (สัญญาณ HIGH) เหมาะกับ PLC ที่ใช้ Sink Type Input

การเลือกใช้ต้องพิจารณาให้ตรงกับชนิดของ PLC Input เพื่อให้สัญญาณทำงานได้ถูกต้อง

</details>

**5. อธิบายหน้าที่และการทำงานของ Encoder ในระบบควบคุม โดยระบุหน้าที่ของสัญญาณ Channel A, B และ Z รวมถึงยกตัวอย่างงานที่นิยมใช้ Encoder**

<details><summary>เฉลย</summary>

Channel A สัญญาณพัลส์หลัก ใช้สำหรับนับตำแหน่ง

Channel B สัญญาณที่มีเฟสต่างจาก A 90° ใช้บอกทิศทางการหมุน (CW หรือ CCW)

Channel Z สัญญาณอ้างอิง (Index Pulse) เกิดขึ้นครั้งเดียวต่อการหมุน 1 รอบ ใช้ระบุตำแหน่งเริ่มต้น

ตัวอย่างงาน ควบคุมความเร็วมอเตอร์ ระบบ Servo ควบคุมตำแหน่งแขนกล

</details>

**6. จงอธิบายความหมายของสีต่าง ๆ ใน Pilot Lamp และ Tower Lamp ว่ามีความหมายอย่างไรในเชิงสัญญาณควบคุม พร้อมระบุสถานการณ์ตัวอย่างที่ใช้ในสายการผลิต**

<details><summary>เฉลย</summary>

แดง อันตราย / เครื่องขัดข้อง (ต้องหยุดทำงานทันที)

เหลือง/ส้ม เตือน / เครื่องอยู่ในโหมดรอหรือภาวะเสี่ยง

เขียว ปกติ / เครื่องพร้อมใช้งานหรือทำงานได้ตามปกติ

น้ำเงิน โหมดพิเศษ / รอการยืนยัน

ขาว ระบบพร้อมทำงาน / ไฟเลี้ยงเปิด

ตัวอย่าง Tower Lamp บนเครื่อง CNC จะติดสีเขียวขณะผลิตปกติ เปลี่ยนเป็นเหลืองเมื่อวัตถุดิบใกล้หมด และแดงพร้อมเสียง Buzzer เมื่อเครื่องขัดข้อง

</details>

**7. จากภาพวงจรการต่อ Relay ชนิด 8 ขา อธิบายหน้าที่ของขา Coil, NO, NC และ Common รวมถึงอธิบายการทำงานเมื่อรีเลย์ได้รับแรงดันควบคุม**

<details><summary>เฉลย</summary>

Coil (ขา 2, 7) รับแรงดันควบคุม 24VDC สร้างสนามแม่เหล็กดึงหน้าสัมผัสให้เปลี่ยนสถานะ

Common (ขา 1, 3) ขากลาง เป็นจุดเชื่อมระหว่าง NO และ NC

NO (ขา 4, 6) หน้าสัมผัสปกติเปิด จะปิดเมื่อรีเลย์ทำงาน (รับไฟที่ Coil)

NC (ขา 5, 8) หน้าสัมผัสปกติปิด จะเปิดเมื่อรีเลย์ทำงาน

เมื่อรีเลย์ได้รับแรงดัน NC เปิดออก → NO ปิดลง → วงจรโหลดทำงาน

</details>

**8. เปรียบเทียบข้อดีและข้อจำกัดของ Relay, Contactor และ Solid State Relay โดยระบุประเภทของงานที่เหมาะกับอุปกรณ์แต่ละชนิด**

<details><summary>เฉลย</summary>

Relay ใช้ Coil แม่เหล็กไฟฟ้า หน้าสัมผัสโลหะ เหมาะสำหรับโหลดเล็ก-กลาง มีเสียงดังคลิก บำรุงรักษาง่าย

Contactor เหมือน Relay แต่รับกระแสสูงได้มากกว่า เหมาะสำหรับมอเตอร์ขนาดใหญ่

Solid State Relay (SSR) ไม่มีหน้าสัมผัสโลหะ ใช้อุปกรณ์อิเล็กทรอนิกส์สวิตช์ เงียบ ทนทาน เหมาะสำหรับการสวิตชิ่งความถี่สูงหรืองานที่ต้องการความเงียบ

</details>

**9. อธิบายหลักการทำงานของมอเตอร์แต่ละชนิด (AC, DC, Stepper, Servo) พร้อมยกตัวอย่างอุปกรณ์หรือเครื่องจักรที่นิยมใช้งานแต่ละประเภท**

<details><summary>เฉลย</summary>

AC Induction Motor ใช้สนามแม่เหล็กหมุนของ Stator เหนี่ยวนำกระแสใน Rotor ทำให้หมุน เช่น พัดลมอุตสาหกรรม

DC Motor ใช้แรงดัน DC ผ่านขดลวด Armature สร้างสนามแม่เหล็กต้านกัน ทำให้หมุน เช่น เครื่องมือไฟฟ้า

Stepper Motor ใช้พัลส์ไฟฟ้าหมุนเป็นขั้น (Step) แต่ละพัลส์หมุนมุมแน่นอน เช่น เครื่องพิมพ์ 3D

Servo Motor Stepper + Feedback Encoder ควบคุมตำแหน่งและความเร็วแม่นยำสูง เช่น แขนกลหุ่นยนต์

</details>

**10. จากความรู้ทั้งหมดในหน่วยนี้ ให้นักศึกษาวาดแผนภาพเชื่อมต่อวงจร PLC ที่ประกอบด้วย Input (Push Button และ Sensor) และ Output (Pilot Lamp หรือ Motor) พร้อมอธิบายการทำงานของระบบโดยรวมอย่างละเอียด**

<details><summary>เฉลย</summary>

วงจรตัวอย่าง

Input X0 = Push Button NO (ปุ่ม Start), X1 = Proximity Sensor (ตรวจวัตถุ)

Output Y0 = Pilot Lamp สีเขียว (แสดงสถานะปกติ), Y1 = Relay → ควบคุมมอเตอร์

หลักการทำงาน

กด Push Button (X0=ON) → โปรแกรม PLC ประมวลผล → สั่ง Y0=ON (Pilot Lamp ติด) และ Y1=ON (Relay ทำงาน → มอเตอร์หมุน)

Proximity Sensor (X1=ON) ตรวจวัตถุ → PLC อาจสั่งหยุดมอเตอร์หรือนับชิ้นงาน

ควรติดตั้ง Tower Lamp ไว้แสดงสถานะรวมของระบบ

</details>
