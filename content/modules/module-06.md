## 6.1 หลักการทำงานของวัตถุพื้นฐานบนหน้าจอ HMI

### 6.1.1 หลักการ Read/Write ระหว่าง HMI และ PLC

ในระบบอัตโนมัติสมัยใหม่ PLC (Programmable Logic Controller) และ HMI (Human-Machine Interface) ทำงานร่วมกันเพื่อให้เกิดการสื่อสารระหว่างเครื่องจักรกับผู้ปฏิบัติงานอย่างมีประสิทธิภาพ HMI ทำหน้าที่เป็น “หน้าจอสื่อสาร” ที่แสดงค่าจากตัวแปรใน PLC และรับคำสั่งจากผู้ใช้กลับไปยัง PLC การทำงานของ Read/Write HMI จึงเป็นพื้นฐานสำคัญของระบบอุตสาหกรรมอัจฉริยะ (Smart Factory) เช่น การควบคุมสายพาน การตรวจสอบค่ากระบวนการผลิต หรือการตั้งค่าพารามิเตอร์ของเครื่องจักร

หลักการทำงานของการอ่านและเขียนข้อมูลระหว่าง PLC และ HMI การสื่อสารระหว่าง PLC และ HMI ใช้โครงสร้าง Master–Slave Communication โดย PLC ทำหน้าที่เป็น *Master Device* ซึ่งควบคุมการประมวลผลและส่งข้อมูลออกไปHMI ทำหน้าที่เป็น *Slave Device* ซึ่งรับข้อมูลจาก PLC เพื่อนำมาแสดงผล และส่งข้อมูลกลับไปเมื่อผู้ใช้สั่งงาน ข้อมูลที่สื่อสารกันแบ่งออกเป็น 2 ประเภทหลัก ได้แก่

1\. Read (อ่านข้อมูล) — HMI อ่านค่าจากหน่วยความจำ (Register/Device) ของ PLC เช่น X, Y, D, M เพื่อนำไปแสดงผลบนหน้าจอ เช่น ค่าความเร็วหรืออุณหภูมิ

2.Write (เขียนข้อมูล) — HMI ส่งค่าจากผู้ใช้ เช่น คำสั่งเริ่ม/หยุด หรือค่าพารามิเตอร์ ไปยัง PLC เพื่อให้เกิดการทำงานตามที่กำหนด

การเชื่อมต่อและตั้งค่าพอร์ตสื่อสาร (Communication Port Setting) ในระบบ Mitsubishi สามารถเชื่อมต่อ HMI กับ PLC ได้หลายรูปแบบ เช่น RS-232 เหมาะสำหรับการสื่อสารระยะสั้น (ไม่เกิน 15 เมตร)

การตั้งค่าพื้นฐานในซอฟต์แวร์ GT Designer3 มีขั้นตอนดังนี้

1.  เปิดโปรแกรม GT Designer3 และสร้างโปรเจกต์ใหม่ (New Project)

2.  เลือกรุ่น HMI (เช่น GOT2000) และรุ่น PLC (เช่น FX5UJ)

3.  ตั้งค่าพอร์ตสื่อสาร เช่น RS-232 หรือ Ethernet ในหน้า Communication Setup

4.  กำหนด Device Address ที่ต้องการเชื่อมโยง เช่น

เมื่อกำหนดเรียบร้อยแล้ว ระบบสามารถทดสอบการเชื่อมต่อโดยใช้ Online Test Communication Check

การออกแบบหน้าจอแสดงผลและควบคุม (HMI Screen Design) ในโปรแกรม GT Designer3 สามารถสร้างหน้าจอแสดงผลแบบโต้ตอบ (Interactive Display) โดยใช้วัตถุหลัก (Objects) เช่น

> Numerical Display สำหรับแสดงค่าตัวเลขจาก PLC
>
> Bit Lamp สำหรับแสดงสถานะการทำงานของอุปกรณ์
>
> Bit Switch สำหรับรับคำสั่งจากผู้ใช้ เช่น Start/Stop Motor
>
> Text Display สำหรับแสดงข้อความ เช่น ระบบกำลังทำงาน หรือเกิด Alarm

แนวทางการออกแบบหน้าจอที่ดี

> จัดกลุ่มวัตถุให้สัมพันธ์กับกระบวนการจริง
>
> ใช้สีที่สื่อถึงสถานะ เช่น เขียว = ทำงาน, แดง = หยุด, เหลือง = แจ้งเตือน
>
> ใส่คำอธิบาย (Label) ชัดเจนทุกปุ่ม

การสื่อสารระหว่าง PLC และ HMI เป็นพื้นฐานสำคัญของระบบควบคุมอัตโนมัติที่ใช้รูปแบบ Master–Slave Communication โดย PLC ทำหน้าที่เป็น Master ในการควบคุมและส่งข้อมูลออก ส่วน HMI ทำหน้าที่เป็น Slave สำหรับรับ–ส่งข้อมูลและแสดงผลให้ผู้ใช้งานเข้าใจได้ง่าย HMI จะอ่าน (Read) ข้อมูลจากหน่วยความจำของ PLC เช่น X, Y, D, M เพื่อนำไปแสดงบนหน้าจอในรูปแบบค่าตัวเลขหรือสัญญาณสถานะ และสามารถเขียน (Write) คำสั่งหรือค่าพารามิเตอร์จากผู้ใช้งานกลับไปยัง PLC เพื่อควบคุมการทำงานของอุปกรณ์ต่าง ๆ เช่น การเริ่ม–หยุดเครื่องจักร หรือปรับค่าการทำงานในระบบได้อย่างแม่นยำ

### 6.1.2 หลักการทำงานของ Bit Switch และรูปแบบ Momentary / Alternate / Set-Reset

หน้าจอ HMI (Human Machine Interface) ทำหน้าที่เป็นสื่อกลางระหว่างผู้ใช้งาน และ เครื่องจักร เพื่อให้ผู้ควบคุมสามารถสั่งงาน ตรวจสอบ และปรับตั้งค่าระบบได้สะดวกมากขึ้น หนึ่งในวัตถุหลักที่นิยมใช้ใน HMI คือ ปุ่ม Bit Switch ซึ่งเป็นปุ่มที่ใช้สำหรับส่งสัญญาณเปิด–ปิด หรือสั่งเริ่ม–หยุดไปยังอุปกรณ์ที่เชื่อมต่อกับ PLC โดยตรง

Bit Switch เป็นองค์ประกอบสำคัญของหน้าจอ HMI เพราะสามารถจำลองการกดสวิตช์จริงในภาคสนามได้ โดยไม่จำเป็นต้องเดินสายสวิตช์จริง ทำให้ระบบมีความยืดหยุ่น ปลอดภัย และลดต้นทุนการเดินสายไฟลง ทั้งยังช่วยให้ผู้ควบคุมเห็นสถานะการทำงานของอุปกรณ์ได้ทันทีจากหน้าจอ เช่น การเปิด–ปิดมอเตอร์ การสั่งทำงานของโซลินอยด์วาล์ว หรือการเริ่มกระบวนการผลิตในสายการผลิต

หลักการทำงานของปุ่มสั่งงานแบบ Bit Switch บน HMIBit Switch คือวัตถุ (Object) บนหน้าจอ HMI ที่ใช้ควบคุม “สัญญาณแบบบิต” ของ PLC เช่น X, Y, M หรือ L โดยเมื่อผู้ใช้งานกดปุ่ม Bit Switch บนหน้าจอ ค่าของบิตนั้นจะถูก “เขียน (Write)” ไปยังหน่วยความจำของ PLC เพื่อให้ PLC รับรู้และนำไปประมวลผลตามโปรแกรมที่กำหนด ตัวอย่างเช่น Bit Switch ที่เชื่อมต่อกับ Y0 หมายถึง การสั่งให้เอาต์พุตของ PLC ทำงาน เช่น เปิดไฟหรือสตาร์ทมอเตอร์ Bit Switch ที่เชื่อมต่อกับ M0 หมายถึง การเปลี่ยนสถานะของบิตภายใน (Internal Bit) ที่ใช้ในการควบคุมลอจิกของโปรแกรม

ตารางที่ 6.1 รูปแบบการทำงานของ Bit Switch

| ประเภทการทำงาน | ลักษณะการควบคุม                  | ตัวอย่างการใช้งาน                    |
|----------------|--------------------------------|-----------------------------------|
| Momentary      | ทำงานเฉพาะตอนที่กดปุ่ม             | ใช้สั่ง Start ชั่วขณะ                  |
| Alternate      | กดครั้งแรก ON, กดอีกครั้ง OFF       | ใช้เปิด–ปิดไฟหรือมอเตอร์               |
| Set / Reset    | ปุ่มหนึ่งสำหรับ ON และอีกปุ่มสำหรับ OFF | ใช้ในระบบที่ต้องการควบคุมแยกสั่งเปิดและปิด |

การออกแบบและตั้งค่าปุ่ม Bit Switch เพื่อควบคุมอุปกรณ์ภายนอกผ่าน PLC การออกแบบปุ่ม Bit Switch ในโปรแกรม GT Designer3 มีขั้นตอนดังนี้

1.  เปิดโปรเจกต์ HMI ที่เชื่อมต่อกับ PLC เริ่มต้นจากการสร้างโปรเจกต์ใหม่ใน GT Designer3 และกำหนดการเชื่อมต่อกับ PLC ให้ถูกต้อง เช่น FX5UJ หรือ FX3U จากนั้นเลือกพอร์ตการสื่อสาร (Communication Port) เช่น RS-232, RS-485 หรือ Ethernet

2.  เพิ่มวัตถุ Bit Switch ลงบนหน้าจอ (Base Screen) ไปที่เมนู Object Switch Bit Switch คลิกเลือกตำแหน่งบนหน้าจอที่ต้องการวางปุ่ม ตั้งชื่อปุ่ม เช่น START, STOP, MOTOR ON เพื่อความเข้าใจง่าย กำหนดการเชื่อมโยงกับอุปกรณ์ (Device Address) ในช่อง Device/Address ให้ระบุหน่วยความจำของ PLC เช่น Y0, M0, หรือ D100 เป็นต้น สามารถตั้งค่าลักษณะการทำงาน (Operation Type) เป็น Momentary หรือ Alternate ได้ตามลักษณะของงาน

3.  ปรับแต่งลักษณะปุ่ม (Appearance) เลือกรูปแบบ สี และขนาดของปุ่มให้เหมาะสมกับหน้าจอ กำหนดสีแสดงผล ON/OFF ให้แตกต่างกันชัดเจน เช่น เขียว (ON) และเทา (OFF)

4.  ทดสอบการทำงาน (Simulation / Online Test) ใช้โหมด Simulation Mode เพื่อตรวจสอบการเปลี่ยนแปลงของบิตใน PLC เมื่อกดปุ่มจาก HMI หากเชื่อมต่อกับ PLC จริง สามารถใช้ Communication Write to GOT เพื่อส่งโปรแกรมลง HMI แล้วทดสอบการทำงานจริงได้

เมื่อระบบพร้อมใช้งาน ผู้ใช้งานสามารถกดปุ่มบนหน้าจอ HMI เพื่อควบคุมการทำงานของอุปกรณ์ภายนอก เช่น มอเตอร์ พัดลม หรือโซลินอยด์วาล์ว ผ่านสัญญาณเอาต์พุตของ PLC ได้โดยตรง ซึ่งช่วยให้การควบคุมเครื่องจักรทำได้รวดเร็วและปลอดภัยยิ่งขึ้น\\

### 6.1.3 หลักการแสดงสถานะอุปกรณ์ผ่าน Bit Lamp

การสั่งงานอุปกรณ์แล้ว สิ่งสำคัญอีกอย่างหนึ่งคือ “การแสดงผลสถานะ” ของระบบ เพื่อให้ผู้ปฏิบัติงานทราบว่าอุปกรณ์ใดกำลังทำงาน อุปกรณ์ใดหยุด หรือมีเหตุขัดข้องใด ๆ เกิดขึ้น หน้าจอ HMI (Human Machine Interface) จึงมีฟังก์ชันหนึ่งที่เรียกว่า Bit Lamp ซึ่งทำหน้าที่แสดงสถานะการทำงานของบิต (Bit Status) ที่รับข้อมูลจาก PLC

### 6.1.4 หลักการแสดงค่าและการรับค่าตัวเลขผ่าน Numerical Display และ Numerical Input

Numerical Display

ในระบบควบคุมอัตโนมัติหรือกระบวนการผลิตทางอุตสาหกรรม ผู้ควบคุมจำเป็นต้องทราบ ค่าตัวเลขที่เกิดขึ้นจากกระบวนการ เช่น อุณหภูมิ, ความดัน, ระดับของเหลว, ความเร็วของมอเตอร์ หรือจำนวนชิ้นงาน เพื่อใช้ในการเฝ้าระวังและควบคุมกระบวนการให้มีประสิทธิภาพ

Numerical Display คือวัตถุ (Object) บนหน้าจอ HMI (Human Machine Interface) ที่ใช้แสดงค่าตัวเลขซึ่งอ่านมาจาก PLC แบบเรียลไทม์ โดยค่าที่แสดงจะมาจากหน่วยความจำของ PLC เช่น Data Register (D) หรือ Word Device (W) และอัปเดตตามค่าจริงที่ PLC ประมวลผลได้ในขณะนั้น

การใช้งาน Numerical Display จึงมีความสำคัญในการสื่อสารข้อมูลตัวเลขระหว่างเครื่องจักรกับผู้ปฏิบัติงาน ช่วยให้สามารถตรวจสอบสถานะการทำงานและประสิทธิภาพของระบบได้ง่าย และช่วยลดความผิดพลาดจากการควบคุมโดยไม่ทราบค่าที่แท้จริงของกระบวนการ

Numerical Display เป็นวัตถุหลักที่ช่วยให้ HMI สามารถแสดงค่าตัวเลขจาก PLC ได้แบบเรียลไทม์ ทำให้ผู้ควบคุมระบบสามารถติดตามผลการทำงานของเครื่องจักรหรือกระบวนการผลิตได้สะดวกและแม่นยำมากขึ้น การเข้าใจหลักการอ่านข้อมูลจาก PLC และการตั้งค่า Numerical Display อย่างถูกต้องจึงเป็นพื้นฐานสำคัญของการออกแบบหน้าจอ HMI ที่มีประสิทธิภาพ

Numerical Input

ในระบบควบคุมที่ใช้ PLC (Programmable Logic Controller) เพื่อควบคุมเครื่องจักรหรือกระบวนการผลิต นอกจากการแสดงผลข้อมูลจากเครื่องจักรผ่าน HMI แล้ว ผู้ใช้งานยังจำเป็นต้อง “ป้อนข้อมูลกลับ” เข้าสู่ระบบ เพื่อปรับค่าการทำงานของเครื่องจักร เช่น ปรับเวลาหน่วง (Delay Time) กำหนดความเร็วรอบ (Set Speed) หรือปรับค่า Set Point ของอุณหภูมิ หรือตัวแปรต่าง ๆ ให้เหมาะสมกับสถานการณ์จริง

เครื่องมือที่ใช้สำหรับการป้อนข้อมูลตัวเลขเข้าสู่ PLC ผ่านหน้าจอ HMI คือ Numerical Input ซึ่งเป็นวัตถุ (Object) ที่อนุญาตให้ผู้ควบคุมสามารถกรอกค่าตัวเลขได้โดยตรง แทนการตั้งค่าผ่านโปรแกรม PLC หรืออุปกรณ์ภายนอก การใช้งาน Numerical Input ช่วยเพิ่มความสะดวก ยืดหยุ่น และความปลอดภัย เพราะผู้ปฏิบัติงานสามารถปรับค่าการทำงานได้จากหน้าจอ โดยไม่ต้องเข้าไปแก้ไขในโปรแกรมหลักของ PLC โดยตรง

## 6.2 จัดทำหน้าจอควบคุมพื้นฐานด้วย HMI และเชื่อมต่อกับ PLC

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 6 เรื่องจัดทำหน้าจอควบคุมพื้นฐานด้วย HMI และเชื่อมต่อกับ PLC ใช้เวลา 3 ชั่วโมง (180 นาที) ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริงกับชุดฝึก และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อม และตรวจสอบการเชื่อมต่อ HMI กับ PLC (10 นาที)

ขั้นที่ 2 ออกแบบหน้าจอที่ 1 ใช้ Bit Switch ปุ่ม Start/Stop ควบคุมหลอดไฟ และใช้ Bit Lamp แสดงสถานะ (30 นาที)

ขั้นที่ 3 สร้างหน้าจอที่ 2 และตั้งค่าปุ่ม GO TO Screen เพื่อสลับระหว่างหน้าจอทั้งสองหน้า (30 นาที)

ขั้นที่ 4 เพิ่ม Numerical Display แสดงค่าปัจจุบันของ Timer หรือ Counter จากรีจิสเตอร์ D ของ PLC (25 นาที)

ขั้นที่ 5 เพิ่ม Numerical Input สำหรับกำหนดค่าตั้งของ Timer หรือ Counter จากหน้าจอ HMI (30 นาที)

ขั้นที่ 6 เขียนโปรแกรม PLC ที่สอดคล้องกับหน้าจอ แล้วโอนถ่ายข้อมูลและทดสอบการทำงานร่วมกัน (35 นาที)

ขั้นที่ 7 ปรับแก้ตำแหน่งและรูปแบบหน้าจอให้อ่านง่ายและใช้งานสะดวก (10 นาที)

ขั้นที่ 8 สรุปผล ส่งแบบบันทึกผล และเก็บอุปกรณ์ (10 นาที)

### 6.2.1 งานจัดทำหน้าจอควบคุมพื้นฐานด้วย HMI และเชื่อมต่อกับ PLC

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถปฏิบัติตามหลักการจัดทำหน้าจอควบคุมพื้นฐานด้วย HMI และเชื่อมต่อกับ PLC ตามที่กำหนดได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 6 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 6.2.2 งานความเหมาะสมของหน้าจอด้านความชัดเจน และความปลอดภัย

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถปฏิบัติตามหลักการตรวจสอบความเหมาะสมของหน้าจอ ด้านความชัดเจนและความปลอดภัยตามรายการ ที่กำหนดได้ โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 6 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 6.2.3 งานหน้าจอหลายหน้าที่ทำงานร่วมกับโปรแกรม PLC

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถดำเนินการจัดทำหน้าจอหลายหน้าที่ทำงานร่วมกับ โปรแกรม PLC ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 6 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

## บทสรุป

การออกแบบหน้าจอ HMI พื้นฐานประกอบด้วย Bit Switch สำหรับสั่งงานบิต Bit Lamp สำหรับแสดงสถานะ Numerical Display สำหรับแสดงค่าตัวเลข และ Numerical Input สำหรับป้อนค่า โดยอ้างอิงอุปกรณ์ภายใน PLC ตามที่กำหนดใน Read/Write การสร้างหน้าจอหลายหน้าและการสลับหน้าจอช่วยจัดระเบียบการใช้งาน หน้าจอที่ดีต้องอ่านง่าย สื่อสถานะชัดเจน และคำนึงถึงความปลอดภัยของผู้ใช้งาน

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้โดยใช้ความรู้จากบทเรียน พร้อมยกตัวอย่างประกอบ หากสามารถอธิบายพร้อมวาดภาพวงจรหรือแผนผังการต่อสายได้จะได้รับคะแนนเพิ่ม

**1. อธิบายหลักการทำงานของการ Read/Write ระหว่าง HMI และ PLC ว่ามีความสำคัญอย่างไรต่อระบบควบคุมอัตโนมัติ พร้อมยกตัวอย่างการใช้งานจริงในงานอุตสาหกรรม**

<details><summary>เฉลย</summary>

การ Read/Write ระหว่าง HMI และ PLC ใช้โครงสร้าง Master-Slave Communication โดย PLC เป็น Master ควบคุมการประมวลผล ส่วน HMI เป็น Slave รับและแสดงผลข้อมูล การ Read คือ HMI อ่านค่าจากหน่วยความจำ PLC (X, Y, D, M) เพื่อแสดงบนหน้าจอ เช่น ค่าความเร็วหรืออุณหภูมิ ส่วนการ Write คือ HMI ส่งคำสั่งหรือพารามิเตอร์จากผู้ใช้ไปยัง PLC ตัวอย่างการใช้งานจริง เช่น การควบคุมสายพานลำเลียง การตรวจสอบค่ากระบวนการผลิต หรือการตั้งค่าพารามิเตอร์เครื่องจักร

</details>

**2. จงอธิบายลักษณะการสื่อสารแบบ Master–Slave Communication ระหว่าง HMI กับ PLC และระบุว่าข้อมูลใดที่อยู่ในกระบวนการ Read และ Write**

<details><summary>เฉลย</summary>

Master-Slave Communication คือรูปแบบการสื่อสารที่ Master (PLC) ควบคุมการส่งข้อมูลออก ในกระบวนการ Read: HMI ร้องขอข้อมูลจากหน่วยความจำ PLC เช่น ค่า D0 (ความเร็ว) หรือ M0 (สถานะ) แล้วนำมาแสดงผล ในกระบวนการ Write: เมื่อผู้ใช้กดปุ่มหรือกรอกค่าบน HMI ข้อมูลจะถูกส่งไปเขียนในหน่วยความจำ PLC เช่น Y0 (สั่งเปิดมอเตอร์) หรือ D10 (ค่า Set Point ใหม่)

</details>

**3. อธิบายประเภทของการเชื่อมต่อระหว่าง HMI และ PLC ได้แก่ RS-232, RS-485 และ Ethernet พร้อมเปรียบเทียบข้อดีและข้อจำกัดของแต่ละแบบ**

<details><summary>เฉลย</summary>

RS-232: เหมาะระยะสั้น (≤15 ม.) ใช้งานง่าย ต้นทุนต่ำ แต่เชื่อมต่อได้เพียง 1 อุปกรณ์ต่อพอร์ต RS-485: รองรับระยะไกลและหลายอุปกรณ์ในเครือข่ายเดียว เหมาะงานอุตสาหกรรมทั่วไป Ethernet (TCP/IP): ความเร็วสูง รองรับหลาย PLC พร้อมกัน เหมาะระบบ Smart Factory แต่ต้นทุนสูงกว่า

</details>

**4. อธิบายขั้นตอนการออกแบบหน้าจอ Read/Write HMI ในโปรแกรม GT Designer3 ตั้งแต่การสร้างโปรเจกต์ใหม่จนถึงการทดสอบการเชื่อมต่อกับ PLC**

<details><summary>เฉลย</summary>

1\) เปิด GT Designer3 สร้าง New Project เลือกรุ่น HMI (เช่น GOT2000) และ PLC (เช่น FX5UJ) 2) ตั้งค่า Communication Port เช่น RS-232 หรือ Ethernet ใน Communication Setup 3) กำหนด Device Address ที่ต้องการ เช่น X0, Y0, D0 4) วาง Object บนหน้าจอ เช่น Bit Switch, Numerical Display 5) ทดสอบด้วย Online Test → Communication Check หรือ Simulation Mode

</details>

**5. อธิบายความหมายและหลักการทำงานของ Bit Switch พร้อมยกตัวอย่างการใช้งานในงานควบคุม เช่น การสั่งเริ่มหรือหยุดเครื่องจักร**

<details><summary>เฉลย</summary>

Bit Switch คือวัตถุบนหน้าจอ HMI ที่ใช้ควบคุมสัญญาณแบบบิตของ PLC เช่น X, Y, M เมื่อผู้ใช้กดปุ่ม ค่าบิตนั้นจะถูก Write ไปยังหน่วยความจำ PLC เพื่อประมวลผลตามโปรแกรม ตัวอย่าง: Bit Switch ที่เชื่อมกับ Y0 จะสั่งให้เอาต์พุต PLC ทำงาน เช่น สตาร์ทมอเตอร์ Bit Switch ที่เชื่อมกับ M0 จะเปลี่ยนสถานะบิตภายในสำหรับควบคุม Logic

</details>

**6. จากตารางรูปแบบการทำงานของ Bit Switch (Momentary, Alternate, Set/Reset) ให้นักศึกษาอธิบายลักษณะการทำงานของแต่ละประเภท พร้อมยกตัวอย่างสถานการณ์การใช้งานที่เหมาะสม**

<details><summary>เฉลย</summary>

Momentary: ทำงาน ON เฉพาะขณะกดปุ่มค้าง เมื่อปล่อยกลับ OFF เหมาะสำหรับสั่ง Start ชั่วขณะ Alternate: กดครั้งแรก ON กดอีกครั้ง OFF สลับกันไป เหมาะสำหรับเปิด-ปิดไฟหรือมอเตอร์ Set/Reset: ใช้สองปุ่มแยกกัน ปุ่มหนึ่งสำหรับ ON (SET) อีกปุ่มสำหรับ OFF (RESET) เหมาะงานที่ต้องการความปลอดภัยสูง

</details>

**7. อธิบายหน้าที่และประโยชน์ของ Bit Lamp ในการแสดงผลสถานะการทำงานของอุปกรณ์ พร้อมอธิบายว่าทำไม Bit Lamp จึงช่วยให้ระบบปลอดภัยและตรวจสอบง่ายขึ้น**

<details><summary>เฉลย</summary>

Bit Lamp คือวัตถุบนหน้าจอ HMI ที่แสดงสถานะการทำงานของบิต PLC แบบเรียลไทม์ (Real-time Monitoring) โดยเปลี่ยนสีหรือรูปภาพตามสถานะของบิต เช่น เขียว = ON, แดง = OFF ช่วยเพิ่มความปลอดภัยเพราะผู้ควบคุมเห็นสถานะอุปกรณ์ทุกตัวได้ทันทีโดยไม่ต้องตรวจสอบวงจรจริง ลดเวลาในการตรวจสอบและช่วยวินิจฉัยปัญหาได้รวดเร็ว

</details>

**8. อธิบายหลักการทำงานของ Numerical Display และเหตุผลที่ต้องนำค่าจาก PLC มาแสดงผลบนหน้าจอ HMI ในรูปแบบตัวเลข พร้อมยกตัวอย่างค่าที่เหมาะสำหรับการแสดงผล**

<details><summary>เฉลย</summary>

Numerical Display คือวัตถุบนหน้าจอ HMI ที่แสดงค่าตัวเลขจาก PLC แบบเรียลไทม์ โดยอ่านค่าจาก Data Register (D) หรือ Word Device (W) ของ PLC แล้วนำมาแสดงผล ตัวอย่างค่าที่เหมาะสำหรับแสดงผล: อุณหภูมิเตาอบ (°C), ความเร็วรอบมอเตอร์ (RPM), จำนวนชิ้นงานที่ผลิต, ความดันระบบ (Bar) หรือระดับของเหลวในถัง

</details>

**9. อธิบายหลักการทำงานของ Numerical Input และยกตัวอย่างการใช้งานจริงที่ผู้ควบคุมสามารถปรับค่าพารามิเตอร์ในเครื่องจักรได้โดยไม่ต้องแก้โปรแกรม PLC โดยตรง**

<details><summary>เฉลย</summary>

Numerical Input คือวัตถุบนหน้าจอ HMI ที่รับค่าตัวเลขจากผู้ใช้แล้วส่ง (Write) ไปยังหน่วยความจำ PLC ช่วยให้ผู้ปฏิบัติงานปรับค่าพารามิเตอร์ได้โดยไม่ต้องแก้โปรแกรม PLC โดยตรง ตัวอย่างการใช้งาน: ปรับเวลาหน่วง Timer จาก 10 เป็น 20 วินาที, ตั้งค่า Set Point อุณหภูมิ, กำหนดความเร็วรอบมอเตอร์, หรือตั้งจำนวนชิ้นงานที่ต้องการผลิตในรอบนั้น

</details>

**10. ให้นักศึกษาสรุปภาพรวมของการใช้งาน HMI ร่วมกับ PLC ตั้งแต่การอ่าน-เขียนข้อมูล การสั่งงานด้วย Bit Switch การแสดงผลด้วย Bit Lamp และ Numerical Display ไปจนถึงการรับค่าผ่าน Numerical Input ว่าช่วยเพิ่มประสิทธิภาพในการควบคุมระบบอัตโนมัติได้อย่างไร**

<details><summary>เฉลย</summary>

การใช้งาน HMI ร่วมกับ PLC ช่วยเพิ่มประสิทธิภาพระบบอัตโนมัติครบวงจร: Read/Write HMI สร้างช่องทางสื่อสารข้อมูลสองทาง Bit Switch ให้ผู้ควบคุมสั่งงานอุปกรณ์ได้ง่ายและปลอดภัย Bit Lamp แสดงสถานะทุกอุปกรณ์แบบเรียลไทม์ลดความผิดพลาด Numerical Display แสดงค่ากระบวนการผลิตอย่างแม่นยำ และ Numerical Input ให้ผู้ปฏิบัติงานปรับพารามิเตอร์ได้ทันทีโดยไม่หยุดกระบวนการ ทั้งหมดนี้ทำให้ระบบควบคุมมีความยืดหยุ่น ปลอดภัย และง่ายต่อการใช้งานในสภาพแวดล้อมอุตสาหกรรมจริง

</details>
