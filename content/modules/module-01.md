## 1.1 คำนิยามและความหมายของโปรแกรมเมเบิลลอจิกคอนโทรลเลอร์

![ภาพที่ 1.1 คำนิยาม PLC](/images/book/image1.jpg)

### คำนิยาม

โปรแกรมเมเบิลลอจิกคอนโทรลเลอร์ (Programmable Logic Controller: PLC) หมายถึง อุปกรณ์ควบคุมเชิงดิจิทัลที่ได้รับการออกแบบมาเพื่อใช้ในงานอุตสาหกรรม ทำหน้าที่ประมวลผลข้อมูลจากสัญญาณอินพุต (Input) ที่มาจากอุปกรณ์ตรวจวัด เช่น สวิตช์ เซ็นเซอร์ หรืออุปกรณ์ส่งสัญญาณอื่น ๆ และประมวลผลตามโปรแกรมที่ผู้ใช้กำหนดไว้ จากนั้นจึงส่งสัญญาณเอาต์พุต (Output) เพื่อควบคุมการทำงานของอุปกรณ์ต่าง ๆ เช่น มอเตอร์ โซลินอยด์ วาล์ว หรือไฟสัญญาณ

### ความหมาย

PLC ถือเป็นสมองกลของระบบควบคุมอัตโนมัติในโรงงานอุตสาหกรรมที่มีคุณลักษณะเด่นด้านความยืดหยุ่น

ในการเขียนโปรแกรม สามารถปรับเปลี่ยนการทำงานได้โดยไม่จำเป็นต้องเปลี่ยนแปลงวงจรไฟฟ้าเหมือนกับรีเลย์แบบเดิม อีกทั้งยังมีความทนทานต่อสภาวะแวดล้อม เช่น ความร้อน ฝุ่น ความชื้น และสัญญาณรบกวนทางไฟฟ้า จึงมีความเหมาะสมอย่างยิ่งสำหรับการใช้งานในสายการผลิตและกระบวนการอุตสาหกรรม

### บทบาทสำคัญ

ใช้ในการควบคุมกระบวนการผลิตอย่างต่อเนื่อง (Continuous Process Control) ควบคุมการทำงานแบบลำดับขั้นตอน (Sequential Control) ใช้ร่วมกับระบบตรวจวัดและเซ็นเซอร์ต่าง ๆ เพื่อเพิ่มความแม่นยำในการควบคุม และสามารถเชื่อมต่อกับระบบเครือข่ายและ HMI (Human Machine Interface) เพื่อการสั่งงานและตรวจสอบสถานะการทำงานได้อย่างสะดวก

## 1.2 ผู้ผลิตโปรแกรมเมเบิลลอจิกคอนโทรลเลอร์และโปรแกรมที่ใช้ในการเขียนโปรแกรมควบคุม

![ภาพที่ 1.2 Manufacturer of PLC](/images/book/image2.jpg)

### ผู้ผลิตโปรแกรมเมเบิลลอจิกคอนโทรลเลอร์ (PLC)

ในปัจจุบันมีผู้ผลิตโปรแกรมเมเบิลลอจิกคอนโทรลเลอร์ (PLC) หลายบริษัท โดยแต่ละบริษัทมีมาตรฐานในการอ้างอิงสัญญาณอินพุตและเอาต์พุต รวมถึงซอฟต์แวร์สำหรับการเขียนโปรแกรมที่แตกต่างกัน แม้ว่าหลักการทำงานโดยทั่วไปจะคล้ายกัน แต่ความแตกต่างเหล่านี้ถือเป็นสิ่งสำคัญที่ผู้เรียนและผู้ใช้งานต้องทำความเข้าใจ เพื่อให้สามารถเลือกใช้งานได้อย่างเหมาะสมกับสภาพแวดล้อมและกระบวนการผลิตในอุตสาหกรรม

**Mitsubishi Electric** เป็นผู้ผลิตที่ได้รับความนิยมอย่างมาก โดยเฉพาะในประเทศไทย การอ้างอิงอินพุตใช้สัญลักษณ์ X0, X1, X2 เป็นต้น ส่วนเอาต์พุตใช้ Y0, Y1, Y2 และใช้ซอฟต์แวร์ GX-Works สำหรับการเขียนโปรแกรม จุดเด่นคือมีความเสถียร ใช้งานง่าย และรองรับการประยุกต์ในงานอุตสาหกรรมหลากหลายประเภท

**Wecon** เป็น PLC ที่มีราคาย่อมเยา เหมาะสำหรับการศึกษาและงานควบคุมขนาดเล็ก โดยใช้อ้างอิงอินพุตและเอาต์พุตในรูปแบบเดียวกับ Mitsubishi คือ X และ Y และใช้ซอฟต์แวร์ Wecon PLC Editor สำหรับเขียนโปรแกรม

**Omron** เป็น PLC ที่ได้รับความนิยมในงานเครื่องจักรอัตโนมัติ เช่น ระบบบรรจุภัณฑ์ มีความทนทานและรองรับโมดูลเสริมหลากหลาย การอ้างอิงอินพุตมักใช้ตัวเลข 0, 1, 2 เป็นต้น และเอาต์พุตใช้ 100, 101 เป็นต้น โดยใช้ซอฟต์แวร์ CX-Programmer เป็นหลัก

**Siemens** เป็นผู้ผลิต PLC ที่มีชื่อเสียงจากยุโรป เหมาะสำหรับโรงงานขนาดใหญ่ที่ต้องการระบบเชื่อมต่อขั้นสูง โดยใช้อ้างอิงอินพุตในรูปแบบ I0.0, I0.1 และเอาต์พุต Q0.0, Q0.1 พร้อมซอฟต์แวร์ TIA Portal ที่รองรับการทำงานแบบครบวงจรและเชื่อมโยงกับเทคโนโลยีอุตสาหกรรม 4.0

กล่าวโดยสรุป แม้ว่า PLC แต่ละยี่ห้อจะมีหลักการทำงานพื้นฐานที่คล้ายกัน แต่การอ้างอิงสัญญาณและซอฟต์แวร์ที่ใช้ มีความแตกต่างกัน ดังนั้นการเรียนรู้ลักษณะเฉพาะของแต่ละยี่ห้อจะช่วยให้ผู้ใช้งานสามารถเขียนโปรแกรมได้ถูกต้อง เลือกใช้ได้อย่างเหมาะสม และเพิ่มประสิทธิภาพในการควบคุมกระบวนการผลิตอัตโนมัติในสภาพแวดล้อมอุตสาหกรรมที่แตกต่างกัน

## 1.3 วิวัฒนาการของระบบ PLC จากอดีตจนถึงปัจจุบัน

\- ยุคแรก (1960s–1970s) → พัฒนามาแทนการควบคุมด้วยรีเลย์ มีเพียงการเขียนลอจิกแบบ Ladder - ยุคกลาง (1980s–1990s) → เพิ่มความสามารถด้านการประมวลผล รองรับภาษาหลายแบบ เช่น STL, FBD - ยุคปัจจุบัน (2000s–ปัจจุบัน) → มีการเชื่อมต่อกับระบบเครือข่าย Ethernet, IoT, รองรับ HMI และ SCADA - แนวโน้มอนาคต → ผสาน PLC กับเทคโนโลยี AI, Cloud และ Big Data เพื่อการควบคุมแบบอัจฉริยะ

## 1.4 โครงสร้างภายในและสถาปัตยกรรมของ PLC

โครงสร้างภายในของโปรแกรมเมเบิลลอจิกคอนโทรลเลอร์ (PLC) ถือเป็นหัวใจสำคัญที่ทำให้ระบบสามารถทำงานได้อย่างมีประสิทธิภาพและต่อเนื่อง โดยการออกแบบของ PLC เน้นความยืดหยุ่น ความทนทาน และความสามารถในการเชื่อมต่อกับอุปกรณ์ภายนอก ทั้งเซ็นเซอร์และอุปกรณ์ควบคุมต่าง ๆ เพื่อรองรับงานอุตสาหกรรมที่หลากหลาย

![ภาพที่ 1.3 โครงสร้าง PLC](/images/book/image3.jpg)

### Power Supply (AC/DC)

ทำหน้าที่จ่ายไฟเลี้ยงให้กับระบบทั้งหมด

> แปลงไฟจากแหล่งจ่าย (เช่น 220/110 VAC หรือ 24/12 VDC) มาเป็นแรงดันที่เหมาะสม

### Battery

> ใช้สำรองไฟเลี้ยงสำหรับหน่วยความจำ
>
> ช่วยเก็บข้อมูลโปรแกรมไม่ให้สูญหายเมื่อไฟดับ

### Memory (Data / Program)

> จัดเก็บโปรแกรมควบคุม (Program) และข้อมูลการทำงาน (Data)
>
> อาจใช้ ROM, RAM หรือ Flash Memory ตามรุ่นของ PLC

### CPU (Central Processing Unit)

สมองหลักของ PLC ทำหน้าที่อ่านสัญญาณจาก Input → ประมวลผลตามโปรแกรม → ส่งสัญญาณควบคุมออกไปยัง Output

### Input Unit

> รับสัญญาณจากอุปกรณ์ตรวจวัด เช่น ปุ่มกด, Limit Switch, Proximity Sensor
>
> แปลงสัญญาณจากภายนอกให้อยู่ในภาพที่ CPU ประมวลผลได้

### Output Unit

> ส่งสัญญาณไปควบคุมอุปกรณ์ เช่น มอเตอร์, หลอดไฟ, วาล์วไฟฟ้า
>
> มีทั้งแบบ Relay, Transistor, และ Triac

### Communication

> ใช้ในการเชื่อมต่อกับอุปกรณ์อื่น เช่น HMI, SCADA หรือระบบเครือข่ายอุตสาหกรรม

### Expansion (ส่วนขยาย)

โมดูลเสริมที่ช่วยเพิ่มความสามารถ เช่น โมดูล I/O เพิ่มเติม โมดูลอนาล็อก และโมดูลสื่อสาร จากโครงสร้างและสถาปัตยกรรมดังกล่าว จะเห็นได้ว่า PLC ถูกออกแบบให้มีการทำงานอย่างเป็นระบบโดยมีหน่วยประมวลผล (CPU) เป็นศูนย์กลาง ประกอบกับหน่วยความจำ อินพุต เอาต์พุต การสื่อสาร และระบบจ่ายไฟ ทำให้ PLC เป็นอุปกรณ์ควบคุมที่ยืดหยุ่น ปรับแต่งได้ และเหมาะสมกับการใช้งานในกระบวนการอัตโนมัติหลากหลายประเภท

## 1.5 ประเภทของการเชื่อมต่อวงจรอินพุตของ PLC

![ภาพที่ 1.4 ประเภทของการเชื่อมต่อวงจรอินพุตของ PLC](/images/book/image4.jpg)

ในระบบควบคุมอัตโนมัติ การเชื่อมต่อสัญญาณจากอุปกรณ์ตรวจจับ (Sensor) เข้าสู่ PLC Input เป็นขั้นตอนสำคัญ เนื่องจากแต่ละอุปกรณ์มีรูปแบบการส่งสัญญาณต่างกัน การเข้าใจการต่อสายแบบ Sink Type และ Source Type จะช่วยให้สามารถเลือกใช้งานได้อย่างถูกต้อง ปลอดภัย และสอดคล้องกับชนิดของเซนเซอร์หรืออุปกรณ์อินพุตที่ใช้ในโรงงานอุตสาหกรรม

### 1. Sink Type (ด้านซ้าย)

> **หลักการทำงาน**
>
> PLC ทำหน้าที่เป็น Sink หรือ "ตัวรับกระแส"

สัญญาณอินพุตจะถูกส่งเข้ามาผ่านการเชื่อมต่อกับ แรงดันบวก (+V) ของแหล่งจ่ายภายนอก

เมื่ออุปกรณ์อินพุต (เช่น ปุ่มกด, เซนเซอร์) ทำงาน กระแสไฟฟ้าจะไหลจาก +24V ผ่านอุปกรณ์ แล้วเข้าสู่ขาอินพุตของ PLC ลงไปยังกราวด์ (0V)

> **การใช้งาน**

นิยมใช้กับอุปกรณ์ที่ให้สัญญาณเอาต์พุตแบบ NPN (Open Collector) เช่น Proximity Sensor แบบ NPN

### 2. Source Type (ด้านขวา)

> **หลักการทำงาน**
>
> PLC ทำหน้าที่เป็น Source หรือ "ตัวจ่ายกระแส"
>
> สัญญาณอินพุตจะถูกเชื่อมต่อกับ กราวด์ (0V) ของแหล่งจ่ายภายนอก

เมื่ออุปกรณ์อินพุตทำงาน กระแสไฟฟ้าจะไหลจากขาอินพุต PLC (ซึ่งจ่ายกระแส +24V) ผ่านอุปกรณ์ แล้วกลับไปยังกราวด์

> **การใช้งาน**

เหมาะสำหรับอุปกรณ์ที่ให้สัญญาณเอาต์พุตแบบ PNP (Open Collector) เช่น Proximity Sensor แบบ PNP

### ตารางที่ 1.1 การเปรียบเทียบการต่อสายอินพุตของ PLC แบบ Sink Type และ Source Type

| **ประเด็นเปรียบเทียบ**    | **Sink Type**                                   | **Source Type**                            |
|------------------------|-------------------------------------------------|--------------------------------------------|
| **การทำงานของ PLC**    | เป็นตัวรับกระแส (Current Sink)                     | เป็นตัวจ่ายกระแส (Current Source)             |
| **ทิศทางกระแสไฟฟ้า**     | ไหลจาก +24V → ผ่านอุปกรณ์อินพุต → เข้าสู่ PLC (ลงกราวด์) | ไหลจาก PLC (+24V) → ผ่านอุปกรณ์อินพุต → ลงกราวด์ |
| **ชนิดเซนเซอร์ที่ใช้ร่วมกัน** | ใช้กับ NPN Sensor                                 | ใช้กับ PNP Sensor                            |
| **ข้อดี**                | ปลอดภัยเมื่ออุปกรณ์มีการรั่วไหลกระแส                    | ใช้ง่ายและเป็นมาตรฐานที่นิยมในยุโรป               |
| **ข้อควรระวัง**          | ต้องใช้แรงดันบวกจากภายนอก                          | อาจเกิดความเสียหายหากต่อผิดขั้ว                  |

## 1.6 ประเภทของการเชื่อมต่อวงจรเอาต์พุตของ PLC

ในการใช้งาน PLC Output จำเป็นต้องเลือกชนิดของการต่อวงจรให้เหมาะสมกับลักษณะของโหลดและแหล่งจ่ายไฟฟ้า โดยทั่วไป Output ของ PLC สามารถแบ่งเป็นแบบ Sink Type และ Source Type ซึ่งกำหนดทิศทางการไหลของกระแสไฟฟ้า และมีผลต่อการเลือกใช้งานกับโหลด (เช่น มอเตอร์, หลอดไฟ, อุปกรณ์ควบคุมอื่น ๆ )

![ภาพที่ 1.5 การต่อ PLC แบบ Sink Type และ Source Type (Output Relay)](/images/book/image5.jpg)

### ด้านซ้าย: Sink Type (PLC Output Relay)

> **หลักการทำงาน**
>
> PLC Output ทำหน้าที่เป็น ตัวรับกระแส (Sink)

กระแสไฟฟ้าไหลจาก แหล่งจ่ายไฟ (DC/AC Power Supply**)** ผ่านโหลด (Load) → ผ่านฟิวส์ (Fuse) → เข้าสู่ขา Output (Y0, Y1, Y…) ของ PLC → ไปยัง COM0/COM1/COM… (กราวด์/Neutral)

> **ลักษณะสำคัญ**
>
> Output Relay สามารถทำงานได้ทั้งไฟ DC และ AC
>
> เหมาะสำหรับโหลดที่ต้องการความยืดหยุ่น เช่น หลอดไฟฟ้า, โซลินอยด์, คอนแทคเตอร์

### ด้านขวา: Source Type (PLC Output Relay)

> **หลักการทำงาน**
>
> PLC Output ทำหน้าที่เป็น ตัวจ่ายกระแส (Source)

กระแสไฟฟ้าไหลจากขา Output (Y0, Y1, Y…) ของ PLC → ออกไปยังโหลด (Load) → ผ่านฟิวส์ → กลับไปยังแหล่งจ่ายไฟ (+V0, +V1, +V…)

> **ลักษณะสำคัญ**
>
> ขา Output ของ PLC จ่ายกระแสโดยตรง
>
> มักใช้กับโหลดที่ต้องการการจ่ายไฟตรงจาก PLC4

![ภาพที่ 1.6 การต่อ PLC แบบ Sink Type และ Source Type (Output Transistor)](/images/book/image6.jpg)

### ด้านซ้าย: Sink Type (PLC Output Transistor)

> **หลักการทำงาน**
>
> PLC ทำหน้าที่เป็น ตัวรับกระแส (Current Sink)

กระแสไฟฟ้าไหลจากขั้วบวกของแหล่งจ่ายไฟ DC → ผ่านโหลด (Load) → ผ่านฟิวส์ (Fuse) → เข้าสู่ขาเอาต์พุตของ PLC (Y0, Y1) → ต่อไปยัง COM (0V)

> **การใช้งาน**
>
> ใช้กับโหลดหรืออุปกรณ์ที่เป็น NPN Output Device
>
> เหมาะสำหรับระบบที่ต้องการให้อุปกรณ์จ่ายไฟบวก (+V) โดยให้ PLC เป็นทางลงกราวด์

### ด้านขวา: Source Type (PLC Output Transistor)

> **หลักการทำงาน**
>
> PLC ทำหน้าที่เป็น ตัวจ่ายกระแส (Current Source)

กระแสไฟฟ้าไหลจากขาเอาต์พุตของ PLC (Y0, Y1) → ออกไปยังโหลด (Load) → ผ่านฟิวส์ (Fuse) → กลับเข้าสู่ขั้วลบของแหล่งจ่ายไฟ DC (0V)

> **การใช้งาน**
>
> ใช้กับโหลดหรืออุปกรณ์ที่เป็น PNP Output Device
>
> เหมาะสำหรับระบบที่ต้องการให้ PLC จ่ายแรงดันบวกโดยตรงไปยังโหลด

![ภาพที่ 1.7 การต่อ PLC แบบ Sink Type และ Source Type (Output Triac)](/images/book/image7.jpg)

### ด้านซ้าย: Sink Type (PLC Output TRIAC)

> **หลักการทำงาน**
>
> PLC ทำหน้าที่เป็น ตัวรับกระแส (Current Sink)

กระแสไฟฟ้าไหลจากแหล่งจ่ายไฟ AC → ผ่านโหลด (Load) → ฟิวส์ (Fuse) → เข้าสู่ขาเอาต์พุต (Y0, Y1) ของ PLC → ต่อไปยัง COM0/COM1 (Neutral)

> **การใช้งาน**

เหมาะกับการควบคุมโหลด AC ที่ต่อกับสายไฟบวก (L Line) แล้วให้ PLC ทำหน้าที่ต่อวงจรลง Neutral

### ด้านขวา: Source Type (PLC Output TRIAC)

> **หลักการทำงาน**
>
> PLC ทำหน้าที่เป็น ตัวจ่ายกระแส (Current Source)

กระแสไฟฟ้าไหลออกจากขาเอาต์พุตของ PLC (Y0, Y1) → ผ่านโหลด (Load) → ฟิวส์ (Fuse) → กลับไปยังแหล่งจ่าย AC (Neutral)

> **การใช้งาน**
>
> เหมาะกับการควบคุมโหลด AC ที่ต้องการให้ PLC จ่ายไฟตรงไปยังโหลด

## 1.7 ประเภทของเอาต์พุตของ PLC

ในการใช้งาน PLC (Programmable Logic Controller) ส่วนที่สำคัญอีกหนึ่งองค์ประกอบคือ วงจรเอาต์พุต (Output Unit) ซึ่งทำหน้าที่ส่งสัญญาณควบคุมไปยังอุปกรณ์ภายนอก เช่น มอเตอร์, หลอดไฟ, โซลินอยด์ หรือฮีตเตอร์ แต่เนื่องจากลักษณะของโหลดและชนิดของไฟฟ้าที่ใช้งานมีความแตกต่างกัน ผู้ผลิต PLC จึงออกแบบเอาต์พุตให้มีหลายรูปแบบ ได้แก่ Relay Output, Transistor Output และ Triac Output แต่ละประเภทมีข้อดี ข้อจำกัด และความเหมาะสมในการใช้งานแตกต่างกัน เช่น Relay เหมาะกับโหลดที่ต้องใช้ทั้ง AC และ DC, Transistor เหมาะกับโหลด DC ที่ต้องการความเร็วสูง ส่วน Triac เหมาะกับโหลด AC โดยเฉพาะงานที่ต้องการควบคุมไฟฟ้ากำลังอย่างหลอดไฟหรือฮีตเตอร์ ดังนั้นการเลือกประเภทเอาต์พุตให้เหมาะสมกับงานจึงเป็นสิ่งสำคัญ เพื่อให้ระบบควบคุมทำงานได้อย่างมีประสิทธิภาพ ปลอดภัย และยืดอายุการใช้งานของอุปกรณ์

### ตารางที่ 1.2 การเปรียบเทียบชนิดของ PLC Output

| **ประเภท Output**     | **คุณสมบัติหลัก**                                | **เหมาะสำหรับโหลด**                        | **ข้อดี**                                                  | **ข้อจำกัด**                                            |
|-----------------------|----------------------------------------------|-------------------------------------------|----------------------------------------------------------|-------------------------------------------------------|
| **Relay Output**      | ใช้หน้าสัมผัสกลไก เปิด–ปิดวงจรได้ทั้ง AC และ DC       | หลอดไฟ AC/DC, มอเตอร์, คอนแทคเตอร์, โซลินอยด์ | \- ใช้ได้ทั้ง AC และ DC - รองรับกระแสสูง                       | \- ตอบสนองช้า (Mechanical) - มีเสียงคลิก - หน้าสัมผัสสึกหรอได้ |
| **Transistor Output** | ใช้ทรานซิสเตอร์ควบคุมการทำงาน ทำงานเฉพาะ DC Load | หลอดไฟ DC, LED, โซลินอยด์ DC, วงจรดิจิทัล      | \- ตอบสนองเร็วมาก - ไม่มีหน้าสัมผัสสึกหรอ - เหมาะกับงานความเร็วสูง | \- ใช้กับ DC เท่านั้น - กระแสที่รองรับต่ำกว่า Relay             |
| **Triac Output**      | ใช้ TRIAC ควบคุมการทำงาน ทำงานเฉพาะ AC Load    | หลอดไฟ AC, ฮีตเตอร์, มอเตอร์ AC ขนาดเล็ก      | \- ตอบสนองเร็ว - ไม่มีเสียงรบกวน - อายุการใช้งานยาวนาน         | \- ใช้กับ AC เท่านั้น - ไม่เหมาะกับโหลดกระแสสูงมาก            |

## 1.8 การอ่านและวิเคราะห์ข้อมูลจากป้ายแสดงคุณลักษณะจำเพาะของ PLC

ในปัจจุบัน PLC (Programmable Logic Controller) ถือเป็นอุปกรณ์หลักในงานควบคุมอัตโนมัติในภาคอุตสาหกรรม มีการพัฒนารูปแบบและขนาดให้หลากหลายเพื่อตอบสนองความต้องการใช้งานที่แตกต่างกัน โดยโครงสร้างของ PLC สามารถแบ่งออกเป็น 2 ประเภทหลัก ได้แก่ Modular PLC และ Compact PLC แต่ละประเภทมีลักษณะเฉพาะ ข้อดี และข้อจำกัดที่เหมาะสมกับงานลักษณะต่างกัน

![ภาพที่ 1.8 ประเภทของ PLC แบบ Modular และ Compact](/images/book/image8.jpg)

### Modular PLC

จากภาพด้านซ้าย แสดงให้เห็นว่า Modular PLC ประกอบด้วยหลายหน่วยย่อย (Modules) ได้แก่

**Power Supply** จ่ายไฟให้กับระบบ

> **CPU Unit** ประมวลผลและควบคุมการทำงาน
>
> **I/O Unit** สำหรับเชื่อมต่อสัญญาณ Input และ Output
>
> **Connection Unit** ใช้เชื่อมต่อกับอุปกรณ์ภายนอกหรือระบบเครือข่าย
>
> **Special Unit** ใช้สำหรับงานเฉพาะ เช่น Motion Control หรือ Communication

**ข้อดี** ขยายระบบได้ง่าย เลือก Module ตามความต้องการ ใช้กับงานอุตสาหกรรมขนาดกลางถึงใหญ่

> **ข้อจำกัด** มีราคาสูง ใช้พื้นที่ติดตั้งมาก

### Compact PLC

จากภาพด้านขวา เป็นตัวอย่าง **Mitsubishi FX5U** ซึ่งรวมส่วนประกอบหลักทั้งหมดไว้ในเครื่องเดียว

> CPU, Power Supply และ I/O ถูกติดตั้งในตัวเดียว
>
> สามารถต่อขยายได้บางส่วนด้วยโมดูลเสริม
>
> **ข้อดี** ขนาดเล็ก ใช้งานง่าย ติดตั้งสะดวก เหมาะสำหรับงานควบคุมขนาดเล็กถึงกลาง
>
> **ข้อจำกัด** ไม่สามารถขยาย I/O ได้มากเท่า Modular PLC และฟังก์ชันบางอย่างอาจจำกัด

### ตารางที่ 1.3 เปรียบเทียบคุณสมบัติของ Modular PLC และ Compact PLC

| **รายการเปรียบเทียบ**       | **Modular PLC**                                   | **Compact PLC**                      |
|---------------------------|---------------------------------------------------|--------------------------------------|
| **โครงสร้าง**              | แยกเป็นหน่วย (Power Supply, CPU, I/O, Special Unit) | รวมทุกส่วนในตัวเดียว (CPU + Power + I/O) |
| **การขยายระบบ**           | ขยายได้ง่าย โดยเพิ่มโมดูลเสริม                          | ขยายได้จำกัด บางรุ่นอาจต่อโมดูลเพิ่มได้เล็กน้อย |
| **ความยืดหยุ่น**             | ยืดหยุ่นสูง เลือกโมดูลตามการใช้งานได้                     | ความยืดหยุ่นต่ำ ฟังก์ชันถูกกำหนดมาแล้ว        |
| **ขนาดและการติดตั้ง**        | ขนาดใหญ่ ต้องใช้พื้นที่ติดตั้งมากกว่า                        | ขนาดกะทัดรัด ติดตั้งง่าย ประหยัดพื้นที่         |
| **ความเหมาะสมในการใช้งาน** | งานอุตสาหกรรมขนาดกลางถึงใหญ่ ที่ซับซ้อนและต้องการขยาย     | งานควบคุมขนาดเล็กถึงกลาง ไม่ซับซ้อนมาก     |
| **ราคา**                  | สูงกว่า เนื่องจากแยกเป็นหลายโมดูล                       | ต่ำกว่า ประหยัดกว่า                      |
| **การซ่อมบำรุง**            | ซ่อมง่าย สามารถเปลี่ยนเฉพาะโมดูลที่เสียได้                 | หากเสียอาจต้องเปลี่ยนทั้งชุด                |

### การอ่านป้ายชื่อ (Nameplate) ของ PLC

## 1.9 ภาษาที่ใช้ในการเขียนโปรแกรมสำหรับ PLC

ภาษาที่ใช้ในการเขียนโปรแกรม PLC ตามมาตรฐาน IEC 61131-3 ซึ่งเป็นมาตรฐานสากลที่กำหนดรูปแบบภาษาสำหรับการควบคุมอัตโนมัติและระบบอุตสาหกรรม โดยกำหนดภาษามาตรฐานไว้ 5 รูปแบบหลัก เพื่อรองรับลักษณะงานที่หลากหลายและตอบโจทย์ผู้ใช้งานทั้งสายฮาร์ดแวร์และซอฟต์แวร์

![ภาพที่ 1.10 ภาษาที่ใช้ใน PLC](/images/book/image10.jpg)

\- Sequential Function Charts (SFC)

ใช้สำหรับการเขียนโปรแกรมที่มีการทำงานแบบขั้นตอน (Step by Step) เหมาะกับงานที่ต้องควบคุมการทำงานเป็นลำดับ เช่น สายการผลิต

\- Function Block Diagram (FBD)

แสดงการทำงานด้วยบล็อกเชื่อมโยงกัน คล้ายวงจรไฟฟ้า เหมาะกับงานที่ซับซ้อน ต้องการแสดงฟังก์ชันหลายส่วนที่ทำงานสัมพันธ์กัน

\- Ladder Diagram (LD)

เป็นภาษาที่นิยมมากที่สุด เนื่องจากโครงสร้างเหมือนวงจรรีเลย์ เหมาะสำหรับช่างไฟฟ้าและวิศวกรที่คุ้นเคยกับวงจรควบคุม ใช้ในงานอุตสาหกรรมทั่วไป

\- Instruction List (IL)

เป็นภาษาแบบข้อความเชิงลำดับ (คล้าย Assembly) เหมาะกับงานที่ต้องการความรวดเร็วในการประมวลผล แต่ปัจจุบันเริ่มถูกแทนที่ด้วยภาษาอื่นเพราะเข้าใจยาก

\- Structured Text (ST)

เป็นภาษาเชิงโปรแกรมมิ่งที่คล้ายภาษา C หรือ Pascal ใช้เขียนคำสั่งซับซ้อน เช่น คณิตศาสตร์ การประมวลผลข้อมูล เหมาะกับงานที่ใช้ตรรกะหรือสูตรซับซ้อน

## 1.10 การเชื่อมต่อวงจรไฟฟ้าของ PLC

วงจรการเชื่อมต่อไฟฟ้าของ PLC (Programmable Logic Controller) โดยเฉพาะ PLC Mitsubishi รุ่น FX5U-32M ซึ่งเป็นรุ่นยอดนิยมในงานควบคุมอัตโนมัติ ภาพนี้อธิบายการเชื่อมต่อวงจรไฟฟ้าระหว่าง แหล่งจ่ายไฟ (Power Supply), วงจรอินพุต (Input Devices) เช่น สวิตช์หรือเซนเซอร์ และ วงจรเอาต์พุต (Output Devices) เช่น รีเลย์, หลอดไฟสัญญาณ หรือโซลินอยด์วาล์ว เพื่อให้ PLC สามารถควบคุมระบบอัตโนมัติได้อย่างถูกต้องและปลอดภัย

![ภาพที่ 1.11 การเชื่อมต่อวงจรไฟฟ้าของ PLC กับแหล่งจ่ายไฟและอุปกรณ์ควบคุม](/images/book/image11.jpg)

### แหล่งจ่ายไฟฟ้า (Power Supply)

ใช้ไฟ AC 220 V ป้อนเข้าที่ Power Supply (เช่น Delta Electronics) Power Supply จะแปลงแรงดันจาก 220 V AC เป็น 24 V DC เพื่อใช้เป็นแรงดันหลักในการจ่ายให้กับ PLC และอุปกรณ์อินพุต/เอาต์พุตขั้ว +24 V และ 0 V (GND) จาก Power Supply จะเชื่อมเข้ากับขั้วจ่ายไฟของ PLC

### วงจรอินพุต (Input Circuit)

ด้านบนของ PLC เชื่อมต่อกับอุปกรณ์อินพุต เช่น สวิตช์ปุ่มกด (Push Button), Proximity Sensor, Limit Switch, และ Photo Sensor เมื่ออินพุตใดทำงาน สัญญาณ 24 V DC จะถูกส่งเข้าที่ขั้วอินพุตของ PLC (เช่น X0, X1 ...) เพื่อให้ CPU ประมวลผลตามโปรแกรมที่กำหนด

### วงจรเอาต์พุต (Output Circuit)

ด้านล่างของ PLC เชื่อมต่อกับอุปกรณ์เอาต์พุต เช่น รีเลย์, หลอดไฟแสดงสถานะ, หรือคอนแทคเตอร์

เมื่อ CPU ประมวลผลแล้วส่งสัญญาณออกจากขั้วเอาต์พุต (เช่น Y0, Y1 ...) สัญญาณไฟ 24 V DC จะจ่ายไปยังอุปกรณ์เอาต์พุตเพื่อให้ทำงานตามคำสั่ง

### ระบบกราวด์และการป้องกัน

ระบบไฟฟ้าทั้งหมดควรต่อสายดิน (Ground) และมีการติดตั้ง ฟิวส์ (Fuse) เพื่อป้องกันกระแสเกินในกรณีเกิดความผิดปกติการจัดระเบียบสายไฟให้เหมาะสมช่วยลดสัญญาณรบกวน (Noise) ที่อาจเกิดจากวงจรภายนอก

## 1.11 อุปกรณ์และพารามิเตอร์ที่เกี่ยวข้องกับการใช้งาน PLC

ในระบบ PLC Mitsubishi (Programmable Logic Controller) การระบุอุปกรณ์และพารามิเตอร์ (Device & Parameter) เป็นสิ่งสำคัญมาก เนื่องจาก PLC ต้องใช้รหัสหรือชื่อเฉพาะ (Prefix) เพื่ออ้างอิงถึงอุปกรณ์ต่าง ๆ ภายในระบบ ไม่ว่าจะเป็นอินพุต (Input), เอาต์พุต (Output), หน่วยความจำภายใน (Memory), ตัวตั้งเวลา (Timer), หรือตัวนับ (Counter) เป็นต้น ภาพนี้แสดงตารางที่สรุป ชื่อย่อ (Prefix), ระบบการกำหนดหมายเลข (Addressing), ชนิดข้อมูล (Type) และ คำอธิบายการใช้งาน (Description) ของแต่ละอุปกรณ์ในระบบ PLC Mitsubishi รุ่นตระกูล FX Series เช่น FX5U, FX3U

![ภาพที่ 1.12 Device & Parameter ของ PLC Mitsubishi](/images/book/image12.jpg)

ภาพนี้แสดงตาราง “Device & Parameter” ซึ่งเป็นรายการของชื่ออุปกรณ์ (Device) ที่ใช้ในการเขียนโปรแกรม PLC โดยแต่ละตัวจะมี ชื่อย่อ (Prefix), ระบบการกำหนดตำแหน่ง (Addressing), ชนิดข้อมูล (Type) และ คำอธิบายหน้าที่ (Description) ที่แตกต่างกัน ซึ่งผู้เขียนโปรแกรมจำเป็นต้องเข้าใจเพื่อนำไปใช้งานได้อย่างถูกต้อง

## บทสรุป

PLC เป็นอุปกรณ์ควบคุมดิจิทัลสำหรับงานอุตสาหกรรม ประกอบด้วย CPU หน่วยความจำ อินพุต เอาต์พุต และแหล่งจ่ายไฟ สามารถปรับการทำงานได้ด้วยการเขียนโปรแกรม ต่างจากรีเลย์แบบเดิม นิยมใช้ภาษา Ladder Diagram (LD) ตามมาตรฐาน IEC 61131-3 การเลือกใช้งานควรพิจารณาจำนวน I/O ชนิดโหลด ซอฟต์แวร์ และสภาพแวดล้อมใช้งาน

ป้ายคุณลักษณะเฉพาะ (Nameplate) ของ PLC มักระบุข้อมูลสำคัญ เช่น รุ่น/รหัสสินค้า (Model No.) แรงดันไฟฟ้าที่ใช้งาน (Input/Output Voltage) จำนวนจุดอินพุต-เอาต์พุต กระแสไฟฟ้าสูงสุดที่ทนได้ และมาตรฐานความปลอดภัยที่ผ่านการรับรอง ซึ่งผู้ใช้งานต้องอ่านและตรวจสอบข้อมูลเหล่านี้ให้ตรงกับความต้องการของระบบก่อนเลือกใช้งานเสมอ

</details>

**9. จงอธิบายภาษาที่ใช้เขียนโปรแกรม PLC ตามมาตรฐาน IEC 61131-3 มาอย่างน้อย 3 ภาษา พร้อมยกตัวอย่างลักษณะการใช้งานของแต่ละภาษา**

<details><summary>เฉลย</summary>

มาตรฐาน IEC 61131-3 กำหนดภาษาเขียนโปรแกรม PLC ไว้ 5 ภาษา ได้แก่ Ladder Diagram (LD) ซึ่งเป็นรูปแบบวงจรรีเลย์ที่เข้าใจง่ายและนิยมมากที่สุด, Function Block Diagram (FBD) ที่ใช้บล็อกฟังก์ชันเชื่อมต่อกันและเหมาะกับงานควบคุมกระบวนการ, Structured Text (ST) ซึ่งเป็นภาษาระดับสูงคล้ายภาษาโปรแกรมทั่วไปและเหมาะกับการคำนวณซับซ้อน, Instruction List (IL) ที่เป็นภาษาระดับคำสั่งพื้นฐาน และ Sequential Function Chart (SFC) ซึ่งใช้แสดงลำดับขั้นการทำงานของระบบที่มีหลายสถานะ

</details>

**10. จงอธิบายขั้นตอนและข้อควรระวังในการเชื่อมต่อวงจรไฟฟ้าให้กับ PLC รวมถึงอุปกรณ์และพารามิเตอร์ที่เกี่ยวข้อง**

<details><summary>เฉลย</summary>

ขั้นตอนการเชื่อมต่อวงจรไฟฟ้าให้กับ PLC เริ่มจากการตรวจสอบแรงดันไฟฟ้าที่จ่ายให้ตรงกับพิกัดของ PLC ต่อสายกราวด์ (Ground) เพื่อความปลอดภัยและลดสัญญาณรบกวน ต่อสายอินพุตจากอุปกรณ์ตรวจจับหรือสวิตช์เข้าตามชนิด Sink หรือ Source ให้ถูกต้อง และต่อสายเอาต์พุตไปยังโหลดโดยพิจารณาพารามิเตอร์ต่าง ๆ เช่น กระแสสูงสุดที่จุดเอาต์พุตรองรับได้ โดยก่อนจ่ายไฟเข้าระบบต้องตรวจสอบการเดินสายให้ถูกต้องครบถ้วนทุกครั้งเพื่อป้องกันความเสียหาย

</details>
