การเรียนรู้ในหน่วยนี้จะช่วยให้นักศึกษาอธิบายโครงสร้าง การทำงาน และลักษณะของอุปกรณ์แต่ละชนิด รวมถึงสามารถเชื่อมต่อและโปรแกรมควบคุมอุปกรณ์เหล่านี้ผ่าน PLC ได้อย่างถูกต้องและปลอดภัย ซึ่งถือเป็นพื้นฐานสำคัญของการพัฒนาระบบควบคุมอัตโนมัติในงานอุตสาหกรรมและระบบเมคคาทรอนิกส์ยุคใหม่

## 8.1 Inductive Proximity Sensor

ในระบบอัตโนมัติและงานควบคุมเครื่องจักรด้วย PLC (Programmable Logic Controller) Inductive Proximity Sensor เป็นหนึ่งในอุปกรณ์ตรวจจับ (Sensor) ที่สำคัญที่สุด ซึ่งใช้สำหรับตรวจจับวัตถุที่เป็น โลหะ โดยไม่ต้องสัมผัสตัววัตถุโดยตรง ช่วยเพิ่มความปลอดภัย ความทนทาน และลดการสึกหรอของอุปกรณ์ในระบบอุตสาหกรรม เนื่องจากใช้หลักการเหนี่ยวนำแม่เหล็กไฟฟ้า (Electromagnetic Induction) ในการตรวจจับวัตถุที่อยู่ในระยะใกล้

Inductive Proximity Sensor หรือ "แม่เหล็กดักจับโลหะ" อาศัยหลักการเหนี่ยวสนามนำแม่เหล็กไฟฟ้า โดยมีขดลวดคอยล์เชื่อมกับวงจรออสซิลเลเตอร์ เมื่อจ่ายไฟเข้าสู่คอยล์จะเกิดสนามแม่เหล็กไฟฟ้ารอบ ๆ เมื่อมีโลหะเคลื่อนผ่านเข้ามาในสนามแม่เหล็กนี้ ก็จะเกิดการทำงานของเซนเซอร์ขึ้น ด้วยการส่งสัญญาณเอาต์พุตแจ้งสถานะการตรวจพบโลหะออกมา ซึ่งจะตอบสนองได้ดีที่สุดกับเหล็ก ส่วนสแตนเลส ทองเหลือง อลูมิเนียม จะมีระยะตรวจจับลดหลั่นกันไป

## 8.2 Capacitive Proximity Sensor

Capacitive Proximity Sensor เป็นเซนเซอร์ตรวจจับวัตถุแบบไม่สัมผัส (Non-contact Sensor) ที่สามารถตรวจจับได้ทั้ง วัตถุโลหะและอโลหะ เช่น พลาสติก แก้ว น้ำ หรือผงแป้ง ซึ่งแตกต่างจาก Inductive Proximity Sensor ที่ตรวจจับได้เฉพาะวัตถุโลหะเท่านั้น

ในระบบ PLC (Programmable Logic Controller) เซนเซอร์ชนิดนี้มักถูกใช้ในงานอุตสาหกรรมที่ต้องการตรวจจับวัตถุที่มีคุณสมบัติเป็นฉนวน เช่น การตรวจสอบระดับของเหลวในถังบรรจุ, การตรวจจับขวดหรือบรรจุภัณฑ์ในสายพานลำเลียง และการควบคุมระบบบรรจุผลิตภัณฑ์อัตโนมัติ โดยไม่จำเป็นต้องสัมผัสกับวัตถุโดยตรง ซึ่งช่วยลดการสึกหรอและเพิ่มความทนทานของระบบโดยรวม

![ภาพที่ 8.4 การต่อใช้งาน Capacitive Proximity Sensor แบบ 3 สาย เข้ากับ PLC Mitsubishi](/images/book/image119.png)

ภาพนี้แสดงตัวอย่างการต่อวงจร Capacitive Proximity Sensor แบบ 3 สาย (3-Wire Type) เข้ากับ PLC Mitsubishi รุ่น FX Series ซึ่งเป็นการประยุกต์ใช้งานจริงในระบบอัตโนมัติทางอุตสาหกรรม เซนเซอร์ชนิดนี้มีความสามารถในการตรวจจับวัตถุได้ทั้งโลหะและอโลหะ เช่น พลาสติก แก้ว และของเหลว โดยไม่ต้องสัมผัสกับวัตถุโดยตรง จึงเหมาะสำหรับระบบบรรจุภัณฑ์และการตรวจจับระดับของเหลวในถัง การเชื่อมต่อสายไฟของเซนเซอร์กับ PLC มีดังนี้: สายสีน้ำตาล (Brown) ต่อเข้ากับ +24VDC ซึ่งเป็นแหล่งจ่ายไฟหลักให้กับเซนเซอร์, สายสีน้ำเงิน (Blue) ต่อเข้ากับ 0VDC (GND) เพื่อปิดวงจรไฟฟ้า, และ สายสีดำ (Black) เป็นสาย สัญญาณ Output ที่ส่งเข้าสู่ ขา X0 ของ PLC เมื่อเซนเซอร์ตรวจจับวัตถุได้ เช่น ของเหลวหรือวัตถุอโลหะ สัญญาณไฟฟ้าจากสายสีดำจะเปลี่ยนสถานะเป็น “ON” (Logic 1) ทำให้ PLC รับข้อมูลการตรวจจับและนำไปประมวลผลต่อ เช่น การสั่งหยุดปั๊ม หรือเปิดวาล์วอัตโนมัติ การต่อใช้งาน Capacitive Proximity Sensor แบบ 3 สายกับ PLC Mitsubishi ถือเป็นพื้นฐานสำคัญของงานควบคุมอัตโนมัติ โดยช่วยให้ระบบตรวจจับวัตถุได้อย่างแม่นยำ ปลอดภัย และเหมาะสำหรับการพัฒนาไปสู่ระบบ Smart Factory ที่ต้องการความยืดหยุ่นและความน่าเชื่อถือในการตรวจจับสัญญาณจริงในกระบวนการผลิต

## 8.3 Photo Proximity Sensor

Photo Proximity Sensor หรือ เซนเซอร์ตรวจจับวัตถุด้วยแสง เป็นอุปกรณ์อิเล็กทรอนิกส์ที่ทำงานบนหลักการของ การส่งและรับแสง เพื่อใช้ในการตรวจจับการมีอยู่หรือการเคลื่อนไหวของวัตถุโดยไม่ต้องสัมผัสทางกายภาพ เซนเซอร์ชนิดนี้ถูกใช้งานอย่างแพร่หลายในระบบอัตโนมัติ (Automation System) และเครื่องจักรกลอุตสาหกรรม เนื่องจากมีความแม่นยำสูง ตอบสนองรวดเร็ว และสามารถตรวจจับวัตถุได้ทั้งที่เป็นโลหะและไม่เป็นโลหะ

หลักการทำงานของ Photo Proximity Sensor คือการปล่อยแสงจาก ตัวส่งแสง (Emitter) เช่น LED อินฟราเรด หรือ เลเซอร์ ไปยังพื้นที่ตรวจจับ และมี ตัวรับแสง (Receiver) ทำหน้าที่ตรวจวัดปริมาณแสงที่สะท้อนกลับหรือถูกขัดขวาง เมื่อมีวัตถุเข้ามาในระยะที่กำหนด การเปลี่ยนแปลงของแสงที่ตรวจจับได้จะถูกแปลงเป็นสัญญาณไฟฟ้าเพื่อส่งต่อไปยัง PLC (Programmable Logic Controller) หรือวงจรควบคุมอื่น ๆ

Photo Proximity Sensor สามารถแบ่งออกได้เป็นหลายรูปแบบตามลักษณะการติดตั้งและทิศทางของแสง ได้แก่ Through-Beam Type – ตัวส่งและตัวรับแสงแยกกัน เมื่อตัวรับไม่ได้รับแสงเพราะมีวัตถุบัง จะเกิดสัญญาณตรวจจับ (เหมาะกับงานตรวจจับระยะไกลและมีความแม่นยำสูง) Retro-Reflective Type – ตัวส่งและตัวรับอยู่ในตัวเดียวกัน ใช้แผ่นสะท้อน (Reflector) ช่วยสะท้อนแสงกลับมายังตัวรับ เมื่อวัตถุบังแสงจะเกิดสัญญาณตรวจจับ Diffuse Type – ตัวส่งและตัวรับอยู่ในตัวเดียวกัน และใช้หลักการสะท้อนแสงจากพื้นผิวของวัตถุโดยตรง เหมาะกับการตรวจจับในระยะใกล้

ด้วยคุณสมบัติในการตรวจจับได้รวดเร็ว ไม่ต้องสัมผัสวัตถุ และรองรับการทำงานในสภาพแวดล้อมที่หลากหลาย เช่น ฝุ่น ความชื้น หรือแสงรบกวน Photo Proximity Sensor จึงเป็นองค์ประกอบสำคัญในระบบควบคุมอัตโนมัติ เช่น การนับจำนวนชิ้นงานบนสายพาน การตรวจจับตำแหน่งวัตถุ การควบคุมกระบวนการบรรจุภัณฑ์ และการตรวจสอบความปลอดภัยของเครื่องจักร

โดยสรุป Photo Proximity Sensor เป็นเซนเซอร์ที่ผสานเทคโนโลยีแสงและอิเล็กทรอนิกส์เข้าด้วยกัน เพื่อสร้างระบบตรวจจับที่รวดเร็ว แม่นยำ และปลอดภัย ซึ่งมีบทบาทสำคัญอย่างยิ่งในงานด้าน เมคคาทรอนิกส์ (Mechatronics) และ ระบบอัตโนมัติทางอุตสาหกรรม (Industrial Automation Systems)

![ภาพที่ 8.5 การเขียนโปรแกรมควบคุมการทำงานของ Photo Proximity Sensor ด้วย GX Works3](/images/book/image120.jpg)

ภาพนี้แสดงตัวอย่างการเขียนโปรแกรมในซอฟต์แวร์ GX Works3 สำหรับควบคุมการทำงานของ Photoelectric Sensor โดยในโปรแกรมใช้สัญลักษณ์ X7 เป็นอินพุตที่รับสัญญาณจาก Photo Sensor และ Y1 เป็นเอาต์พุตที่ควบคุมหลอดไฟสีเขียว (LAMP G) ให้ทำงาน เมื่อเซนเซอร์ตรวจจับวัตถุได้ (เช่น กล่องที่เคลื่อนผ่านบนสายพานลำเลียง) อินพุต X7 จะเปลี่ยนสถานะจาก “OFF” เป็น “ON” ทำให้เอาต์พุต Y1 ทำงานและหลอดไฟสีเขียวติดขึ้น เพื่อแสดงผลการตรวจจับในระบบจริง โปรแกรมนี้เป็นพื้นฐานของการประยุกต์ใช้งานเซนเซอร์ในระบบ PLC สำหรับงานอัตโนมัติ เช่น การนับจำนวนชิ้นงาน การตรวจสอบตำแหน่ง หรือการคัดแยกผลิตภัณฑ์ ซึ่งช่วยให้กระบวนการผลิตทำงานได้อย่างมีประสิทธิภาพและแม่นยำ

## 8.4 Fiber Optic Sensor

ในระบบควบคุมอัตโนมัติสมัยใหม่ Fiber Optic Sensor ถือเป็นหนึ่งในเซนเซอร์ที่มีบทบาทสำคัญอย่างมาก โดยเฉพาะในงานที่ต้องการ ความแม่นยำสูงและการตรวจจับในพื้นที่จำกัด เช่น การตรวจสอบวัตถุขนาดเล็ก การนับชิ้นงานบนสายพานความเร็วสูง หรือการตรวจจับในพื้นที่ที่มีสภาวะอันตรายซึ่งไม่สามารถติดตั้งเซนเซอร์ทั่วไปได้ เซนเซอร์ชนิดนี้ทำงานโดยใช้หลักการของ แสงและใยแก้วนำแสง (Optical Fiber) ในการส่งและรับสัญญาณ ทำให้สามารถตรวจจับวัตถุได้โดยไม่ต้องสัมผัสโดยตรง

ไฟเบอร์ออบติกเซนเซอร์ประกอบด้วยอุปกรณ์สองชิ้นประกอบเข้าด้วยกัน คือ

1.ไฟเบอร์แอมพลิฟายเออร์ (Fiber Amplifier) ทำหน้าที่หลักๆในการปล่อยแสงออกไปยังสายไฟเบอร์ออพติกและเป็นส่วนในการประมวลผลในการตรวจจับวัตถุ ส่วนคุณสมบัติอื่นๆจะแตกต่างกันตามแต่ละรุ่น

2.หัวไฟเบอร์ออบติก (Fiber Optic) สายไฟเบอร์มีความสำคัญในการนำพาแสงจากส่วนของแอมป์พลิฟลายเออร์ไปยังวัตถุที่ต้องการตรวจจับ ซึ่งหัวไฟเบอร์ออบติกจะมีหลายรูปแบบให้เลิอกใช้งานให้เหมาะแก่การใช้งานและติดตั้ง

หลักการทำงานของไฟเบอร์เซนเซอร์

ทำงานโดยวงจรภายในแอมพลิไฟเออร์กำเนิดแสงและยิงแสงออกมาผ่านไปยังสายไฟเบอร์ที่หัวส่ง(Transmitter) ไปกระทบกับวัตถุ และสะท้อนกลับมายังหัวรับ(Receiver) แล้วส่งกลับไปยังแอมพลิไฟเออร์ ทำการประมวลผลจากค่าความเข้มแสงสะท้อนกลับมาเป็นตัวเลข

![ภาพที่ 8.6 หลักการทำงานของ Fiber Optic Sensor](/images/book/image121.jpg)

(ที่มา: https://riko.in.th/sensor-knowledge/11-sensors-basic-knowledge/30-how-fiberoptic-sensor-work)

ภาพนี้แสดงหลักการทำงานของ Fiber Optic Sensor ซึ่งเป็นอุปกรณ์ตรวจจับวัตถุด้วยการส่งและรับสัญญาณแสง โดยใช้เส้นใยแก้วนำแสง (Fiber Cable) ในการส่งผ่านแสงจาก หัวส่ง (Transmitter) ไปยังวัตถุ และรับแสงสะท้อนกลับจากวัตถุผ่าน หัวรับ (Receiver) จากนั้นสัญญาณแสงที่สะท้อนกลับจะถูกแปลงเป็นสัญญาณไฟฟ้าโดย หน่วยขยายสัญญาณ (Amplifier Unit) เพื่อส่งต่อให้กับ PLC ในการประมวลผลต่อไป

จากภาพเมื่อแสงจากหัวส่งเดินทางไปกระทบกับวัตถุ หากวัตถุอยู่ในระยะตรวจจับ แสงบางส่วนจะสะท้อนกลับเข้าสู่หัวรับ ทำให้เกิดสัญญาณเอาต์พุตที่สามารถใช้สั่งงานอุปกรณ์ เช่น หยุดมอเตอร์ หรือเปิดสัญญาณไฟแจ้งเตือน หลักการนี้ทำให้ Fiber Optic Sensor เหมาะสำหรับงานที่ต้องการตรวจจับวัตถุขนาดเล็ก ความเร็วสูง หรือพื้นที่ติดตั้งจำกัด เช่น ในเครื่องจักรอัตโนมัติและสายการผลิตที่มีความซับซ้อนสูง

## 8.5 Encoder

Encoder เอ็นโค้ดเดอร์ คืออุปกรณ์ที่ใช้สำหรับวัดระยะทางการเคลื่อนที่ของระบบที่ต้องการความแม่นยำในการบอกค่าระยะทางที่ต้องการความแม่นยำสูง เช่นระยะการเคลื่อนที่ของ Servo motor ระยะการเคลื่อนที่ของ Ball screw หรือระยะการเคลื่อนที่ของสายพานลำเลียงต่างๆ โดยหลักการทำงานของ เอ็นโค้ดเดอร์นั้นภายในจะมีแผ่นจานหมุนที่เจาะรูเอาไว้ให้เซ็นเซอร์ตัวส่งและตัวรับสามารถส่งสัญญาณหากันได้ หากรูของจานหมุนมาตรงตำแหน่งที่เซ็นเซอร์แสงสามารถส่องถึงกันได้ก็จะเกิดเป็นสัญญาณ Logic 1 หากรูของจานหมุนมาตรงตำแหน่งที่เซ็นเซอร์แสงที่ไม่สามารถส่องถึงกันได้ก็จะเกิดเป็นสัญญาณ Logic 0 ซึ่งความละเอียดจะขึ้นอยู่กับรุ่นของ เอ็นโค้ดเดอร์ที่เราเลือกใช้ ซึ่งมี่ตั้งแต่ 10 พัลซ์ 30 พัลซ์ 100 พัลซ์ 300 พัลซ์ 600 พัลซ์ 1000 พัลซ์ หรืออาจจะมากกว่าที่ได้ ยกตัวอย่าง พัลซ์ที่พูดถึงนี้คือสัญญาณที่จ่ายออกมาจาก เอ็นโค้ดเดอร์ต่อการหมุน 1 รอบ เช่นเอ็นโค้ดเดอร์ 100 พัลซ์ ก็หมายถึงการหมุน 1 รอบของเอ็นโค้ดเดอร์จะได้สัญญาณออกมา 100 พัลซ์

ภาพนี้แสดงหลักการทำงานของ Rotary Encoder ซึ่งเป็นอุปกรณ์ตรวจวัดการหมุนของเพลาในระบบอัตโนมัติ โดยทำหน้าที่แปลงการเคลื่อนไหวเชิงกลให้เป็นสัญญาณไฟฟ้าแบบพัลส์เพื่อใช้ควบคุมตำแหน่ง ความเร็ว หรือทิศทางของมอเตอร์ ตัว Encoder จะมี ดิสก์เจาะช่อง (Slotted Disk) หมุนไปพร้อมกับเพลา และมี หลอดแสง LED (Light Source) กับ ตัวตรวจจับแสง (Photodetector) วางอยู่ตรงข้ามกัน เมื่อดิสก์หมุน ช่องแสงจะสลับเปิดและปิด ทำให้เกิดสัญญาณพัลส์ไฟฟ้าที่สามารถส่งไปยัง Signal Converter เพื่อแปลงเป็นสัญญาณดิจิทัลออกมาในรูปของ สัญญาณ A, B และ Z โดยที่สัญญาณ A และ B ใช้สำหรับระบุทิศทางและจำนวนพัลส์ของการหมุน ส่วนสัญญาณ Z ใช้เป็นจุดอ้างอิงตำแหน่งเริ่มต้น (Home Position) หนึ่งรอบของการหมุน การทำงานในลักษณะนี้ช่วยให้ PLC สามารถตรวจจับและควบคุมการหมุนของมอเตอร์ได้อย่างแม่นยำ เหมาะสำหรับระบบที่ต้องการการควบคุมแบบปิดวงจร (Closed-loop Control) เช่น ระบบสายพานลำเลียง หุ่นยนต์อุตสาหกรรม เครื่องตัดอัตโนมัติ หรือระบบวัดระยะทางเชิงกล ความสามารถของ Encoder ในการแปลงการเคลื่อนที่ให้เป็นข้อมูลดิจิทัลทำให้ระบบอัตโนมัติสามารถทำงานได้อย่างมีประสิทธิภาพ แม่นยำ และตอบสนองต่อการเปลี่ยนแปลงของตำแหน่งหรือความเร็วได้แบบเรียลไทม์

## 8.6 Tower Lamp

Tower Lamp หรือ Signal Tower Light เป็นอุปกรณ์สัญญาณแสดงสถานะที่ถูกติดตั้งบนเครื่องจักรหรือในสายการผลิต เพื่อให้ผู้ปฏิบัติงานสามารถทราบสถานะของเครื่องจักรได้อย่างรวดเร็วจากระยะไกล โดยมักใช้สีของหลอดไฟเป็นตัวบ่งบอกสถานะ เช่น เครื่องทำงานปกติ หยุดชั่วคราว หรือเกิดข้อขัดข้อง ซึ่งช่วยเพิ่มประสิทธิภาพในการควบคุม ดูแล และบำรุงรักษาเครื่องจักรในระบบอัตโนมัติ ปัจจุบัน Tower Lamp มักถูกเชื่อมต่อกับ PLC (Programmable Logic Controller) เพื่อให้สามารถควบคุมการเปิด-ปิดหลอดไฟแต่ละสีได้ตามเงื่อนไขที่กำหนดในโปรแกรม

![ภาพที่ 8.8 Tower Lamp](/images/book/image124.png)

ภาพนี้แสดง Tower Lamp หรือ โคมไฟสัญญาณเตือนแบบเสาไฟหลายชั้น ซึ่งเป็นอุปกรณ์แสดงสถานะของเครื่องจักรในระบบอัตโนมัติ โดยมักติดตั้งอยู่บนเครื่องผลิตหรือสายพานในโรงงาน เพื่อให้ผู้ปฏิบัติงานสามารถมองเห็นสถานะของเครื่องจักรได้อย่างชัดเจนจากระยะไกล Tower Lamp ในภาพประกอบด้วยหลอดไฟ 3 ชั้น คือ สีแดง สีเหลือง และสีเขียว ซึ่งแต่ละสีจะบ่งบอกสถานะที่แตกต่างกัน ดังนี้

สีเขียว (Green) เครื่องจักรกำลังทำงานตามปกติ

สีเหลือง (Yellow) เครื่องอยู่ในโหมดเตรียมทำงาน รอคำสั่ง หรือกำลังเปลี่ยนสถานะ

สีแดง (Red) เครื่องจักรหยุดทำงาน หรือเกิดข้อผิดพลาดที่ต้องได้รับการตรวจสอบ

บางรุ่นของ Tower Lamp อาจมี เสียงเตือน (Buzzer) เพิ่มเติม เพื่อแจ้งเตือนผู้ควบคุมเมื่อเกิดเหตุฉุกเฉินหรือเมื่อเครื่องหยุดโดยไม่ตั้งใจ

Tower Lamp เป็นอุปกรณ์แสดงสถานะที่สำคัญในงานอุตสาหกรรม เพราะช่วยให้ผู้ปฏิบัติงานรับรู้สถานะของเครื่องจักรได้ทันทีโดยไม่ต้องเข้าใกล้เครื่อง ทำให้สามารถตอบสนองต่อปัญหาได้อย่างรวดเร็วและปลอดภัย การทำงานของ Tower Lamp สามารถควบคุมได้โดยตรงผ่าน PLC เพื่อแสดงผลตามเงื่อนไขของระบบ เช่น เมื่อเครื่องเริ่มทำงานให้แสดงไฟสีเขียว เมื่อหยุดชั่วคราวให้แสดงไฟสีเหลือง และเมื่อเกิดข้อขัดข้องให้แสดงไฟสีแดง ช่วยเพิ่มประสิทธิภาพในการตรวจสอบและการบำรุงรักษาระบบอัตโนมัติได้อย่างมีประสิทธิภาพ

![ภาพที่ 8.9 แผนผังการต่อวงจร Tower Lamp พร้อมเสียงเตือน](/images/book/image125.png)

ภาพนี้แสดงแผนผังการต่อวงจรของ Tower Lamp แบบ 3 สีพร้อมเสียงเตือน (Buzzer) ซึ่งนิยมใช้ในระบบควบคุมอัตโนมัติของโรงงานอุตสาหกรรม เพื่อแสดงสถานะการทำงานของเครื่องจักร โดยการเชื่อมต่อจะควบคุมผ่านสัญญาณจาก PLC หรือรีเลย์ภายนอก ภายใน Tower Lamp จะมีหลอดไฟ 3 สี ได้แก่ สีแดง สีเหลือง และสีเขียว พร้อมโมดูลเสียงเตือน โดยแต่ละสีมีความหมายแตกต่างกัน เช่น สีแดง (RED) แสดงว่าเครื่องจักรหยุดทำงานหรือเกิดความขัดข้อง, สีเหลือง (YELLOW) แสดงว่าเครื่องอยู่ในโหมดเตรียมพร้อมหรือรอคำสั่ง และ สีเขียว (GREEN) หมายถึงเครื่องกำลังทำงานตามปกติ ส่วน เสียงเตือน (BUZZER) จะทำงานเมื่อเกิดเหตุฉุกเฉินหรือเพื่อแจ้งเตือนผู้ปฏิบัติงาน Tower Lamp จะต่อกับแหล่งจ่ายไฟ VCC (+24VDC) และ GND โดยแต่ละสีจะต่อผ่านขา Output ของ PLC ซึ่งสามารถสั่งเปิดหรือปิดได้ตามเงื่อนไขที่ตั้งไว้ในโปรแกรม Ladder Diagram การทำงานนี้ช่วยให้ผู้ปฏิบัติงานสามารถทราบสถานะของเครื่องจักรได้อย่างรวดเร็วและปลอดภัย ทำให้การตรวจสอบและบำรุงรักษาเป็นไปอย่างมีประสิทธิภาพ ทั้งยังเป็นองค์ประกอบสำคัญของระบบควบคุมอัตโนมัติในแนวคิด Smart Factory ตามมาตรฐานอุตสาหกรรม 4.0

![ภาพที่ 8.10 โปรแกรม Ladder Diagram ควบคุม Tower Lamp และเสียงเตือน (Buzzer) ด้วย PLC](/images/book/image126.png)

ภาพนี้แสดงตัวอย่างการเขียนโปรแกรม Ladder Diagram สำหรับการควบคุม Tower Lamp แบบ 3 สี และเสียงเตือน (Buzzer) โดยใช้คำสั่งพื้นฐานของ PLC Mitsubishi GX Works3 เพื่อแสดงสถานะของเครื่องจักรในระบบอัตโนมัติ โปรแกรมนี้แบ่งการทำงานออกเป็นหลายเงื่อนไข โดยในแต่ละบรรทัดจะสั่งให้ไฟแต่ละสีทำงานตามสถานะของระบบ เช่น เมื่อเกิดสัญญาณ ERROR โปรแกรมจะสั่งให้ ไฟสีแดง (LAMP_RED) ทำงานเพื่อแจ้งเตือนว่าระบบเกิดข้อขัดข้องหรือเครื่องจักรหยุดทำงาน, เมื่อเกิดสถานะ WARNING จะสั่งให้ ไฟสีส้ม (LAMP_ORANGE) ทำงานเพื่อแสดงว่าเครื่องจักรอยู่ในภาวะเตือนหรือรอการตรวจสอบ, และเมื่อสถานะเป็น READY จะเปิด ไฟสีเขียว (LAMP_GREEN) เพื่อแสดงว่าเครื่องจักรพร้อมทำงานตามปกติ นอกจากนี้ยังมีการควบคุม เสียงเตือน (BUZZER) ให้ทำงานเมื่อเกิดสัญญาณ ERROR หรือ WARNING พร้อมกัน เพื่อเพิ่มความชัดเจนในการแจ้งเตือนแก่ผู้ปฏิบัติงาน โปรแกรมนี้เป็นตัวอย่างของการประยุกต์ใช้ PLC ในการควบคุมระบบแสดงสถานะของเครื่องจักรแบบอัตโนมัติ ซึ่งช่วยให้ผู้ควบคุมสามารถรับรู้สถานะการทำงานได้อย่างรวดเร็ว เพิ่มความปลอดภัย ลดความผิดพลาดในการทำงาน และยกระดับประสิทธิภาพของกระบวนการผลิตในแนวคิด Smart Factory ตามมาตรฐานอุตสาหกรรม 4.0

## 8.7 Relay

รีเลย์ทำงานโดยอาศัยหลักการของ แม่เหล็กไฟฟ้า (Electromagnetic Principle) ภายในตัวรีเลย์จะประกอบด้วยขดลวดแม่เหล็ก (Coil), แกนเหล็ก (Core), และหน้าสัมผัส (Contact) เมื่อขดลวดได้รับกระแสไฟฟ้า จะเกิดแรงแม่เหล็กดึงให้หน้าสัมผัสเปลี่ยนสถานะ เช่น จากเปิด (NO: Normally Open) เป็นปิด หรือจากปิด (NC: Normally Closed) เป็นเปิด ซึ่งสามารถใช้สั่งการให้อุปกรณ์ภายนอกทำงานได้ ตัวอย่างเช่น เมื่อ PLC ส่งสัญญาณออกจากขา Output ไปยังขดลวดของรีเลย์ หน้าสัมผัสจะเปลี่ยนสถานะและต่อวงจรให้ มอเตอร์ หรือ หลอดไฟ ทำงานตามต้องการ

รีเลย์สามารถแบ่งได้หลายประเภท เช่น Electromagnetic Relay (EMR) ใช้แรงแม่เหล็กในการเปลี่ยนสถานะหน้าสัมผัส เหมาะสำหรับงานทั่วไป

การต่อใช้งานกับ PLC ในระบบควบคุมอัตโนมัติ รีเลย์มักถูกต่อเข้ากับขา Output ของ PLC โดยใช้แรงดัน 24VDC สำหรับขดลวด และให้หน้าสัมผัสควบคุมวงจรภายนอก เช่น การจ่ายไฟให้มอเตอร์หรือหลอดไฟ 220VAC การต่อแบบนี้ช่วยให้ PLC สามารถควบคุมอุปกรณ์กำลังได้โดยไม่ต้องรับโหลดไฟฟ้าโดยตรง เพิ่มอายุการใช้งานของ PLC และลดความเสียหายที่อาจเกิดจากไฟฟ้ากระชาก

## 8.8 DC Motor

มอเตอร์กระแสตรง (DC Motor) เป็นอุปกรณ์ขับเคลื่อนพื้นฐานที่ใช้พลังงานไฟฟ้ากระแสตรงในการเปลี่ยนเป็นพลังงานกล โดยสามารถควบคุมความเร็วและทิศทางการหมุนได้อย่างง่ายและแม่นยำ มอเตอร์ชนิดนี้จึงถูกนำมาใช้อย่างแพร่หลายในระบบอัตโนมัติ เช่น ระบบสายพานลำเลียง, แขนกล, ประตูอัตโนมัติ และหุ่นยนต์เคลื่อนที่ การใช้ PLC (Programmable Logic Controller) ในการควบคุม DC Motor ทำให้สามารถตั้งโปรแกรมให้มอเตอร์ทำงานได้ตามเงื่อนไขที่กำหนด เช่น การหมุนไป-กลับ การปรับความเร็ว หรือการหยุดเมื่อมีสัญญาณจากเซนเซอร์ ซึ่งเป็นพื้นฐานสำคัญของงาน เมคคาทรอนิกส์ (Mechatronics System)

![ภาพที่ 8.11 โครงสร้างภายในของมอเตอร์กระแสตรง (DC Motor Construction Parts)](/images/book/image127.jpg)

ภาพนี้แสดงส่วนประกอบหลักภายในของมอเตอร์กระแสตรง (DC Motor) ซึ่งประกอบด้วยชิ้นส่วนสำคัญ ได้แก่

1\. Field Winding ขดลวดสนามแม่เหล็ก ทำหน้าที่สร้างสนามแม่เหล็กหลักภายในมอเตอร์

2\. Pole Shoe ส่วนขยายของขั้วแม่เหล็ก ช่วยกระจายสนามแม่เหล็กให้สม่ำเสมอ

3\. Yoke or Frame โครงสร้างภายนอกที่รองรับชิ้นส่วนทั้งหมดและทำหน้าที่เป็นทางเดินของฟลักซ์แม่เหล็ก

4 .Armature Conductors ขดลวดที่อยู่บนโรเตอร์ ทำหน้าที่รับกระแสไฟฟ้าและสร้างแรงบิดให้เกิดการหมุน

5\. Commutator ตัวสวิตช์กลที่ทำหน้าที่กลับทิศทางกระแสในขดลวดอาร์มาเจอร์เพื่อให้มอเตอร์หมุนต่อเนื่องในทิศทางเดียว

สนามแม่เหล็กที่เกิดจากกระแสไฟในขดลวดจะทำปฏิกิริยากับสนามแม่เหล็กของสเตเตอร์ เกิดแรงบิด (Torque) ทำให้โรเตอร์หมุน การควบคุมทิศทางการหมุนสามารถทำได้โดยการกลับขั้วแรงดัน (Reversing Polarity) ประเภทของ DC Motor ที่นิยมใช้งาน ได้แก่

1\. Permanent Magnet DC Motor (PMDC) ใช้แม่เหล็กถาวร เหมาะกับงานทั่วไป เช่น พัดลม หรือหุ่นยนต์ขนาดเล็ก

2\. Shunt DC Motor มีการต่อขนานระหว่างขดลวดสนามกับขดลวดอาร์มาเจอร์ ให้ความเร็วคงที่ เหมาะกับงานที่ต้องการความเสถียร

3\. Series DC Motor มีแรงบิดเริ่มต้นสูง เหมาะสำหรับงานขับโหลดหนัก เช่น เครื่องยกหรือระบบลำเลียง

4\. Compound DC Motor: รวมข้อดีของแบบ Shunt และ Series เข้าด้วยกัน

มอเตอร์กระแสตรงประกอบด้วยส่วนสนามแม่เหล็ก (Field System) และส่วนอาร์มาเจอร์ (Armature System) ที่ทำงานร่วมกันในการเปลี่ยนพลังงานไฟฟ้าให้เป็นพลังงานกล การทำงานของแต่ละส่วนมีความสัมพันธ์กันอย่างใกล้ชิดเพื่อให้มอเตอร์หมุนได้อย่างต่อเนื่องและมีแรงบิดที่สม่ำเสมอ การเข้าใจโครงสร้างภายในนี้จึงเป็นพื้นฐานสำคัญในการเรียนรู้การควบคุม DC Motor ด้วย PLC และการประยุกต์ใช้ในงานระบบอัตโนมัติอุตสาหกรรม

การควบคุม DC Motor ด้วย PLC จะส่งสัญญาณควบคุมออกทางขา Output (เช่น Y0, Y1) ไปยังวงจรขับ เช่น Relay, Transistor, หรือ H-Bridge Driver (เช่น L298N, BTS7960) เพื่อสั่งให้มอเตอร์หมุนไปข้างหน้า (Forward) หรือย้อนกลับ (Reverse) การเขียนโปรแกรมสามารถใช้เงื่อนไขจาก Input (เช่น Sensor, Switch) เพื่อให้มอเตอร์หมุนในทิศทางที่ต้องการ และหยุดเมื่อถึงตำแหน่งที่กำหนด เช่น การใช้คำสั่ง SET / RESET หรือ OUT ใน GX Works3 ของ Mitsubishi เพื่อสั่งเปิด-ปิดมอเตอร์ตามลำดับการทำงาน

![ภาพที่ 8.12 การต่อวงจรควบคุมมอเตอร์กระแสตรงแบบหมุนไป–กลับ ด้วย PLC Mitsubishi](/images/book/image128.jpg)

ภาพนี้แสดงการเชื่อมต่อวงจรควบคุม DC Motor โดยใช้ PLC Mitsubishi รุ่น FX5U-24MT/ES ทำหน้าที่ควบคุมการหมุนไปข้างหน้าและหมุนย้อนกลับของมอเตอร์ โดยใช้ รีเลย์ (Relay) 2 ตัว เป็นอุปกรณ์สั่งงานทิศทางการหมุนของมอเตอร์ผ่านสัญญาณจากขา Output ของ PLC ได้แก่

> Y0 ใช้ควบคุมรีเลย์สำหรับการหมุนไปข้างหน้า (Forward)
>
> Y1 ใช้ควบคุมรีเลย์สำหรับการหมุนย้อนกลับ (Reverse)

ขา Input (เช่น X0, X1, X2) เชื่อมต่อกับสวิตช์สั่งงาน เช่น ปุ่ม Start, Stop, และ Reverse ส่วนวงจรไฟฟ้า 24VDC จะเป็นแหล่งจ่ายพลังงานให้กับรีเลย์และมอเตอร์ การทำงานของรีเลย์ทั้งสองถูกออกแบบให้ไม่สามารถทำงานพร้อมกันได้ เพื่อป้องกันการลัดวงจรและความเสียหายของมอเตอร์

![ภาพที่ 8.13 โปรแกรมแลดเดอร์ไดอะแกรมควบคุมการหมุนไป–กลับของมอเตอร์กระแสตรง](/images/book/image129.jpg)

ภาพนี้แสดงตัวอย่างโปรแกรมในซอฟต์แวร์ GX Works3 สำหรับเขียนแลดเดอร์ไดอะแกรมควบคุมมอเตอร์กระแสตรง (DC Motor) แบบหมุนไปข้างหน้า (CW – Clockwise) และหมุนย้อนกลับ (CCW – Counter Clockwise) โดยใช้ PLC Mitsubishi FX5U

X1 เป็นอินพุตจากปุ่มสั่งหมุนไปข้างหน้า (SW FWD)

X2 เป็นอินพุตจากปุ่มสั่งหมุนย้อนกลับ (SW REV)

Y6 เป็นเอาต์พุตควบคุมรีเลย์หรือไดรเวอร์สำหรับหมุนมอเตอร์ไปข้างหน้า (CW)

Y7 เป็นเอาต์พุตควบคุมการหมุนย้อนกลับ (CCW)

เมื่อกดปุ่ม SW1 (X1) โปรแกรมจะสั่งให้ขา Y6 ทำงาน ส่งผลให้มอเตอร์หมุนไปข้างหน้า

เมื่อกดปุ่ม SW2 (X2) โปรแกรมจะสั่งให้ขา Y7 ทำงาน ส่งผลให้มอเตอร์หมุนย้อนกลับและเมื่อปล่อยปุ่ม มอเตอร์จะหยุดการทำงานทันที

## 8.9 Stepper Motor

สเต็ปเปอร์มอเตอร์ (Stepper Motor) เป็นมอเตอร์ไฟฟ้าที่สามารถหมุนเป็น “จังหวะ” หรือ “ขั้น” ตามจำนวนพัลส์สัญญาณไฟฟ้าที่ส่งเข้ามา ซึ่งเหมาะสำหรับการควบคุมการเคลื่อนที่ที่ต้องการความแม่นยำ เช่น การควบคุมแขนกล, ระบบลำเลียง, เครื่อง CNC และเครื่องพิมพ์ 3 มิติ การใช้ PLC (Programmable Logic Controller) ร่วมกับสเต็ปเปอร์มอเตอร์ทำให้สามารถควบคุมทิศทาง ความเร็ว และจำนวนรอบได้อย่างแม่นยำ โดยไม่ต้องใช้วงจรควบคุมซับซ้อนมากนัก ถือเป็นหนึ่งในระบบที่สำคัญในงาน เมคคาทรอนิกส์ (Mechatronics) และ อัตโนมัติอุตสาหกรรม (Industrial Automation)

สเต็ปเปอร์มอเตอร์ทำงานโดยการแปลงพัลส์ไฟฟ้าให้เป็นการหมุนเชิงกล โดยทุกพัลส์ที่ส่งเข้ามาจะทำให้มอเตอร์หมุนไปทีละ “สเต็ป” มุมการหมุนต่อสเต็ปมักอยู่ในช่วง 0.9° ถึง 1.8° ขึ้นอยู่กับชนิดของมอเตอร์ประเภทของ Stepper Motor ที่นิยมใช้งาน ได้แก่ Permanent Magnet Stepper (PM Stepper): ใช้แม่เหล็กถาวรในการสร้างแรงบิด หมุนทีละสเต็ป เหมาะกับงานทั่วไป Variable Reluctance Stepper (VR Stepper) ใช้หลักการดูดแม่เหล็กเพื่อให้โรเตอร์หมุนตามตำแหน่ง สนองไว แต่แรงบิดต่ำ Hybrid Stepper รวมข้อดีของ PM และ VR เข้าด้วยกัน มีความละเอียดสูงและแรงบิดมาก เหมาะกับงานอุตสาหกรรม

![ภาพที่ 8.14 ลำดับการทำงานของระบบควบคุมสเต็ปปิ้งมอเตอร์](/images/book/image130.png)

ภาพนี้แสดงลำดับการทำงานของระบบขับเคลื่อนสเต็ปปิ้งมอเตอร์ ซึ่งประกอบด้วย 3 ส่วนหลัก ได้แก่ ตัวกำเนิดสัญญาณควบคุม (Controller) ทำหน้าที่สร้างสัญญาณพัลส์ (Pulse Signal) และทิศทาง (Direction Signal) เพื่อกำหนดจำนวนสเต็ปและทิศทางการหมุนของมอเตอร์ ไดรฟ์ขับสเต็ปปิ้งมอเตอร์ (Stepping Motor Drive) รับสัญญาณจาก Controller และแปลงเป็นกระแสไฟฟ้าสำหรับขับขดลวดภายในมอเตอร์ โดยจะกำหนดลำดับการจ่ายไฟให้แต่ละขดลวดเพื่อสร้างแรงหมุน สเต็ปปิ้งมอเตอร์ (Stepper Motor) ทำหน้าที่เปลี่ยนพลังงานไฟฟ้าให้เป็นการเคลื่อนที่เชิงกล โดยจะหมุนทีละ ขั้นตามจำนวนพัลส์ที่ได้รับ

การควบคุมลักษณะนี้ช่วยให้สามารถกำหนดตำแหน่งมุมหมุนได้อย่างแม่นยำโดยไม่ต้องใช้ตัวเข้ารหัส (Encoder) ซึ่งเหมาะกับงานที่ต้องการการเคลื่อนที่เป็นจังหวะ เช่น แขนกล หุ่นยนต์ เครื่องพิมพ์ 3D หรือระบบลำเลียงที่ต้องการความละเอียดสูง

ในระบบควบคุมมอเตอร์แบบสเต็ป (Stepper Motor Control) การใช้ Microstep Driver เป็นส่วนสำคัญในการควบคุมทิศทางและความละเอียดของการหมุน โดยเฉพาะในงานที่ต้องการความแม่นยำสูง เช่น ระบบหุ่นยนต์ เครื่อง CNC หรือเครื่องพิมพ์ 3D เนื่องจาก Microstep Driver สามารถแบ่งการหมุนของมอเตอร์ให้ละเอียดขึ้นเป็นหลายส่วน (Subdivision) ต่อการหมุนหนึ่งรอบ จึงช่วยให้มอเตอร์หมุนได้อย่างนุ่มนวลและแม่นยำมากขึ้น

![ภาพที่ 8.15 การตั้งค่าและการต่อใช้งาน Microstep Driver กับ Stepper Motor](/images/book/image131.jpg)

ภาพนี้แสดงตัวอย่างของการ ตั้งค่า DIP Switch และการต่อวงจรระหว่าง Microstep Driver กับ Stepper Motor รุ่น TB6600 ซึ่งเป็นไดรฟ์ยอดนิยมที่ใช้กับมอเตอร์สเต็ป 2 เฟส เช่นรุ่น 17HS3401 โดยมีรายละเอียดสำคัญดังนี้

1.  การตั้งค่า DIP Switch (SW1–SW6) SW1–SW3 ใช้กำหนดจำนวนพัลส์ต่อรอบ (Subdivision) เช่น 400, 800, 1600, 3200 pulse/rev และ SW4–SW6 ใช้กำหนดกระแสที่จ่ายให้มอเตอร์ เช่น 1.0A, 1.5A, 2.0A เป็นต้น

2.  การต่อสายสัญญาณควบคุม (Control Signal):

- PUL+ / PUL− : สัญญาณพัลส์ควบคุมจำนวนก้าว (Step Signal)

- DIR+ / DIR− : สัญญาณควบคุมทิศทางการหมุน (Direction Signal)

- ENA+ / ENA− : สัญญาณเปิด/ปิดการทำงานของมอเตอร์ (Enable Signal)

3.  การต่อสายไฟมอเตอร์ (Motor Interface):

- ขั้ว A+, A−, B+, B− เชื่อมต่อกับขดลวดของ Stepper Motor

- แหล่งจ่ายไฟ DC 9–42V ใช้เป็นไฟเลี้ยงสำหรับการขับมอเตอร์

4.  ข้อมูลจำเพาะของ Stepper Motor รุ่น 17HS3401:

- มุมหมุนต่อสเต็ป (Step Angle): 1.8° ± 0.09°

- แรงบิดถือครอง (Holding Torque): ≥ 29 N·cm

- กระแสใช้งานต่อเฟส: 1 A/Phase

- ความต้านทานขดลวด: 3.4 Ohm/Phase

- ใช้การหมุนลำดับสัญญาณ A–AB–B ตามทิศทาง Clockwise

Microstep Driver มีบทบาทสำคัญในการควบคุมการหมุนของ Stepper Motor ผ่านการกำหนดพัลส์และทิศทางการหมุนที่ส่งมาจากคอนโทรลเลอร์ (เช่น PLC หรือไมโครคอนโทรลเลอร์) การตั้งค่าที่ถูกต้องของ DIP Switch และการต่อสายสัญญาณอย่างเหมาะสม จะช่วยให้ระบบทำงานได้อย่างมีประสิทธิภาพ มอเตอร์หมุนได้อย่างแม่นยำตามจำนวนสเต็ปที่กำหนด และสามารถนำไปประยุกต์ใช้ในระบบอัตโนมัติที่ต้องการความละเอียดสูง เช่น แขนกลอุตสาหกรรม หรือระบบขนส่งอัจฉริยะ

![ภาพที่ 8.16 การต่อใช้งาน Stepper Motor Driver รุ่น TB6600 เข้ากับ PLC Mitsubishi](/images/book/image132.png)

ภาพนี้แสดงการต่อวงจรระหว่าง PLC Mitsubishi กับ Stepper Motor Driver รุ่น TB6600 และ Stepper Motor 4 สาย โดยมีรายละเอียดดังนี้

1.  การเชื่อมต่อสัญญาณควบคุมจาก PLC เข้าสู่ TB6600 Driver

- Y0 → PUL+ / PUL− ส่งสัญญาณพัลส์ควบคุมจำนวนสเต็ป (Step Signal)

- Y1 → DIR+ / DIR− ส่งสัญญาณควบคุมทิศทางการหมุน (Direction Signal)

- Y2 → ENA+ / ENA− สัญญาณเปิด/ปิดการทำงานของมอเตอร์ (Enable Signal)

โดยสัญญาณทั้งหมดเป็นแบบ 24VDC ซึ่งเป็นแรงดันมาตรฐานของ PLC Mitsubishi

2.  การต่อสายระหว่าง TB6600 กับ Stepper Motor

- ขั้ว A+ และ A− เชื่อมกับขดลวดเฟส A ของมอเตอร์

- ขั้ว B+ และ B− เชื่อมกับขดลวดเฟส B ของมอเตอร์

โดยมอเตอร์ 4 สายทั่วไปจะมีการแยกเฟส A และ B อย่างชัดเจนตามสีสาย เช่น

- A+ = แดง, A− = น้ำเงิน

- B+ = เขียว, B− = ดำ

3.  การจ่ายไฟเลี้ยง (Power Supply):

- ใช้แรงดัน 24VDC ต่อเข้าขั้ว VCC และ GND ของไดรฟ์

- GND เชื่อมต่อร่วมกับระบบ PLC เพื่อให้สัญญาณกราวด์ตรงกัน

การควบคุม Stepper Motor ด้วย PLC

PLC จะส่งพัลส์ควบคุมจากขา Output (เช่น Y0, Y1) ไปยัง Driver ของ Stepper Motor ซึ่ง Driver จะทำหน้าที่แปลงสัญญาณพัลส์ให้เป็นกระแสไฟฟ้าในขดลวดของมอเตอร์ การเขียนโปรแกรมสามารถกำหนดได้ทั้งจำนวนสเต็ป (ระยะทางการหมุน), ทิศทางการหมุน (CW/CCW) และความเร็ว (ผ่านความถี่ของพัลส์) ตัวอย่างเช่น การควบคุม Stepper Motor ให้หมุน 360° อาจต้องการ 200 พัลส์ หากมอเตอร์มี 1.8° ต่อสเต็ป โดย PLC สามารถใช้คำสั่ง PLSY, PULS, DRVI, DRVA หรือ SPED (ใน Mitsubishi PLC) เพื่อสั่งการได้โดยตรง

![ภาพที่ 8.17 ตัวอย่างโปรแกรมควบคุม Stepper Motor ด้วยคำสั่ง PLSY ใน GX Works2](/images/book/image133.jpg)

จากภาพแสดงตัวอย่างการเขียน Ladder Diagram สำหรับสั่งให้มอเตอร์หมุนเมื่อกดปุ่มเริ่ม (X000) และหยุดเมื่อกดปุ่มหยุด (X001) โดยใช้คำสั่ง PLSY K4000 K3600 Y000 ซึ่งมีความหมายดังนี้

PLSY คำสั่งส่งพัลส์ออกทางขา Output

K4000 ความถี่ของสัญญาณพัลส์ (หน่วย Hz) ซึ่งส่งผลต่อความเร็วในการหมุนของมอเตอร์

K3600 จำนวนพัลส์ทั้งหมดที่จะส่งออก (หน่วยเป็นพัลส์) ซึ่งส่งผลต่อมุมการหมุนของมอเตอร์

Y000 ขา Output ของ PLC ที่ใช้ส่งสัญญาณพัลส์ไปยังขา PUL ของ Stepper Driver

หลักการทำงานของโปรแกรม

1\. เมื่อกด ปุ่มเริ่ม (X000) และไม่กด ปุ่มหยุด (X001) → PLC จะ SET M1 เพื่อเริ่มการส่งพัลส์

2\. เมื่อ M1 ถูกตั้งค่า (ON) → คำสั่ง PLSY จะเริ่มส่งพัลส์จำนวน 3600 พัลส์ที่ความถี่ 4000Hz ออกทางขา Y000

3\. หากกด ปุ่มหยุด (X001) ระบบจะ RST M1 เพื่อยกเลิกการส่งพัลส์และหยุดการหมุนของมอเตอร์

จากตัวอย่างนี้แสดงให้เห็นถึงการใช้ คำสั่ง PLSY ใน GX Works2 เพื่อควบคุม Stepper Motor แบบง่าย โดย PLC จะทำหน้าที่ส่งสัญญาณพัลส์ให้กับ Stepper Driver เพื่อขับมอเตอร์หมุนตามจำนวนรอบและความเร็วที่กำหนด ซึ่งเป็นพื้นฐานสำคัญของการควบคุมตำแหน่งและการเคลื่อนไหวในระบบอัตโนมัติ เช่น แขนกล หุ่นยนต์ และเครื่องจักรบรรจุภัณฑ์อัจฉริยะ

## 8.10 Servo Motor

ระบบอัตโนมัติทางอุตสาหกรรมที่ต้องการการควบคุมตำแหน่ง ความเร็ว และแรงบิดอย่างแม่นยำ เช่น หุ่นยนต์อุตสาหกรรม เครื่อง CNC เครื่องบรรจุภัณฑ์ และแขนกล (Manipulator Arm) — การใช้ Servo Motor (เซอร์โวมอเตอร์) ถือเป็นหัวใจหลักของระบบขับเคลื่อนความแม่นยำสูง (Precision Motion Control System)

Servo Motor แตกต่างจาก DC Motor หรือ Stepper Motor ทั่วไป เพราะมี ระบบป้อนกลับ (Feedback System) เช่น Encoder หรือ Resolver ที่ส่งสัญญาณกลับมาบอกตำแหน่งและความเร็วของเพลามอเตอร์ ทำให้คอนโทรลเลอร์หรือ PLC สามารถปรับแก้สัญญาณควบคุมแบบเรียลไทม์ เพื่อให้มอเตอร์ทำงานได้ตามตำแหน่งหรือความเร็วที่ตั้งไว้โดยไม่เกิดความคลาดเคลื่อน โดยมีส่วนหลักดังต่อไปนี้

1\. หลักการทำงานของ Servo Motor

Servo Motor ทำงานโดยใช้ วงจรควบคุมแบบปิด (Closed-loop Control System) ประกอบด้วย 3 ส่วนหลัก ได้แก่

- ส่วนกำเนิดสัญญาณควบคุม (Controller): เช่น PLC หรือ Motion Controller ทำหน้าที่ส่งคำสั่งให้ Servo Driver

- ส่วนขับกำลัง (Servo Driver): รับคำสั่งจาก Controller แล้วจ่ายกระแสและแรงดันที่เหมาะสมให้กับ Servo Motor

- ส่วนมอเตอร์ (Servo Motor): แปลงพลังงานไฟฟ้าเป็นพลังงานกล เพื่อขับเคลื่อนอุปกรณ์

- ส่วนป้อนกลับ (Feedback Device): เช่น Encoder ตรวจสอบตำแหน่งจริงของเพลา แล้วส่งกลับไปยัง Driver เพื่อเปรียบเทียบกับค่าที่ต้องการ

2\. ระบบ Feedback และการควบคุมแบบ Closed-loop

ระบบ Feedback ทำให้ Servo Motor สามารถปรับความเร็วและตำแหน่งให้ตรงกับค่าที่ต้องการได้เสมอ ตัวอย่างการทำงานคือ

- หากมอเตอร์หมุนไม่ถึงตำแหน่งที่ตั้งไว้ (เกิด Error)

- Encoder จะส่งสัญญาณกลับไปยัง Driver

- Driver จะเพิ่มกระแสให้มอเตอร์หมุนต่อจนถึงตำแหน่งเป้าหมาย

ดังนั้น Servo System จึงมี ความแม่นยำสูง, ตอบสนองเร็ว, และ ป้องกันข้อผิดพลาดของตำแหน่ง (Position Error) ได้ดีกว่า Stepper Motor

3\. ประเภทของ Servo Motor

- AC Servo Motor: ใช้ไฟฟ้ากระแสสลับ นิยมในอุตสาหกรรมสมัยใหม่ เนื่องจากมีแรงบิดสูงและควบคุมได้แม่นยำ

- DC Servo Motor: ใช้ไฟฟ้ากระแสตรง เหมาะกับงานขนาดเล็ก เช่น หุ่นยนต์หรือระบบต้นแบบทางการศึกษา

4\. ตัวอย่างการนำไปใช้ในงานอุตสาหกรรม

- ควบคุมการหมุนของแขนกลให้แม่นยำตามองศาที่กำหนด

- ระบบบรรจุภัณฑ์ที่ต้องหยุดในตำแหน่งคงที่ทุกครั้ง

- เครื่อง CNC ที่ต้องการความละเอียดสูงในระดับไมโครเมตร

Servo Motor เป็นอุปกรณ์ขับเคลื่อนที่มีความสำคัญอย่างยิ่งในระบบอัตโนมัติยุคอุตสาหกรรม 4.0 เพราะสามารถควบคุม ตำแหน่ง (Position), ความเร็ว (Speed) และ แรงบิด (Torque) ได้อย่างแม่นยำและตอบสนองรวดเร็วกว่า Stepper หรือ DC Motor ทั่วไป โดยหัวใจของ Servo System อยู่ที่ วงจรควบคุมแบบปิด (Closed-loop Control System) ซึ่งใช้การเปรียบเทียบระหว่างตำแหน่งที่สั่ง (Command Position) กับตำแหน่งจริง (Actual Position) ผ่าน อุปกรณ์ Feedback เช่น Encoder หรือ Resolver เมื่อมีความคลาดเคลื่อนเกิดขึ้นในตำแหน่งหรือความเร็วของมอเตอร์ ระบบจะทำการปรับค่ากระแสและแรงดันให้เหมาะสมโดยอัตโนมัติ เพื่อให้มอเตอร์กลับไปยังค่าที่ต้องการได้อย่างถูกต้องและรวดเร็ว จึงทำให้ Servo Motor มี ความแม่นยำสูง, การตอบสนองทันที (Real-time Response) และสามารถทำงานซ้ำในตำแหน่งเดิมได้โดยไม่ผิดพลาด

Servo Motor ยังสามารถทำงานร่วมกับ PLC (Programmable Logic Controller) ได้อย่างสมบูรณ์ โดย PLC จะทำหน้าที่ส่งสัญญาณควบคุม เช่น การเริ่มหมุน การกำหนดทิศทาง และความเร็ว ไปยัง Servo Driver ซึ่งจะตีความสัญญาณเหล่านี้และสั่งการมอเตอร์ให้หมุนตามโปรแกรมที่กำหนดไว้ ในเชิงอุตสาหกรรม Servo Motor ถูกนำไปใช้อย่างแพร่หลาย เช่น

- ระบบแขนกล (Robotic Arm) ที่ต้องเคลื่อนไหวในตำแหน่งที่แม่นยำ

- เครื่อง CNC ที่ต้องควบคุมตำแหน่งหัวตัดด้วยความละเอียดระดับไมโครเมตร

- ระบบบรรจุภัณฑ์อัตโนมัติ (Automatic Packaging) ที่ต้องการการหยุดและเริ่มการทำงานในจุดเดิมซ้ำๆ อย่างคงที่

- เครื่องจักรประกอบชิ้นส่วนที่ต้องหมุนหรือยกชิ้นงานในตำแหน่งแน่นอน

โดยสรุปแล้ว Servo Motor คือมอเตอร์ที่ผสานความแม่นยำ ความเร็ว และความเสถียรในการควบคุมการเคลื่อนไหว เหมาะสำหรับงานอัตโนมัติที่ต้องการประสิทธิภาพสูง การนำ Servo Motor มาใช้งานร่วมกับ PLC จึงถือเป็นเทคโนโลยีสำคัญที่ผลักดันให้ระบบเครื่องจักรกลในโรงงานอัจฉริยะ (Smart Factory) มีความแม่นยำ ประหยัดพลังงาน และตอบสนองต่อการผลิตแบบเรียลไทม์ได้ดียิ่งขึ้น

![ภาพที่ 8.18 ชุดมอเตอร์เซอร์โวและไดรฟ์ของ Mitsubishi สำหรับระบบควบคุมอัตโนมัติ](/images/book/image134.png)

ภาพนี้แสดงชุดอุปกรณ์ Servo Motor และ Servo Drive ซึ่งเป็นหัวใจหลักของระบบควบคุมการเคลื่อนไหว (Motion Control System) ที่ต้องการความแม่นยำสูงในอุตสาหกรรมสมัยใหม่ โดยอุปกรณ์ในภาพเป็นผลิตภัณฑ์ของ Mitsubishi Electric ซึ่งได้รับการออกแบบให้สามารถเชื่อมต่อกับ PLC ได้โดยตรง รองรับการควบคุมแบบ Position, Speed และ Torque Control

![ภาพที่ 8.19 การต่อใช้งาน Mitsubishi Servo Driver กับ PLC ควบคุมการทำงานของ Servo Motor](/images/book/image135.png)

ภาพนี้แสดงตัวอย่างการเชื่อมต่อระหว่าง PLC กับ Servo Driver รุ่น MR-J4 ของ Mitsubishi Electric ซึ่งเป็นระบบขับเคลื่อนที่ได้รับความนิยมสูงในงานอุตสาหกรรมอัตโนมัติ เช่น ระบบแขนกล เครื่องจักร CNC หรือระบบขนส่งอัตโนมัติ โดย PLC ทำหน้าที่เป็นตัวควบคุมคำสั่งหลัก ส่วน Servo Driver ทำหน้าที่ขับสัญญาณไฟฟ้าไปยัง Servo Motor ให้หมุนตามตำแหน่งหรือความเร็วที่กำหนด พร้อมระบบ Feedback ที่ตรวจสอบตำแหน่งจริงของมอเตอร์เพื่อความแม่นยำสูงสุด โดยมีการเชื่อมต่อสายสัญญาณและสายไฟหลักดังนี้

1\. สายไฟ DC 24V (สีแดง) จ่ายแรงดันไฟให้กับ PLC และ Servo Driver

2\. ขั้วสัญญาณควบคุมจาก PLC ส่งคำสั่งสัญญาณ เช่น Pulse (สัญญาณพัลส์ควบคุมตำแหน่ง) และ Direction (ทิศทางการหมุน) เข้าสู่ Servo Driver

3\. ขั้ว U, V, W เป็นขั้วจ่ายกำลังไฟฟ้ากระแสสลับไปยังมอเตอร์เซอร์โว

4\. ขั้ว Encoder Feedback รับสัญญาณตำแหน่งกลับจากมอเตอร์มายัง Driver เพื่อให้ระบบสามารถเปรียบเทียบและแก้ไขความคลาดเคลื่อน

5\. สายสีน้ำตาล/ฟ้า/เหลือง แสดงการต่อสัญญาณควบคุม เช่น Enable, Pulse, Direction ที่เชื่อมตรงจาก PLC มายัง Driver

การต่อวงจรลักษณะนี้ช่วยให้ PLC สามารถควบคุม Servo Motor ได้ทั้งการหมุนไปข้างหน้า (CW), หมุนย้อนกลับ (CCW), หยุด, และการควบคุมตำแหน่งแบบละเอียดด้วยคำสั่ง Motion Control

![ภาพที่ 8.20 การเชื่อมต่อ PLC Mitsubishi FX5U เข้ากับ Servo Amplifier ผ่านบอร์ด MR-TB50](/images/book/image136.jpg)

ภาพนี้แสดงให้เห็นถึง การทำงานร่วมกันของ PLC กับ Servo Amplifier ผ่านบอร์ด MR-TB50 ซึ่งเป็นการเชื่อมต่อที่ครบวงจรทั้งการควบคุมคำสั่งและการตรวจสอบสถานะระบบ การออกแบบลักษณะนี้ช่วยให้การติดตั้งเป็นระเบียบ เข้าใจง่าย และสามารถตรวจสอบสัญญาณได้สะดวก โดย PLC จะควบคุมทิศทาง ความเร็ว และตำแหน่งของ Servo Motor ในขณะที่ Servo Amplifier จะตอบสนองด้วยความแม่นยำและความเสถียรสูง เหมาะสำหรับการใช้งานในโรงงานอัตโนมัติที่ต้องการประสิทธิภาพและความปลอดภัยระดับอุตสาหกรรม โดยมีรายละเอียดการเชื่อมต่อระหว่าง PLC และ Servo Amplifier ดังนี้

1\. ส่วนบนของภาพ (MR-TB50) เป็นบอร์ดเทอร์มินัลสำหรับเชื่อมสัญญาณระหว่าง Servo Amplifier กับอุปกรณ์ควบคุมอื่น เช่น PLC, สวิตช์ หรือระบบ Alarm

2\. PLC ตัวบน ทำหน้าที่รับสัญญาณสถานะจาก Servo เช่น Alarm (ALM) และ Emergency Stop (EMG) ผ่านอินพุตที่กำหนดไว้

3\. PLC ตัวล่าง เป็นชุดควบคุมหลักสำหรับส่งสัญญาณคำสั่งไปยัง Servo Amplifier เช่น

\- Y0 / Y3 / Y6 ใช้สำหรับส่งสัญญาณ Pulse และ Direction เพื่อควบคุมการหมุนของมอเตอร์

\- COM0 / COM1 / COM2 เป็นจุดรวมสัญญาณกราวด์ของแต่ละชุดคำสั่ง

4\. เส้นสีแดง: เป็นสายไฟแรงดัน DC 24V ใช้จ่ายไฟให้กับวงจรควบคุมและ Servo

5\. เส้นสีน้ำเงินและเหลือง: เป็นสายสัญญาณควบคุมระหว่าง PLC และ Servo Driver สำหรับการสั่งการและรับสถานะกลับ

ระบบนี้ช่วยให้ PLC สามารถควบคุมการหมุน การหยุด และตรวจจับความผิดปกติของ Servo Motor ได้โดยตรง ทำให้เหมาะสำหรับการใช้งานที่ต้องการความเที่ยงตรงสูง เช่น การจัดเรียงสินค้าอัตโนมัติ หรือการเคลื่อนที่แบบซิงโครไนซ์ในสายการผลิต

## 8.11 Solenoid Valve

ในกระบวนการควบคุมเครื่องจักรอัตโนมัติ การควบคุมการไหลของของไหลหรือแรงดันลมเป็นสิ่งสำคัญอย่างยิ่ง ซึ่งอุปกรณ์ที่ถูกนำมาใช้ในการเปิด–ปิดการไหลนี้คือ โซลินอยด์วาล์ว (Solenoid Valve) โดยมี PLC (Programmable Logic Controller) เป็นตัวควบคุมการทำงาน วาล์วชนิดนี้ใช้หลักการของ แม่เหล็กไฟฟ้า (Electromagnetic Force) เพื่อขับกลไกให้เปิดหรือปิดทางเดินของของไหล เช่น ลม น้ำ หรือน้ำมันไฮดรอลิก จึงนิยมใช้กันอย่างแพร่หลายในโรงงานอัตโนมัติ เช่น ระบบลำเลียง ระบบบรรจุภัณฑ์ และระบบไฮดรอลิกส์ โดยมีส่วนประกอบหลักดังต่อไปนี้

1\. หลักการทำงานของ Solenoid Valve

เมื่อมีการจ่ายแรงดันไฟฟ้าเข้าสู่ขดลวดแม่เหล็กไฟฟ้าในตัววาล์ว สนามแม่เหล็กจะดึงแกนเหล็ก (Plunger) ให้เคลื่อนที่ ส่งผลให้ช่องทางของของไหลเปิดหรือปิดได้ตามลักษณะของวาล์ว ตัววาล์วสามารถทำงานได้ทั้งแบบ

- Normally Closed (NC) ปิดอยู่เมื่อไม่มีไฟ และจะเปิดเมื่อมีไฟจ่าย

- Normally Open (NO) เปิดอยู่เมื่อไม่มีไฟ และจะปิดเมื่อมีไฟจ่าย

2\. ประเภทของ Solenoid Valve ตามจำนวนพอร์ตและทิศทางการทำงาน

- 2/2 Way Valve มี 2 พอร์ต ใช้เปิด–ปิดการไหล

- 3/2 Way Valve ใช้ควบคุมการจ่ายลมหรือของไหลไปยังอุปกรณ์ เช่น กระบอกลม

- 5/2 Way Valve มักใช้ในระบบนิวเมติกส์ เพื่อควบคุมกระบอกลมแบบสองทิศทาง (Double Acting Cylinder)

- 5/3 Way Valve มีสามตำแหน่ง ใช้ในระบบที่ต้องการความแม่นยำในการหยุดกระบอกลมตรงกลาง

3\. การควบคุมด้วย PLC

ในระบบควบคุมจริง PLC จะส่งสัญญาณไฟฟ้าออกจากพอร์ตเอาต์พุต (เช่น Y0, Y1) ไปยังขดลวดของโซลินอยด์วาล์ว เพื่อเปิดหรือปิดทางเดินของของไหล

ตัวอย่างเช่น เมื่อ X0 = ON (สวิตช์เริ่มการทำงาน) PLC จะส่งสัญญาณให้ Y0 = ON เพื่อเปิดวาล์วให้ลมหรือของไหลไหลเข้าสู่กระบอกสูบ

โซลินอยด์วาล์วเป็นอุปกรณ์สำคัญในระบบควบคุมอัตโนมัติของโรงงาน ใช้สำหรับควบคุมการเปิด–ปิดของของไหลในระบบนิวเมติกส์หรือไฮดรอลิกส์ โดยการเชื่อมต่อกับ PLC สามารถทำให้การทำงานเป็นแบบอัตโนมัติ เพิ่มความแม่นยำ ลดข้อผิดพลาดจากการทำงานของมนุษย์ และสามารถเขียนโปรแกรมให้ทำงานร่วมกับเซนเซอร์หรืออุปกรณ์อื่น ๆ ได้อย่างยืดหยุ่น ดังนั้นการเข้าใจหลักการทำงาน โครงสร้าง และวิธีควบคุมของ Solenoid Valve จึงเป็นพื้นฐานสำคัญในการพัฒนาและออกแบบระบบควบคุมอัตโนมัติในงานอุตสาหกรรมยุคใหม่

![ภาพที่ 8.22 ประเภทของ Solenoid Valve ต่าง ๆ](/images/book/image139.jpg)

ภาพนี้แสดงอุปกรณ์ควบคุมทิศทางลมในระบบนิวเมติกส์ ซึ่งเป็นส่วนสำคัญในการทำงานของเครื่องจักรอัตโนมัติ โดยเฉพาะในระบบที่ใช้ PLC ควบคุมการจ่ายลม เพื่อสั่งการกระบอกสูบ (Cylinder) หรืออุปกรณ์ขับเคลื่อนต่าง ๆ โซลินอยด์วาล์ว (Solenoid Valve) เป็นวาล์วที่ควบคุมการไหลของลมอัดโดยใช้แรงดันไฟฟ้า เช่น 24 VDC ภายในมีขดลวดแม่เหล็กไฟฟ้า เมื่อได้รับแรงดันจะสร้างสนามแม่เหล็กดึงแกนวาล์วให้เปลี่ยนตำแหน่ง เพื่อเปิดหรือปิดทางเดินลม ใช้ในวงจรควบคุมการทำงานของกระบอกลม เช่น การยืด–หด หรือเปิด–ปิดวาล์วอื่น ๆ

ส่วนแมนนิโฟลด์วาล์ว (Manifold Valve Unit) เป็นชุดรวมของโซลินอยด์วาล์วหลายตัวติดตั้งอยู่บนฐานเดียวกัน เพื่อความสะดวกในการเดินท่อลมและเดินสายไฟ สามารถเชื่อมต่อกับ PLC ผ่านขั้วต่อเดียว เช่น พอร์ต D-sub หรือขั้วต่อไฟฟ้าแบบโมดูล ช่วยลดพื้นที่ติดตั้งและเพิ่มความเป็นระเบียบของระบบนิวเมติกส์ในเครื่องจักรอัตโนมัติ

เมื่อ PLC ส่งสัญญาณเอาต์พุตไฟฟ้าไปยังขดลวดของโซลินอยด์วาล์ว ขดลวดจะสร้างสนามแม่เหล็กดึงแกนภายในให้เปลี่ยนตำแหน่ง ทำให้ลมอัดไหลไปยังพอร์ตที่ต้องการ เช่น ไปยังด้านหน้าของกระบอกลมเพื่อให้แท่งลูกสูบเคลื่อนที่ออก หรือไปยังอีกด้านเพื่อให้ลูกสูบหดกลับ อุปกรณ์ชนิดนี้ถูกนำไปใช้งานอย่างแพร่หลายในระบบแขนกลอัตโนมัติ เครื่องแพ็คสินค้า สายพานลำเลียงที่ใช้กระบอกลมผลักสินค้า และระบบควบคุมวาล์วในเครื่องจักรอุตสาหกรรม

## บทสรุป

PLC สามารถควบคุมอุปกรณ์อื่นได้หลากหลาย ทั้งเซนเซอร์ตรวจจับชนิดต่าง ๆ Encoder Tower Lamp Relay และมอเตอร์ชนิด DC, Stepper และ Servo รวมถึง Solenoid Valve การเลือกอุปกรณ์และวิธีต่อต้องสอดคล้องกับชนิดของอินพุตและเอาต์พุตของ PLC การควบคุมตำแหน่งและความเร็วของมอเตอร์ใช้คำสั่งเฉพาะ เช่น DDRVI และ DDRVA และการใช้ Inverter ช่วยควบคุมความเร็วของมอเตอร์ไฟฟ้ากระแสสลับได้อย่างมีประสิทธิภาพ

## แบบฝึกหัดท้ายหน่วยเรียน

**คำชี้แจง:** ให้นักศึกษาตอบคำถามต่อไปนี้โดยใช้ความรู้จากบทเรียน พร้อมยกตัวอย่างประกอบ หากสามารถอธิบายพร้อมวาดภาพวงจรหรือแผนผังการต่อสายได้จะได้รับคะแนนเพิ่ม

**1. อธิบายหลักการทำงานของ Inductive Proximity Sensor และยกตัวอย่างการใช้งานจริงในระบบอุตสาหกรรมที่ต้องตรวจจับวัตถุโลหะโดยไม่สัมผัส**

<details><summary>เฉลย</summary>

Inductive Proximity Sensor ทำงานโดยใช้หลักการเหนี่ยวนำแม่เหล็กไฟฟ้า (Electromagnetic Induction) ภายในมีขดลวดคอยล์เชื่อมกับวงจรออสซิลเลเตอร์ เมื่อจ่ายไฟจะเกิดสนามแม่เหล็กไฟฟ้ารอบ ๆ เมื่อวัตถุโลหะเคลื่อนเข้ามาในระยะตรวจจับ สนามแม่เหล็กจะถูกรบกวน ทำให้วงจรส่งสัญญาณเอาต์พุตออกมา ตรวจจับได้ดีที่สุดกับเหล็ก โดยไม่ต้องสัมผัสวัตถุโดยตรง ตัวอย่างการใช้งานจริง: ตรวจจับชิ้นงานโลหะบนสายพานลำเลียง นับจำนวนชิ้นงาน ตรวจสอบตำแหน่งของแขนกล และระบบป้องกันเครื่องจักรเมื่อประตูนิรภัยเปิด

</details>

**2. เปรียบเทียบความแตกต่างระหว่าง Inductive Proximity Sensor และ Capacitive Proximity Sensor ในด้านหลักการทำงานและลักษณะวัตถุที่สามารถตรวจจับได้**

<details><summary>เฉลย</summary>

Inductive Proximity Sensor: ใช้หลักการเหนี่ยวนำแม่เหล็กไฟฟ้า ตรวจจับได้เฉพาะวัตถุโลหะ ระยะตรวจจับสั้น (1-50 mm) เหมาะกับสภาพแวดล้อมที่มีความชื้นหรือน้ำมัน Capacitive Proximity Sensor: ใช้หลักการเปลี่ยนแปลงความจุไฟฟ้า ตรวจจับได้ทั้งโลหะและอโลหะ เช่น พลาสติก แก้ว น้ำ ผงแป้ง ระยะตรวจจับปรับได้ เหมาะกับงานตรวจสอบระดับของเหลวในถัง ตรวจจับบรรจุภัณฑ์ และระบบบรรจุอาหารอัตโนมัติ

</details>

**3. อธิบายหลักการทำงานของ Photoelectric Sensor และอธิบายลักษณะของการติดตั้งแบบ Through-beam, Retro-reflective และ Diffuse พร้อมตัวอย่างงานที่เหมาะสมในแต่ละแบบ**

<details><summary>เฉลย</summary>

Through-Beam: ตัวส่งและตัวรับแยกกันวางตรงข้าม เมื่อวัตถุบังแสงจะเกิดสัญญาณ ความแม่นยำสูง เหมาะระยะไกล เช่น ตรวจจับวัตถุใหญ่บนสายพาน Retro-Reflective: ตัวส่งและตัวรับในตัวเดียว ใช้แผ่นสะท้อนช่วย เมื่อวัตถุบังแสงจะเกิดสัญญาณ ติดตั้งง่ายกว่า Through-Beam เหมาะตรวจจับวัตถุโปร่งแสง Diffuse: ตัวส่งและตัวรับในตัวเดียว ใช้แสงสะท้อนจากวัตถุโดยตรง ติดตั้งง่ายที่สุด เหมาะระยะใกล้ เช่น ตรวจจับชิ้นงานขนาดเล็กบนสายพาน

</details>

**4. อธิบายการทำงานของ Fiber Optic Sensor และอธิบายสาเหตุที่ทำให้เซนเซอร์ชนิดนี้เหมาะกับงานที่ต้องการความแม่นยำสูงหรือพื้นที่จำกัด**

<details><summary>เฉลย</summary>

Fiber Optic Sensor ประกอบด้วย 2 ส่วน: Fiber Amplifier ทำหน้าที่ปล่อยแสงและประมวลผล และ Fiber Optic Head นำแสงไปยังจุดตรวจจับ การทำงาน: แอมพลิไฟเออร์กำเนิดแสง ส่งผ่านสายไฟเบอร์ไปยังหัวส่ง (Transmitter) กระทบวัตถุ แสงสะท้อนกลับสู่หัวรับ (Receiver) ส่งกลับแอมพลิไฟเออร์ประมวลผลค่าความเข้มแสง แล้วส่งสัญญาณไปยัง PLC เหมาะกับงานที่ต้องการความแม่นยำสูงหรือพื้นที่จำกัด เพราะสายไฟเบอร์บางเล็กสามารถส่องถึงจุดแคบได้ ทนต่อสภาพแวดล้อมเลวร้าย เช่น อุณหภูมิสูง สนามแม่เหล็ก หรือพื้นที่มีกระแสไฟรบกวน

</details>

**5. อธิบายหลักการทำงานของ Encoder และยกตัวอย่างการประยุกต์ใช้ Encoder ในระบบควบคุมการเคลื่อนไหว เช่น การวัดความเร็วหรือระยะทางของสายพานลำเลียง**

<details><summary>เฉลย</summary>

Encoder ทำงานโดยภายในมีแผ่นจานหมุนที่เจาะรู LED ส่องผ่านช่องรูไปยัง Photodetector เมื่อจานหมุน ช่องแสงสลับเปิด-ปิด เกิดสัญญาณพัลส์ A, B และ Z สัญญาณ A และ B ใช้ระบุทิศทางและนับพัลส์ สัญญาณ Z เป็นจุดอ้างอิง Home Position การประยุกต์ใช้: สายพานลำเลียงใช้ Encoder วัดระยะทางการเคลื่อนที่ โดย PLC นับพัลส์แล้วคำนวณระยะทาง (ระยะ = พัลส์ × เส้นรอบวงล้อ / พัลส์ต่อรอบ) และวัดความเร็ว (ความเร็ว = พัลส์ต่อวินาที / พัลส์ต่อรอบ × เส้นรอบวง)

</details>

**6. อธิบายหน้าที่ของ Tower Lamp ในระบบอัตโนมัติ และอธิบายความหมายของแต่ละสี (แดง เหลือง เขียว) พร้อมยกตัวอย่างโปรแกรมการควบคุมไฟแสดงสถานะด้วย PLC**

<details><summary>เฉลย</summary>

Tower Lamp หรือ Signal Tower Light เป็นอุปกรณ์แสดงสถานะเครื่องจักรที่มองเห็นได้จากระยะไกล ความหมายของสี: สีเขียว (Green) = เครื่องจักรทำงานปกติ สีเหลือง (Yellow) = เครื่องรอคำสั่ง อยู่ในโหมดเตรียมพร้อม หรือกำลังเปลี่ยนสถานะ สีแดง (Red) = เครื่องหยุดหรือเกิดข้อขัดข้องที่ต้องตรวจสอบ บางรุ่นมี Buzzer เพิ่มเติมสำหรับแจ้งเตือนด้วยเสียง ตัวอย่างโปรแกรม: เมื่อ M0 (READY) = ON → Y0 (LAMP_GREEN) ทำงาน เมื่อ M1 (WARNING) = ON → Y1 (LAMP_YELLOW) ทำงาน เมื่อ M2 (ERROR) = ON → Y2 (LAMP_RED) และ Y3 (BUZZER) ทำงาน

</details>

**7. อธิบายหลักการทำงานของ Relay และการประยุกต์ใช้รีเลย์ในการควบคุมอุปกรณ์ภายนอกผ่าน PLC รวมถึงเปรียบเทียบข้อดีของการใช้รีเลย์เทียบกับการต่อวงจรโดยตรง**

<details><summary>เฉลย</summary>

Relay ทำงานโดยอาศัยหลักการแม่เหล็กไฟฟ้า เมื่อขดลวด (Coil) ได้รับกระแสไฟฟ้าจาก Output ของ PLC สนามแม่เหล็กจะดึงให้หน้าสัมผัส (Contact) เปลี่ยนสถานะ (NO → ปิด, NC → เปิด) ทำให้วงจรภายนอกทำงานได้ การประยุกต์ใช้: PLC ส่งสัญญาณ 24VDC ไปยังขดลวดรีเลย์ หน้าสัมผัสรีเลย์จะต่อวงจร 220VAC ให้มอเตอร์หรือหลอดไฟทำงาน ข้อดีของการใช้รีเลย์: PLC ไม่ต้องรับโหลดไฟฟ้าโดยตรง ป้องกันความเสียหายจากไฟกระชาก แยก Low Voltage (24V) ออกจาก High Voltage (220V)

</details>

**8. อธิบายหลักการทำงานของ DC Motor และอธิบายวิธีการควบคุมการหมุนไป-กลับของมอเตอร์โดยใช้รีเลย์หรือ H-Bridge Driver พร้อมยกตัวอย่างโปรแกรมใน GX Works3**

<details><summary>เฉลย</summary>

DC Motor ทำงานโดยแปลงพลังงานไฟฟ้ากระแสตรงเป็นพลังงานกล เมื่อกระแสไฟฟ้าไหลผ่านขดลวดอาร์มาเจอร์ในสนามแม่เหล็กของสเตเตอร์ เกิดแรงบิดทำให้โรเตอร์หมุน การกลับทิศทางทำได้โดยกลับขั้วแรงดัน (Reversing Polarity) วิธีควบคุมหมุนไป-กลับ: PLC ส่งสัญญาณ Y0 = ON เพื่อสั่ง Relay 1 ให้มอเตอร์หมุน Forward และ Y1 = ON เพื่อสั่ง Relay 2 ให้มอเตอร์หมุน Reverse โดยออกแบบ Interlock ไม่ให้ Y0 และ Y1 ทำงานพร้อมกัน เพื่อป้องกันลัดวงจร ตัวอย่างโปรแกรม: กด X1 (SW FWD) → Y6 (CW) ทำงาน มอเตอร์หมุนไปข้างหน้า กด X2 (SW REV) → Y7 (CCW) ทำงาน มอเตอร์หมุนย้อนกลับ

</details>

**9. อธิบายความแตกต่างระหว่าง Stepper Motor และ Servo Motor ทั้งในด้านหลักการทำงาน ระบบควบคุม และความเหมาะสมของการใช้งานในแต่ละประเภทของเครื่องจักร**

<details><summary>เฉลย</summary>

Stepper Motor: หมุนทีละ "สเต็ป" ตามจำนวนพัลส์ที่ส่งเข้ามา มุมหมุนต่อสเต็ป 0.9°-1.8° ไม่มีระบบ Feedback (Open-loop Control) แม่นยำเพียงพอสำหรับงานทั่วไป ราคาถูกกว่า ใช้กับ Driver เช่น TB6600 ในระบบ CNC และเครื่องพิมพ์ 3D Servo Motor: มีระบบ Closed-loop Feedback ผ่าน Encoder หรือ Resolver ตรวจสอบตำแหน่งจริงและแก้ไขความคลาดเคลื่อนแบบเรียลไทม์ แม่นยำสูงกว่า ตอบสนองเร็วกว่า เหมาะงานที่ต้องการความแม่นยำระดับสูง เช่น หุ่นยนต์ CNC ราคาสูงกว่า ต้องการ Servo Driver เช่น Mitsubishi MR-J4

</details>

**10. อธิบายหลักการทำงานของ Solenoid Valve และอธิบายการควบคุมการเปิด-ปิดวาล์วลมด้วย PLC พร้อมวาดแผนผังวงจรแสดงการเชื่อมต่อระหว่าง PLC และโซลินอยด์วาล์วในระบบนิวเมติกส์**

<details><summary>เฉลย</summary>

Solenoid Valve ทำงานโดยใช้แม่เหล็กไฟฟ้า เมื่อมีแรงดันไฟฟ้าเข้าขดลวด สนามแม่เหล็กดึงแกนเหล็ก (Plunger) ให้เคลื่อนที่ ทำให้ช่องทางของไหลเปิดหรือปิด ประเภท: NC (Normally Closed) ปิดเมื่อไม่มีไฟ เปิดเมื่อมีไฟ NO (Normally Open) เปิดเมื่อไม่มีไฟ ปิดเมื่อมีไฟ การควบคุมด้วย PLC: PLC ส่งสัญญาณจาก Output (Y0) ไปยังขดลวดวาล์ว เมื่อ X0 (สวิตช์เริ่ม) = ON → PLC สั่ง Y0 = ON เปิดวาล์วให้ลมไหลเข้ากระบอกสูบ เมื่อ X1 (สวิตช์หยุด) = ON → PLC สั่ง Y0 = OFF ปิดวาล์วหยุดการทำงาน แผนผังการต่อวงจร: \[+24VDC\] → \[Output Y0 ของ PLC\] → \[ขดลวด Solenoid Valve\] → \[GND\] โดยขดลวดวาล์วต่อขนานกับ Free-wheeling Diode เพื่อป้องกันแรงดันกลับ

</details>
