## 5.1 หลักการของ HMI และเปรียบเทียบข้อดีข้อเสียของ HMI

### 5.1.1 ส่วนประกอบหลักของ HMI และหน้าที่ของแต่ละส่วน

HMI ประกอบด้วยส่วนสำคัญหลายส่วนที่ทำงานร่วมกันเพื่อให้เกิดการสื่อสารกับ PLC และผู้ใช้งานได้อย่างมีประสิทธิภาพ ทั้งในด้านการแสดงผลและการรับข้อมูลจากผู้ใช้

ส่วนประกอบหลักของ HMI ได้แก่

1.  จอแสดงผล (Display Unit) ใช้แสดงสถานะและข้อมูลจากระบบ เช่น ค่าแรงดัน กระแส หรือสถานะของอุปกรณ์

2.  หน่วยประมวลผล (CPU Unit) ควบคุมการทำงานและการเชื่อมต่อข้อมูลระหว่าง PLC กับหน้าจอ

3.  หน่วยความจำ (Memory) จัดเก็บโปรแกรมและกราฟิกของหน้าจอ

4.  พอร์ตสื่อสาร (Communication Port) ใช้เชื่อมต่อกับ PLC ผ่าน RS-232, RS-485 หรือ Ethernet

![](/images/book/image76.png)

ภาพที่ 5.1 ภาพแสดงโครงสร้างของ ชุดฝึกการใช้งาน HMI ร่วมกับ PLC ของ Mitsubishi

![](/images/book/image77.jpg)

ภาพที่ 5.2 พอร์ตเชื่อมต่อและส่วนประกอบด้านหลังของหน้าจอ HMI Mitsubishi GOT2000 Series

#### 1. Ethernet Interface

ใช้เชื่อมต่อกับอุปกรณ์อุตสาหกรรมหลายชนิดพร้อมกัน (เช่น PLC, อินเวอร์เตอร์, เซอร์โว) ผ่านเครือข่าย Ethernet รองรับมาตรฐาน CC-Link IE Field Network

#### 2. RS-232 Interface

พอร์ตอนุกรมสำหรับเชื่อมต่อกับอุปกรณ์ เช่น PLC, เครื่องอ่านบาร์โค้ด, เครื่องพิมพ์ หรือเครื่องมือวัดอื่น ๆ

#### 3. RS-422/485 Interface

ใช้เชื่อมต่อกับอุปกรณ์อุตสาหกรรมที่สื่อสารแบบระยะไกล เช่น PLC, อินเวอร์เตอร์, เซอร์โว, ตัวควบคุมอุณหภูมิ และอุปกรณ์ที่ใช้โปรโตคอล MODBUS

#### 4. USB Interface (USB Mini-B)

เชื่อมต่อกับคอมพิวเตอร์เพื่อโอนย้ายข้อมูล หรืออัปโหลด/ดาวน์โหลดโปรแกรมจากซอฟต์แวร์ HMI

#### 5. SD Memory Card Interface

ช่องใส่ SD Card สำหรับบันทึกข้อมูลจำนวนมาก เช่น ข้อมูลการทำงาน, ค่า Alarm, หรือบันทึก Log ของระบบ

HMI ประกอบด้วยส่วนแสดงผล หน่วยประมวลผล หน่วยความจำ และพอร์ตสื่อสารที่หลากหลาย เพื่อรองรับการสื่อสารกับอุปกรณ์อุตสาหกรรมได้หลายประเภท การเข้าใจโครงสร้างและพอร์ตเชื่อมต่อของ HMI ช่วยให้สามารถออกแบบระบบควบคุมและการเชื่อมต่อกับ PLC ได้อย่างถูกต้องและมีประสิทธิภาพสูงสุด

### 5.1.2 ความหมายและบทบาทของ HMI ในระบบควบคุมอัตโนมัติ

Human Machine Interface (HMI) คืออุปกรณ์ที่ใช้เป็นสื่อกลางระหว่างมนุษย์และเครื่องจักร เพื่อให้ผู้ควบคุมสามารถตรวจสอบสถานะและสั่งงานระบบได้อย่างสะดวก โดยทั่วไป HMI จะทำงานร่วมกับ PLC เพื่อแสดงผลข้อมูลจากระบบ เช่น ค่าการทำงานของมอเตอร์ เซนเซอร์ หรือสัญญาณแจ้งเตือนต่าง ๆ

HMI ช่วยให้ผู้ใช้งานสามารถมองเห็นภาพรวมของระบบได้ในรูปแบบกราฟิก เช่น ปุ่มกดเสมือน (Virtual Button) หรือไฟแสดงสถานะ ทำให้การควบคุมเครื่องจักรง่ายขึ้น ลดการใช้วงจรไฟฟ้าแบบปุ่มกดจริง และช่วยเพิ่มความปลอดภัยในการทำงาน HMI

![](/images/book/image78.png)

เป็นอุปกรณ์ที่ทำหน้าที่เป็นสื่อกลางระหว่างผู้ใช้งานกับเครื่องจักรหรือระบบอัตโนมัติ เพื่อแลกเปลี่ยนข้อมูลและทำการประมวลผลคำสั่งต่าง ๆ ได้อย่างสะดวกและรวดเร็ว จึงเป็นที่นิยมใช้กันอย่างแพร่หลายในอุตสาหกรรมต่าง ๆ เช่น รถยนต์ อิเล็กทรอนิกส์ อุปกรณ์การแพทย์ และอุตสาหกรรมการผลิต เป็นต้น

ภาพที่ 5.3 ตัวอย่างหน้าจอ HMI ในระบบควบคุมเครื่องจักรอุตสาหกรรม

หลักการทำงานของเทคโนโลยี HMI

การรับข้อมูล HMI สามารถรวบรวมข้อมูลต่าง ๆ ที่เกี่ยวข้องกับกระบวนการผลิตจากเครื่องจักรและอุปกรณ์ต่าง ๆ ผ่านระบบการสื่อสาร เช่น ข้อมูลสถานะเครื่องจักร ข้อมูลการผลิต ข้อมูลคุณภาพ ข้อมูลความปลอดภัย ได้อย่างรวดเร็ว

การประมวลผลข้อมูล HMI จะทำการประมวลผลข้อมูลที่ได้รับมา เพื่อแสดงผลหรือส่งต่อไปยังระบบอื่น ๆ เช่น ระบบ PLC หรือระบบ ERP สำหรับควบคุมการทำงาน

การแสดงผลและการควบคุม HMI จะนำเสนอข้อมูลต่าง ๆ ให้ผู้ใช้งานผ่านหน้าจอแสดงผลในรูปแบบต่าง ๆ เช่น ข้อความ ภาพ ตัวเลข กราฟ แผนภูมิ สัญลักษณ์ หรือ Alarm เตือน

การบันทึกข้อมูล HMI สามารถบันทึกข้อมูลต่าง ๆ ที่เกี่ยวข้องกับกระบวนการทำงาน เพื่อใช้สำหรับการอ้างอิงหรือการวิเคราะห์ สำหรับพัฒนาธุรกิจให้เติบโตยิ่งขึ้นได้

### 5.1.3 ข้อดีและข้อเสียของการใช้ HMI

การนำ HMI มาใช้ในอุตสาหกรรมช่วยเพิ่มประสิทธิภาพการทำงาน เนื่องจากสามารถมอนิเตอร์และควบคุมระบบได้จากจุดเดียว แต่ก็มีข้อจำกัดบางประการที่ต้องพิจารณา เช่น ราคาของอุปกรณ์และซอฟต์แวร์

ตารางที่ 5.1 การเปรียบเทียบข้อดีและข้อเสียข้อเสีย

| ข้อดี                                   | ข้อเสีย                                         |
|---------------------------------------|-----------------------------------------------|
| ใช้งานง่ายและเข้าใจได้จากภาพกราฟิก         | ราคาสูงกว่าการใช้สวิตช์และไฟแสดงผลทั่วไป             |
| ลดความผิดพลาดจากการควบคุมด้วยสวิตช์จริง     | ต้องใช้ความรู้ด้านซอฟต์แวร์ในการออกแบบหน้าจอ          |
| สามารถตรวจสอบและแก้ไขปัญหาได้รวดเร็ว      | หากระบบล่มอาจควบคุมเครื่องจักรไม่ได้                 |
| แสดงผลแบบเรียลไทม์ มีระบบแจ้งเตือน (Alarm) | ต้องดูแลเรื่องไฟเลี้ยงและการอัปเดตซอฟต์แวร์อย่างสม่ำเสมอ |
| เชื่อมต่อกับ PLC ได้หลายรุ่นและหลายโปรโตคอล  |                                               |

ข้อดีหลักของ HMI คือช่วยให้ผู้ควบคุมเห็นสถานะของเครื่องจักรแบบเรียลไทม์ ลดจำนวนสวิตช์และหลอดไฟบนตู้ควบคุม ปรับค่าพารามิเตอร์ได้โดยไม่ต้องแก้ไขโปรแกรม PLC และบันทึกสัญญาณเตือน (Alarm) เพื่อใช้วิเคราะห์ปัญหา ส่วนข้อเสีย ได้แก่ ต้นทุนเริ่มต้นสูงกว่าสวิตช์แบบดั้งเดิม ต้องมีผู้ที่มีความรู้ในการออกแบบหน้าจอ และหากหน้าจอหรือการสื่อสารขัดข้อง ผู้ควบคุมอาจสั่งงานเครื่องจักรไม่ได้ จึงต้องติดตั้งปุ่มหยุดฉุกเฉินแบบฮาร์ดแวร์ร่วมด้วยเสมอ

ภาพที่ 5.5 การเชื่อมต่อระหว่าง PLC กับ HMI

ภาพนี้แสดงการเชื่อมต่อระหว่าง PLC Mitsubishi รุ่น FX5UJ Series กับ HMI รุ่น GOT Simple Series โดยสามารถเชื่อมต่อได้หลายรูปแบบตามประเภทของพอร์ตสื่อสารที่มีในอุปกรณ์ ทั้งแบบ LAN (Ethernet), RS-232, และ RS-422/485 ซึ่งแต่ละแบบมีจุดเด่นแตกต่างกัน ดังนี้

1.  สาย LAN (Ethernet) ใช้เชื่อมต่อแบบเครือข่ายความเร็วสูง เหมาะสำหรับการส่งข้อมูลระหว่าง PLC กับ HMI ที่อยู่ในระบบเดียวกัน สามารถรองรับการสื่อสารหลายอุปกรณ์พร้อมกัน เช่น PLC, อินเวอร์เตอร์ หรือเซอร์โว เหมาะสำหรับงานอุตสาหกรรมที่ต้องการความเร็วและเสถียรสูง

2.  สาย RS-232 เป็นการเชื่อมต่อแบบอนุกรมระยะใกล้ (ไม่เกิน 15 เมตร) ใช้งานง่าย เหมาะสำหรับการเชื่อมต่อ PLC กับ HMI หนึ่งต่อหนึ่ง มักใช้ในระบบขนาดเล็กหรือชุดฝึกอบรม

3.  สาย RS-422/RS-485 รองรับการสื่อสารระยะไกล (ได้มากกว่า 100 เมตร) เชื่อมต่ออุปกรณ์ได้หลายตัวในระบบเดียว (Multi-drop Communication) เหมาะสำหรับงานอุตสาหกรรมที่มีอุปกรณ์หลายจุดและต้องการความเสถียรสูง

การเลือกใช้สายสื่อสารระหว่าง PLC กับ HMI ต้องพิจารณาจากระยะทาง ลักษณะของระบบ และจำนวนอุปกรณ์ในเครือข่าย โดยทั่วไป การเชื่อมต่อผ่าน LAN จะเหมาะกับระบบอุตสาหกรรมสมัยใหม่ที่ต้องการความเร็วสูง ส่วน RS-232 และ RS-422/485 จะเหมาะสำหรับระบบควบคุมเฉพาะทางหรือระบบฝึกอบรมที่มีขนาดเล็กกว่า

## 5.3 การเชื่อมต่อ HMI กับ PLC และใช้งานโปรแกรม GT Designer3

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 5 เรื่องการเชื่อมต่อ HMI กับ PLC และใช้งานโปรแกรม GT Designer3 ใช้เวลา 3 ชั่วโมง (180 นาที) ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริงกับชุดฝึก และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อม และตรวจสอบสายเชื่อมต่อระหว่าง HMI, PLC และคอมพิวเตอร์ (10 นาที)

ขั้นที่ 2 สร้างโปรเจกต์ใหม่ใน GT Designer3 เลือกรุ่น HMI และตั้งค่า Controller Setting ให้ตรงกับ PLC (30 นาที)

ขั้นที่ 3 ตั้งค่า IP Address ของ HMI คอมพิวเตอร์ และ PLC ให้อยู่ในเครือข่ายเดียวกันตามที่ครูกำหนด (30 นาที)

ขั้นที่ 4 ออกแบบหน้าจอทดสอบ ประกอบด้วยข้อความหัวเรื่อง Bit Lamp และ Bit Switch อย่างง่าย (30 นาที)

ขั้นที่ 5 โอนถ่ายโปรเจกต์ (Download/Transfer) เข้าสู่ HMI และตรวจสอบว่าหน้าจอแสดงผลถูกต้อง (25 นาที)

ขั้นที่ 6 ทดสอบการสื่อสารกับ PLC โดยกด Bit Switch แล้วสังเกตเอาต์พุต Y และสถานะใน GX Works3 Monitor (30 นาที)

ขั้นที่ 7 วิเคราะห์และแก้ไขปัญหาหากการสื่อสารไม่สำเร็จ โดยตรวจ IP Address, สายสัญญาณ และ Controller Setting (15 นาที)

ขั้นที่ 8 สรุปผล ส่งแบบบันทึกผล และเก็บอุปกรณ์ (10 นาที)

### 5.3.1 งานเชื่อมต่อ HMI กับ PLC

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถสังเกตการเชื่อมต่อHMI กับ PLC ตามผังการเชื่อมต่อที่กำหนดได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 5 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 5.3.2 งานโปรแกรม GT Designer3

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถดำเนินการใช้งานโปรแกรม GT Designer3 สร้างโปรเจกต์และโอนถ่ายข้อมูลไปยัง HMI ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 5 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

## บทสรุป

HMI (Human Machine Interface) เป็นอุปกรณ์แสดงผลและรับคำสั่งจากผู้ปฏิบัติงานผ่านหน้าจอสัมผัส ช่วยให้ควบคุมและเฝ้าสังเกตระบบได้สะดวกกว่าสวิตช์และหลอดไฟแบบเดิม แต่มีข้อจำกัดด้านต้นทุนและการบำรุงรักษา การใช้งานเริ่มจากเลือกรุ่น HMI ติดตั้งโปรแกรม GT Designer3 กำหนด Controller Setting ตั้งค่า IP Address และเชื่อมต่อกับ PLC ผ่านพอร์ตสื่อสาร จากนั้นจึงโอนถ่ายโปรเจกต์เข้าสู่ HMI

## แบบฝึกหัดท้ายหน่วยเรียน

</details>

**2. ยกตัวอย่างการใช้งาน HMI ร่วมกับ PLC ในงานอุตสาหกรรมจริง พร้อมอธิบายว่าการทำงานร่วมกันของทั้งสองอุปกรณ์นี้ช่วยเพิ่มประสิทธิภาพของระบบได้อย่างไร**

<details><summary>เฉลย</summary>

ข้อดี ใช้งานง่าย แสดงผลเป็นภาพกราฟิกเข้าใจได้ทันที ลดจำนวนสวิตช์และหลอดไฟบนแผงควบคุม เปลี่ยนแปลงหน้าจอได้ด้วยซอฟต์แวร์โดยไม่ต้องเดินสายใหม่ และเก็บบันทึกข้อมูลได้ ข้อจำกัด ราคาสูงกว่าอุปกรณ์แบบเดิม ต้องใช้ความรู้ในการออกแบบโปรแกรม และต้องบำรุงรักษาหน้าจอสัมผัสให้พร้อมใช้งาน

</details>

**4. จากบทเรียน 'ส่วนประกอบ HMI' ให้อธิบายหน้าที่ของ จอแสดงผล (Display Unit), หน่วยประมวลผล (CPU Unit) และ พอร์ตสื่อสาร (Communication Port) พร้อมยกตัวอย่างการใช้งานจริง**

<details><summary>เฉลย</summary>

ส่วนประกอบสำคัญของ HMI ได้แก่ หน้าจอแสดงผลแบบสัมผัสใช้แสดงข้อมูลและรับคำสั่ง หน่วยประมวลผลทำหน้าที่ประมวลผลข้อมูลและคำสั่ง พอร์ตสื่อสาร เช่น Ethernet, RS-232, RS-485 และ USB ใช้เชื่อมต่อกับ PLC และคอมพิวเตอร์ และแหล่งจ่ายไฟ DC 24V สำหรับเลี้ยงวงจรภายใน

**7. จากส่วนประกอบของโปรแกรม GT Designer3 จงอธิบายหน้าที่ของ Tool Bar, Object Palette, และ Work Space ว่ามีบทบาทอย่างไรในการออกแบบหน้าจอ HMI**

<details><summary>เฉลย</summary>

ส่วนประกอบหลักของ GT Designer3 ได้แก่ Menu Bar แถบเมนูคำสั่งหลัก Toolbar แถบเครื่องมือที่ใช้บ่อย Screen Editor พื้นที่ออกแบบหน้าจอ Object/Parts ชุดอุปกรณ์สำเร็จรูป เช่น สวิตช์ หลอดไฟ ตัวเลข และ Project Tree/Property Window ใช้จัดการหน้าจอและตั้งค่าคุณสมบัติของอุปกรณ์แต่ละตัว

</details>

**8. อธิบายหลักการเชื่อมต่อระหว่าง PLC กับ HMI พร้อมระบุความแตกต่างของการเชื่อมต่อผ่านพอร์ต RS-232, RS-485, และ Ethernet ว่าแต่ละแบบเหมาะกับงานลักษณะใด**

<details><summary>เฉลย</summary>

การเชื่อมต่อ PLC กับ HMI ทำได้หลายแบบ เช่น ผ่านสาย LAN (Ethernet) ซึ่งมีความเร็วสูงและนิยมใช้มากที่สุด ผ่าน RS-232 สำหรับระยะใกล้ และ RS-485 สำหรับการต่อพ่วงหลายอุปกรณ์ โดยต้องตั้งค่าชนิดคอนโทรลเลอร์และพารามิเตอร์การสื่อสารใน GT Designer3 ให้ตรงกับ PLC ที่ใช้งาน

</details>

**9. อธิบายขั้นตอนการตั้งค่าการเชื่อมต่อคอนโทรลเลอร์ (Controller Setting) ในโปรแกรม GT Designer3 และเหตุใดการกำหนด Communication Driver ให้ถูกต้องจึงมีความสำคัญ**

<details><summary>เฉลย</summary>

ขั้นตอนสำคัญคือ เปิดเมนู Common \> Controller Setting เลือกผู้ผลิตและรุ่นของ PLC เช่น MELSEC iQ-F (FX5UJ) เลือกชนิดการเชื่อมต่อเป็น Ethernet กำหนด IP Address ของ HMI และของ PLC ให้อยู่ในวงเครือข่ายเดียวกัน บันทึกการตั้งค่า แล้วอัปโหลดโปรเจกต์เข้าสู่ HMI เพื่อให้การสื่อสารมีผล

</details>

**10. อธิบายภาพรวมของการทำงานร่วมกันระหว่าง PLC และ HMI ตั้งแต่การออกแบบหน้าจอใน GT Designer3 จนถึงการเชื่อมต่อและแสดงผลแบบเรียลไทม์ พร้อมยกตัวอย่างการใช้งานในสายการผลิตจริง**

<details><summary>เฉลย</summary>

PLC ทำหน้าที่ควบคุมการทำงานของอุปกรณ์ในระบบตามโปรแกรม ส่วน HMI ทำหน้าที่เป็นหน้าจอแสดงสถานะและรับคำสั่งจากผู้ใช้ ทั้งสองเชื่อมต่อแลกเปลี่ยนข้อมูลกันตลอดเวลา ผู้ใช้สั่งงานผ่าน HMI คำสั่งถูกส่งไปยัง PLC เพื่อควบคุมอุปกรณ์จริง และ PLC ส่งสถานะกลับมาแสดงบน HMI ทำให้ควบคุมและติดตามระบบได้อย่างมีประสิทธิภาพ

</details>
