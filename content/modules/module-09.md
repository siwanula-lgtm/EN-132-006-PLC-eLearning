## จุดประสงค์การสอน

- **9.1 เข้าใจหลักการทำงานของระบบสายพานลำเลียง (Conveyor System) ได้**
    - 9.1.1 ระบุเซนเซอร์ที่ใช้ในระบบสายพานลำเลียงและตำแหน่ง ติดตั้งได้
    - 9.1.2 อธิบายบทบาทของ PLC ในการควบคุมระบบสายพาน ลำเลียงได้
    - 9.1.3 อธิบายหลักการทำงานของ Conveyor System ตั้งแต่การตรวจจับวัตถุจนถึงการนับจำนวนชิ้นงานได้
- **9.2 ปฏิบัติการควบคุมระบบสายพานลำเลียงด้วย PLC และ HMI ได้ถูกต้อง**
    - 9.2.1 สังเกตการเขียนโปรแกรมPLC ควบคุมระบบสายพานลำเลียง ได้ถูกต้อง
    - 9.2.2 เลียบแบบการควบคุมระบบสายพานลำเลียงด้วย PLC และ HMI ได้ถูกต้อง
    - 9.2.3 ดำเนินการเชื่อมต่อ PLC – HMI – IoT เพื่อแสดงข้อมูลการทำงานของระบบได้ถูกต้อง
- **9.3 เข้าใจลำดับการทำงานของระบบบรรจุผลิตภัณฑ์อัตโนมัติ (Automatic Packing System) ได้**
    - 9.3.1 ระบุโครงสร้างและลำดับการทำงานของระบบ บรรจุผลิตภัณฑ์อัตโนมัติได้
    - 9.3.2 อธิบายหลักการเชื่อมต่อ PLC – HMI – IoT และประโยชน์ต่อ Smart Factory ได้
- **9.4 ปฏิบัติการควบคุมระบบบรรจุผลิตภัณฑ์อัตโนมัติด้วย PLC ได้ถูกต้อง**
    - 9.4.1 ฝึกเขียนโปรแกรม PLC ควบคุมระบบบรรจุผลิตภัณฑ์อัต โนมัติได้ถูกต้อง
    - 9.4.2 ดำเนินการตรวจสอบความปลอดภัยและประสิทธิภาพ ของระบบ โดยรวม และบันทึกแนวทางปรับปรุงได้

ในยุคของ Industry 4.0 หรือ อุตสาหกรรมยุคที่ 4 เป็นยุคที่มีการบูรณาการเทคโนโลยีดิจิทัลเข้ากับระบบการผลิต เพื่อให้เกิดกระบวนการผลิตที่ อัจฉริยะ (Smart Manufacturing) โดยมีการเชื่อมโยงระหว่าง เครื่องจักร, ระบบควบคุม, หุ่นยนต์, Internet of Things (IoT) และ การวิเคราะห์ข้อมูล (Data Analytics) เพื่อเพิ่มประสิทธิภาพในการทำงาน ความยืดหยุ่น และลดข้อผิดพลาดในกระบวนการผลิต

หนึ่งในระบบพื้นฐานที่สำคัญของการผลิตอัตโนมัติคือ

1\. ระบบสายพานลำเลียง (Conveyor System)

ระบบสายพานลำเลียงเป็นหัวใจหลักของสายการผลิต ที่ใช้สำหรับเคลื่อนย้ายชิ้นงานหรือผลิตภัณฑ์จากจุดหนึ่งไปยังอีกจุดหนึ่งอย่างต่อเนื่อง โดยมีการติดตั้ง เซนเซอร์ (Sensor) เช่น Proximity Sensor, Encoder เพื่อควบคุมการเคลื่อนไหว ตรวจจับตำแหน่ง และนับจำนวนชิ้นงาน ซึ่งระบบควบคุมหลักจะใช้ PLC (Programmable Logic Controller) ในการสั่งการมอเตอร์ เปิด-ปิด และหยุดทำงานตามเงื่อนไขที่กำหนด

ระบบสายพานในอุตสาหกรรมยุคใหม่ยังสามารถเชื่อมต่อกับระบบ HMI (Human Machine Interface) เพื่อให้ผู้ปฏิบัติงานสามารถเฝ้าดูสถานะของระบบแบบเรียลไทม์ และปรับค่าการทำงานได้สะดวกยิ่งขึ้น

> 2\. ระบบบรรจุผลิตภัณฑ์อัตโนมัติ (Automatic Packing System)

เมื่อชิ้นงานผ่านกระบวนการผลิต ระบบสายพานจะลำเลียงไปยัง สถานีบรรจุภัณฑ์ (Packing Station) ซึ่งเป็นจุดที่ระบบบรรจุอัตโนมัติทำงาน เช่น การเติมสินค้า การชั่งน้ำหนัก การปิดฝา หรือการซีลถุง โดยมี PLC เป็นตัวควบคุมลำดับการทำงาน และเชื่อมโยงกับ เซนเซอร์ตรวจจับน้ำหนัก (Load Cell), เซนเซอร์ตรวจตำแหน่ง, และอุปกรณ์ขับเคลื่อน (Actuator) เพื่อให้กระบวนการบรรจุเป็นไปอย่างถูกต้องและแม่นยำ

ในยุค Industry 4.0 ระบบบรรจุภัณฑ์เหล่านี้สามารถเชื่อมต่อกับ ระบบ IoT และ Cloud เพื่อเก็บข้อมูลการผลิต เช่น จำนวนบรรจุภัณฑ์ เวลาการทำงาน หรือสถิติความผิดพลาด ซึ่งช่วยให้ผู้บริหารสามารถวิเคราะห์ข้อมูลและปรับปรุงกระบวนการผลิตได้อย่างมีประสิทธิภาพ

## 9.1 หลักการทำงานของระบบสายพานลำเลียง (Conveyor System)

### 9.1.1 เซนเซอร์ที่ใช้ในระบบสายพานลำเลียงและตำแหน่งติดตั้ง

ระบบสายพานลำเลียงเป็นระบบอัตโนมัติที่ถูกใช้อย่างแพร่หลายในสายการผลิต เพื่อเคลื่อนย้ายวัตถุหรือชิ้นงานจากจุดหนึ่งไปยังอีกจุดหนึ่ง โดยอาศัยมอเตอร์เป็นต้นกำลังในการขับเคลื่อนสายพาน การทำงานของระบบถูกควบคุมโดย PLC ซึ่งจะรับสัญญาณจาก Sensor เพื่อตรวจจับวัตถุและส่งคำสั่งให้มอเตอร์ทำงานตามลำดับ เช่น การเริ่ม–หยุดสายพาน การนับจำนวนชิ้นงาน หรือการหยุดระบบเมื่อพบความผิดปกติ

เซนเซอร์ที่ใช้ในระบบสายพานลำเลียงมีหลายชนิดตามหน้าที่ ได้แก่ 1) Photoelectric Sensor ติดตั้งที่ต้นสายพานเพื่อตรวจจับการเข้ามาของชิ้นงาน และที่ปลายสายพานเพื่อตรวจจับชิ้นงานที่ถึงจุดหยุดหรือจุดคัดแยก 2) Inductive Proximity Sensor ติดตั้งด้านข้างสายพานใกล้แนวการเคลื่อนที่ของชิ้นงานเพื่อตรวจจับหรือคัดแยกชิ้นงานโลหะ 3) Capacitive Proximity Sensor ใช้ตรวจจับชิ้นงานอโลหะหรือระดับวัสดุในภาชนะ 4) Encoder ติดตั้งที่เพลาลูกกลิ้งหรือเพลามอเตอร์ขับสายพานเพื่อวัดความเร็วและระยะการเคลื่อนที่ และ 5) Limit Switch หรือสวิตช์ดึงหยุดฉุกเฉิน (Pull Cord Switch) ติดตั้งตามแนวสายพานเพื่อความปลอดภัย

การติดตั้งเซนเซอร์ควรคำนึงถึงระยะตรวจจับ (Sensing Distance) ขนาดและความสูงของชิ้นงาน และแสงรบกวนจากภายนอก โดยติดตั้งให้แนวลำแสงหรือหน้าเซนเซอร์ตั้งฉากกับทิศทางการเคลื่อนที่ของชิ้นงาน และยึดขาจับให้มั่นคงไม่สั่นตามการทำงานของสายพาน

### 9.1.2 บทบาทของ PLC ในการควบคุมระบบสายพานลำเลียง

นอกจากนี้ยังสามารถเชื่อมต่อกับ HMI เพื่อให้ผู้ควบคุมสามารถดูสถานะการทำงานของระบบแบบเรียลไทม์ เช่น การแสดงจำนวนชิ้นงาน สถานะมอเตอร์ หรือคำสั่งหยุดฉุกเฉิน ซึ่งช่วยเพิ่มความสะดวกและความปลอดภัยในการทำงาน

PLC ทำหน้าที่เป็นศูนย์กลางการควบคุมระบบสายพานลำเลียง โดยรับสัญญาณจากปุ่ม Start/Stop ปุ่มหยุดฉุกเฉิน และเซนเซอร์ต่าง ๆ เข้าทางอินพุต แล้วประมวลผลตามโปรแกรมเพื่อสั่งงานเอาต์พุต เช่น สั่งคอนแทกเตอร์หรือ Inverter ให้มอเตอร์ขับสายพานเริ่มทำงาน หยุด หรือปรับความเร็ว สั่งกระบอกลมคัดแยกชิ้นงาน และสั่ง Tower Lamp แสดงสถานะ นอกจากนี้ PLC ยังใช้ Counter นับจำนวนชิ้นงาน ใช้ Timer หน่วงเวลาระหว่างขั้นตอน และใช้วงจร Interlock ป้องกันการทำงานผิดลำดับ ทำให้ระบบทำงานได้อัตโนมัติ ปลอดภัย และปรับเปลี่ยนลำดับการทำงานได้ด้วยการแก้ไขโปรแกรมโดยไม่ต้องเดินสายใหม่

### 9.1.3 หลักการทำงานของ Conveyor System ตั้งแต่การตรวจจับวัตถุจนถึงการนับจำนวนชิ้นงาน

![](/images/book/image136.png)

ภาพที่ 9.1 ระบบสายพานลำเลียง

ภาพนี้แสดงถึงหลักการพื้นฐานของการใช้ PLC ควบคุมระบบสายพานลำเลียง โดยอาศัยสัญญาณจากเซนเซอร์และมอเตอร์ เพื่อสร้างกระบวนการผลิตที่ทำงานอย่างอัตโนมัติและมีความแม่นยำสูง ซึ่งเป็นแนวคิดสำคัญของระบบ Mechatronics และอุตสาหกรรมอัตโนมัติ (Industrial Automation) ในยุคปัจจุบัน

ลำดับการทำงานของระบบสายพานลำเลียงตั้งแต่การตรวจจับวัตถุจนถึงการนับจำนวนชิ้นงาน มีดังนี้ 1) ผู้ควบคุมกดปุ่ม Start ที่ตู้ควบคุมหรือบนหน้าจอ HMI แล้ว PLC สั่งมอเตอร์ขับสายพานให้ทำงาน 2) เมื่อชิ้นงานเคลื่อนผ่านเซนเซอร์ สัญญาณอินพุตเปลี่ยนจาก OFF เป็น ON 3) PLC ใช้คำสั่งตรวจจับขอบขาขึ้น (Rising Edge) ร่วมกับ Counter เพื่อนับชิ้นงานครั้งละ 1 ชิ้น แม้สัญญาณจะค้างอยู่ขณะชิ้นงานผ่าน 4) เมื่อค่านับครบตามที่กำหนด เช่น 10 ชิ้น PLC สั่งหยุดสายพาน แสดงไฟเตือน หรือส่งสัญญาณไปยังสถานีบรรจุ 5) ผู้ควบคุมกดปุ่ม Reset เพื่อล้างค่านับและเริ่มรอบใหม่ และหากกดปุ่มหยุดฉุกเฉินเมื่อใด ระบบจะหยุดทันที

## 9.2 การควบคุมระบบสายพานลำเลียงด้วย PLC และ HMI

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 9.1 เรื่องควบคุมระบบสายพานลำเลียงด้วย PLC และ HMI ใช้เวลา 3 ชั่วโมง (180 นาที) ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริงกับชุดฝึก และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อม ทดสอบปุ่มหยุดฉุกเฉิน และอ่านข้อควรระวัง (10 นาที)

ขั้นที่ 2 กำหนดตารางการใช้งานอินพุตและเอาต์พุต (I/O Assignment) และตรวจสอบการต่อสาย (20 นาที)

ขั้นที่ 3 เขียนโปรแกรม PLC ควบคุมการเริ่ม-หยุดสายพาน ตรวจจับและนับชิ้นงานด้วย Sensor (40 นาที)

ขั้นที่ 4 ออกแบบหน้าจอ HMI แสดงสถานะ จำนวนชิ้นงาน และปุ่มควบคุมระบบสายพาน (35 นาที)

ขั้นที่ 5 เขียนโปรแกรมคัดแยกหรือบรรจุชิ้นงานตามน้ำหนักที่วัดได้จาก Load Cell (45 นาที)

ขั้นที่ 6 ทดสอบการทำงานรวมของระบบ และจำลองเหตุขัดข้อง เช่น ชิ้นงานติด เพื่อตรวจสอบการหยุดอย่างปลอดภัย (20 นาที)

ขั้นที่ 7 สรุปผล ส่งแบบบันทึกผล และเก็บอุปกรณ์ (10 นาที)

### 9.2.1 งานเขียนโปรแกรม PLC ควบคุมระบบ สายพานลำเลียง

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถสังเกตการเขียนโปรแกรมPLC ควบคุมระบบสายพานลำเลียง ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 9.1 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 9.2.2 งานควบคุมระบบสายพานลำเลียงด้วย PLC และ HMI

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถเลียบแบบการควบคุมระบบสายพานลำเลียงด้วย PLC และ HMI ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 9.1 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 9.2.3 งานการบูรณาการ PLC – HMI – IoT ในโรงงานอัจฉริยะ

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถดำเนินการเชื่อมต่อ PLC – HMI – IoT เพื่อแสดงข้อมูลการทำงานของระบบได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 9.1 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

## 9.3 โครงสร้างและลำดับการทำงานของระบบบรรจุผลิตภัณฑ์อัตโนมัติ (Automatic Packing System)

### 9.3.1 โครงสร้างและลำดับการทำงานของระบบบรรจุผลิตภัณฑ์อัตโนมัติ

ระบบบรรจุผลิตภัณฑ์อัตโนมัติเป็นระบบควบคุมที่มีความซับซ้อนมากขึ้น โดยใช้ PLC ควบคุมลำดับขั้นตอนของการบรรจุ เช่น การตรวจจับภาชนะ การเปิดวาล์วจ่ายผลิตภัณฑ์ การตรวจสอบน้ำหนัก การปิดฝาหรือซีลบรรจุภัณฑ์ และการนับจำนวนบรรจุภัณฑ์ทั้งหมด

ระบบนี้มักถูกใช้งานร่วมกับอุปกรณ์เสริม เช่น Load Cell Sensor สำหรับตรวจวัดน้ำหนัก, Proximity Sensor สำหรับตรวจจับตำแหน่ง, และ Solenoid Valve สำหรับควบคุมการจ่ายผลิตภัณฑ์ ทั้งหมดจะถูกควบคุมผ่าน PLC และสามารถตรวจสอบได้จากหน้าจอ HMI ซึ่งแสดงสถานะ เช่น “กำลังบรรจุ”, “บรรจุครบ”, หรือ “หยุดชั่วคราว”

การใช้ PLC และ HMI ในระบบบรรจุภัณฑ์อัตโนมัติไม่เพียงช่วยลดความผิดพลาดจากมนุษย์ แต่ยังเพิ่มความแม่นยำ ความเร็ว และความสม่ำเสมอของกระบวนการผลิต อีกทั้งยังสามารถปรับตั้งค่าการทำงานให้เหมาะสมกับผลิตภัณฑ์แต่ละประเภทได้อย่างยืดหยุ่น

โครงสร้างของระบบบรรจุผลิตภัณฑ์อัตโนมัติประกอบด้วย สายพานป้อนภาชนะ เซนเซอร์ตรวจจับภาชนะ ชุดจ่ายผลิตภัณฑ์ (Feeder หรือ Filling Valve) ชุดชั่งน้ำหนักด้วย Load Cell ชุดปิดผนึก และสายพานส่งออก โดยมี PLC ควบคุมลำดับการทำงาน และ HMI ใช้ตั้งค่าและแสดงสถานะ ลำดับการทำงานโดยทั่วไป ได้แก่ 1) ป้อนภาชนะเข้าสู่ตำแหน่งบรรจุ 2) เซนเซอร์ตรวจพบภาชนะ PLC สั่งหยุดสายพาน 3) PLC สั่งจ่ายผลิตภัณฑ์จนน้ำหนักที่อ่านได้จาก Load Cell ถึงค่าที่ตั้งไว้ 4) ปิดผนึกภาชนะ 5) PLC สั่งสายพานเคลื่อนภาชนะไปยังจุดส่งออก เพิ่มค่านับจำนวนผลิตภัณฑ์ แล้วเริ่มรอบการทำงานใหม่

### 9.3.2 หลักการเชื่อมต่อ PLC – HMI – IoT และประโยชน์ต่อ Smart Factory

![](/images/book/image137.jpg)

ภาพที่ 9.2 ระบบบรรจุภัณฑ์อัตโนมัติในโรงงานอัจฉริยะ

ภาพนี้แสดงแผนผังการทำงานของ ระบบบรรจุภัณฑ์อัตโนมัติ (Automatic Packing System) ในแนวคิดของ โรงงานอัจฉริยะ (Smart Factory) ตามยุคอุตสาหกรรม 4.0 โดยมี PLC (Programmable Logic Controller) ทำหน้าที่เป็นศูนย์กลางในการควบคุมอุปกรณ์ทั้งหมดในกระบวนการ เช่น เซนเซอร์ตรวจจับสินค้า, ตัวจ่ายผลิตภัณฑ์, มอเตอร์ขับเคลื่อน, เครื่องซีลบรรจุภัณฑ์ และ ระบบตรวจสอบน้ำหนัก (Load Cell)

ข้อมูลจากการทำงานของระบบจะถูกส่งไปยัง HMI (Human Machine Interface) เพื่อให้ผู้ควบคุมสามารถดูสถานะของเครื่องจักรแบบเรียลไทม์ ปรับค่าการทำงาน หรือสั่งหยุดเครื่องได้สะดวก นอกจากนี้ PLC ยังเชื่อมต่อกับ IoT Gateway เพื่อส่งข้อมูลการผลิตขึ้น Cloud Server ซึ่งจะเก็บและวิเคราะห์ข้อมูลผ่าน Dashboard Online ทำให้สามารถติดตามประสิทธิภาพของเครื่องจักร, ตรวจสอบการทำงานผิดปกติ และวางแผนบำรุงรักษาเชิงป้องกัน (Predictive Maintenance) ได้อย่างแม่นยำ

โดยสรุป ภาพนี้สื่อถึงการบูรณาการของเทคโนโลยี PLC – HMI – IoT เข้าด้วยกันในระบบบรรจุภัณฑ์อัตโนมัติ เพื่อให้เกิดการทำงานที่ มีความแม่นยำ, ปลอดภัย, ตรวจสอบได้แบบเรียลไทม์ และเป็นส่วนหนึ่งของการพัฒนา โรงงานอัจฉริยะ (Smart Factory) ในยุคอุตสาหกรรม 4.0 อย่างแท้จริง

## 9.4 การควบคุมระบบบรรจุผลิตภัณฑ์อัตโนมัติด้วย PLC

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 9.2 เรื่องควบคุมระบบบรรจุผลิตภัณฑ์อัตโนมัติด้วย PLC ใช้เวลา 3 ชั่วโมง (180 นาที) ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริงกับชุดฝึก และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อม ทดสอบปุ่มหยุดฉุกเฉิน และอ่านข้อควรระวัง (10 นาที)

ขั้นที่ 2 กำหนดตาราง I/O Assignment และเขียนลำดับการทำงานของระบบบรรจุผลิตภัณฑ์ (25 นาที)

ขั้นที่ 3 เขียนโปรแกรม PLC ควบคุมลำดับการป้อนภาชนะ การบรรจุ การชั่งน้ำหนักด้วย Load Cell และการส่งออกชิ้นงาน (60 นาที)

ขั้นที่ 4 จัดทำหน้าจอ HMI แสดงน้ำหนัก จำนวนชิ้นงาน สถานะ และสัญญาณเตือน (35 นาที)

ขั้นที่ 5 ทดสอบการทำงานรวมด้วยชิ้นงานหลายน้ำหนัก และทดสอบการหยุดฉุกเฉิน (35 นาที)

ขั้นที่ 6 สรุปผล ส่งแบบบันทึกผล และเก็บอุปกรณ์ (15 นาที)

### 9.4.1 งานเขียนโปรแกรม PLC ควบคุมระบบบรรจุผลิตภัณฑ์อัตโนมัติ

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถฝึกเขียนโปรแกรม PLC ควบคุมระบบบรรจุผลิตภัณฑ์อัต โนมัติได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 9.2 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 9.4.2 งานความปลอดภัยและประสิทธิภาพของระบบ โดยรวม แล้วเสนอแนวทางปรับปรุง

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถดำเนินการตรวจสอบความปลอดภัยและประสิทธิภาพ ของระบบ โดยรวม และบันทึกแนวทางปรับปรุงได้ โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 9.2 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

## บทสรุป

การประยุกต์ใช้ PLC ร่วมกับ HMI ในงานเมคคาทรอนิกส์ เช่น ระบบสายพานลำเลียงและระบบบรรจุผลิตภัณฑ์อัตโนมัติ ต้องเริ่มจากการวิเคราะห์ลำดับการทำงาน กำหนดอินพุตและเอาต์พุต เขียนโปรแกรมควบคุม และออกแบบหน้าจอแสดงสถานะ ระบบที่ดีต้องมีมาตรการความปลอดภัย เช่น ปุ่มหยุดฉุกเฉิน การตรวจจับความผิดปกติ และการทดสอบการทำงานโดยรวมก่อนใช้งานจริง

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้โดยใช้ความรู้จากบทเรียน พร้อมยกตัวอย่างประกอบ หากสามารถอธิบายพร้อมวาดภาพวงจรหรือแผนผังการต่อสายได้จะได้รับคะแนนเพิ่ม

**1. อธิบายบทบาทของ PLC ในการควบคุมระบบสายพานลำเลียง และระบุเหตุผลว่าทำไมจึงนิยมใช้ PLC แทนการควบคุมด้วยวงจรรีเลย์แบบเดิม**

<details><summary>เฉลย</summary>

PLC ทำหน้าที่เป็นศูนย์กลางควบคุมระบบสายพานลำเลียง โดยรับสัญญาณจากปุ่มกด Start/Stop และ Sensor ต่าง ๆ แล้วสั่งงานมอเตอร์ขับสายพาน นับจำนวนชิ้นงาน และหยุดระบบอัตโนมัติเมื่อครบเงื่อนไข เหตุผลที่นิยมใช้ PLC แทนรีเลย์แบบเดิม เพราะ PLC สามารถปรับเปลี่ยนโปรแกรมได้โดยไม่ต้องเดินสายใหม่ มีความยืดหยุ่นสูง วินิจฉัยข้อผิดพลาดได้ง่าย และรองรับการเชื่อมต่อกับ HMI และ IoT ได้

</details>

**2. อธิบายหลักการทำงานของระบบสายพานลำเลียง (Conveyor System) ตั้งแต่การตรวจจับวัตถุ การนับจำนวนชิ้นงาน จนถึงการหยุดสายพานเมื่อครบจำนวนที่กำหนด**

<details><summary>เฉลย</summary>

\(1\) กดปุ่ม Start → PLC สั่งมอเตอร์สายพาน ON ผ่านเอาต์พุต Y0 (2) ชิ้นงานเคลื่อนผ่านหน้า Proximity/Photoelectric Sensor ที่ติดอยู่บนสายพาน → Sensor ส่งสัญญาณ X1 ให้ PLC (3) PLC ใช้ Counter ภายใน (C0) นับจำนวนสัญญาณ ON ของ Sensor (4) เมื่อ Counter C0 ครบค่าที่กำหนด → PLC สั่งมอเตอร์ OFF และเปิดสัญญาณไฟแจ้งเตือน "ครบจำนวน" (5) กด Reset → ล้างค่า Counter แล้วเริ่มรอบใหม่

</details>

**3. ยกตัวอย่างอุปกรณ์ Sensor ที่ใช้ในระบบสายพานลำเลียง พร้อมอธิบายหน้าที่และตำแหน่งที่เหมาะสมในการติดตั้ง**

<details><summary>เฉลย</summary>

\(1\) Proximity Sensor (Inductive) — ติดที่จุดเริ่มต้นและปลายสายพาน ทำหน้าที่ตรวจจับชิ้นงานโลหะและนับจำนวน (2) Photoelectric Sensor — ติดในจุดกลางสายพาน ตรวจจับวัตถุทุกประเภท ใช้นับและหยุดสายพานในจุดที่กำหนด (3) Rotary Encoder — ติดที่เพลามอเตอร์ วัดความเร็วและระยะทางของสายพาน (4) Emergency Stop (NC) — ติดที่ตู้ควบคุมและข้างสายพาน ใช้หยุดฉุกเฉินทันที

</details>

**4. อธิบายการทำงานของระบบสายพานที่เชื่อมต่อกับ HMI ว่ามีประโยชน์อย่างไรในการเฝ้าดูสถานะและควบคุมเครื่องจักร**

<details><summary>เฉลย</summary>

HMI ช่วยให้ผู้ควบคุมสามารถ (1) มองเห็นสถานะมอเตอร์ (ON/OFF) และจำนวนชิ้นงานแบบเรียลไทม์บนหน้าจอ (2) กดปุ่ม Start/Stop และ Reset ผ่านหน้าจอสัมผัสแทนปุ่มกดจริง (3) รับการแจ้งเตือน Alarm เมื่อเกิดความผิดปกติ เช่น Sensor เสีย หรือมอเตอร์ร้อนเกิน (4) ปรับค่าพารามิเตอร์ เช่น จำนวนชิ้นงานต่อรอบ ความเร็วสายพาน โดยไม่ต้องแก้ไขโปรแกรม PLC ใหม่

</details>

**5. เขียนแนวคิดหรือแผนผังลำดับการทำงาน (Flow Diagram) ของระบบสายพานลำเลียงอัตโนมัติที่ตรวจจับวัตถุ นับจำนวน และหยุดทำงานอัตโนมัติเมื่อครบจำนวนที่กำหนด**

<details><summary>เฉลย</summary>

\[START\] → กดปุ่ม Start (X0=ON) → Motor ON (Y0=ON), HMI แสดง "Running"

→ ชิ้นงานผ่าน Sensor (X1=ON ทุกชิ้น) → Counter C0 +1

→ \[C0 ครบจำนวน?\]

ใช่ → Motor OFF (Y0=OFF), Pilot Lamp ON (Y1=ON), HMI แสดง "Complete"

→ รอกด Reset → ล้าง C0 → \[กลับ START\]

ไม่ใช่ → \[กลับตรวจ Sensor ต่อ\]

→ กดปุ่ม Stop (X2=NC เปิด) หรือ E-Stop ทุกเมื่อ → Motor OFF ทันที

</details>

**6. อธิบายโครงสร้างและหลักการทำงานของระบบบรรจุผลิตภัณฑ์อัตโนมัติ (Automatic Packing System) โดยระบุอุปกรณ์หลัก เช่น Load Cell, Solenoid Valve, Sensor และ Motor**

<details><summary>เฉลย</summary>

ระบบประกอบด้วย (1) Proximity Sensor — ตรวจจับภาชนะที่วางตำแหน่ง (2) Solenoid Valve — รับคำสั่ง PLC เปิดจ่ายสินค้า (3) Load Cell — วัดน้ำหนักแบบอนาล็อก 4-20 mA เปรียบเทียบกับค่าที่ตั้งไว้ (4) Sealing Machine — ซีลบรรจุภัณฑ์เมื่อน้ำหนักถูกต้อง (5) Conveyor Motor — ลำเลียงภาชนะเข้า-ออกสถานี PLC ควบคุมลำดับทั้งหมดผ่าน Sequential Control และแสดงผลบน HMI

</details>

**7. อธิบายการทำงานของ PLC ในการควบคุม Sequential Control ของระบบบรรจุภัณฑ์ เช่น การตรวจจับภาชนะ การจ่ายสินค้า การชั่งน้ำหนัก และการซีลบรรจุภัณฑ์**

<details><summary>เฉลย</summary>

ขั้นที่ 1 Sensor ตรวจจับภาชนะ → X0=ON → PLC หยุดสายพาน (Y0=OFF)

ขั้นที่ 2 PLC เปิด Solenoid Valve (Y1=ON) → จ่ายสินค้าเข้าภาชนะ

ขั้นที่ 3 Load Cell ส่งค่าน้ำหนัก → PLC เปรียบเทียบ → ครบตามค่า → Y1=OFF

ขั้นที่ 4 PLC สั่ง Sealing Machine (Y2=ON) → รอ Timer T0 → Y2=OFF

ขั้นที่ 5 PLC สั่งสายพานเดิน (Y0=ON) → ภาชนะออก → C0+1 → รอรอบถัดไป

หากน้ำหนักไม่ผ่าน Y3=ON (Alarm) + HMI แจ้งเตือน → รอการยืนยัน

</details>

**8. อธิบายประโยชน์ของการเชื่อมต่อ HMI กับระบบบรรจุภัณฑ์อัตโนมัติในการตรวจสอบสถานะแบบเรียลไทม์และการปรับค่าพารามิเตอร์**

<details><summary>เฉลย</summary>

\(1\) แสดงสถานะแต่ละขั้นตอนการบรรจุแบบ Graphic เช่น "กำลังจ่ายสินค้า", "กำลังชั่งน้ำหนัก", "ซีลเสร็จ" (2) ผู้ควบคุมสามารถปรับค่าน้ำหนักเป้าหมาย เวลา Timer และจำนวนบรรจุภัณฑ์ต่อชุดได้บน HMI โดยไม่ต้องแก้โปรแกรม (3) รับสัญญาณ Alarm แบบเรียลไทม์ เช่น "น้ำหนักเกิน", "Sensor เสีย" (4) บันทึกสถิติจำนวนบรรจุภัณฑ์และ Alarm ในแต่ละกะการผลิต

</details>

**9. อธิบายการเชื่อมต่อ PLC – HMI – IoT ในระบบบรรจุภัณฑ์อัตโนมัติ ว่าช่วยยกระดับการทำงานของโรงงานให้เป็น Smart Factory ได้อย่างไร**

<details><summary>เฉลย</summary>

ระดับ Field Sensor และ Actuator ตรวจจับและขับเคลื่อนจริง

ระดับ Control PLC ประมวลผล Sequential Control

ระดับ Supervisory HMI แสดงสถานะและรับคำสั่ง

ระดับ Network IoT Gateway ส่งข้อมูลผ่าน Ethernet/Wi-Fi ขึ้น Cloud

ระดับ Cloud Dashboard วิเคราะห์ OEE, Production Count, Predictive Maintenance

ผลลัพธ์ โรงงานสามารถตรวจสอบประสิทธิภาพเครื่องจักร วางแผนบำรุงรักษา และลดเวลาหยุดการผลิตได้อย่างอัจฉริยะ

</details>

**10. เสนอแนวคิดการพัฒนาระบบเมคคาทรอนิกส์ที่ใช้ PLC และ HMI ควบคุมการทำงานอัตโนมัติ เช่น ระบบจัดเรียงสินค้า ระบบคัดแยก หรือระบบตรวจสอบคุณภาพ พร้อมอธิบายหลักการทำงาน**

<details><summary>เฉลย</summary>

ตัวอย่าง ระบบคัดแยกสินค้าอัตโนมัติ

หลักการ Photoelectric Sensor ตรวจจับสินค้าบนสายพาน → PLC ประมวลผลประเภทสินค้าจากสัญญาณ Sensor หลายจุด → สั่งงาน Pneumatic Pusher (Solenoid Valve + กระบอกลม) ดันสินค้าเข้าช่องที่กำหนด → Tower Lamp และ HMI แสดงจำนวนสินค้าแต่ละประเภทแบบเรียลไทม์ → ส่งข้อมูลขึ้น Cloud ผ่าน IoT Gateway ช่วยลดแรงงาน เพิ่มความแม่นยำ และติดตามการผลิตได้ตลอดเวลา

</details>
