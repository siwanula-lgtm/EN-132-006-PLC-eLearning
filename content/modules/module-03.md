## จุดประสงค์การสอน

- **3.1 เข้าใจส่วนประกอบและขั้นตอนการติดตั้งโปรแกรม GX Works3 ได้**
    - 3.1.1 บอกส่วนประกอบหลักของโปรแกรม GX Works3 ได้
    - 3.1.2 อธิบายขั้นตอนการติดตั้งและอัปเดตโปรแกรม GX Works3 ได้
- **3.2 เข้าใจการเชื่อมต่อ การเขียน-อ่านข้อมูล และการตรวจสอบแบบ เรียลไทม์ของ PLC ได้**
    - 3.2.1 บอกวิธีการเชื่อมต่อ PLC กับคอมพิวเตอร์ได้
    - 3.2.2 เบอกลำดับลำดับขั้นตอนการเขียนและอ่านข้อมูลจาก PLC ได้
    - 3.2.3 อธิบายหลักการจำลองการทำงานของโปรแกรมและ การตรวจสอบแบบเรียลไทม์ได้
- **3.3 ปฏิบัติการเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3 ได้ถูกต้อง**
    - 3.3.1 สังเกตการเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3 ตามขั้นตอนได้ถูกต้อง
    - 3.3.2 ดำเนินการทดสอบโปรแกรมด้วย Simulation เทียบกับ PLC จริง และบันทึกข้อแตกต่างได้ถูกต้อง

ในปัจจุบันระบบควบคุมอัตโนมัติ (Automation System) มีบทบาทสำคัญในงานอุตสาหกรรมเกือบทุกประเภท โดยเฉพาะการใช้ Programmable Logic Controller (PLC) ซึ่งเป็นสมองหลักของกระบวนการผลิตที่ช่วยควบคุมเครื่องจักร ระบบขนส่ง และกระบวนการอัตโนมัติต่าง ๆ ให้ทำงานได้อย่างถูกต้อง

ภาพนี้แสดงหน้าต่างหลักของโปรแกรม GX Works3 ซึ่งเป็นซอฟต์แวร์สำหรับการเขียนและจัดการโปรแกรมของ PLC Mitsubishi โดยมีส่วนประกอบที่สำคัญดังนี้

Menu Bar (แถบเมนูหลัก)

อยู่ด้านบนสุดของหน้าจอ ประกอบด้วยเมนูคำสั่งหลัก เช่น Project, Edit, Diagnostics, Tool, และ Help สำหรับการสร้างโปรเจกต์ใหม่ การตรวจสอบระบบ และตั้งค่าการเชื่อมต่อ

Tool Bar (แถบเครื่องมือด่วน)

แสดงเป็นไอคอนสัญลักษณ์ที่ใช้คำสั่งต่าง ๆ ได้รวดเร็ว เช่น Save, Build, Download, Simulation ช่วยให้ผู้ใช้งานทำงานได้สะดวกขึ้น

Navigation Window (หน้าต่างนำทาง)

อยู่ทางด้านซ้ายของหน้าจอ ใช้แสดงโครงสร้างโปรเจกต์ทั้งหมด เช่น โปรแกรมหลัก (Main Program), พารามิเตอร์อุปกรณ์, และโมดูลเสริมต่าง ๆ

Programming Area (พื้นที่เขียนโปรแกรม)

พื้นที่ตรงกลางของหน้าจอ ใช้สำหรับเขียนโปรแกรมในรูปแบบ Ladder Diagram (LD) หรือ Structured Text (ST) รวมถึงการแก้ไขและทดสอบคำสั่ง

Output Window (หน้าต่างผลลัพธ์)

อยู่ด้านล่างสุด ใช้แสดงข้อความจากการทำงานของโปรแกรม เช่น Error, Warning, Information เพื่อช่วยผู้ใช้งานตรวจสอบความถูกต้องของโค้ด

ภาพที่ 3.3 การเลือกซีรีส์ ประเภทและภาษาที่ใช้เขียนของ PLC ในโปรแกรม GX Works3

ภาพนี้แสดงขั้นตอนการตั้งค่าพื้นฐานหลังจากสร้างโปรเจกต์ใหม่ในโปรแกรม GX Works3 โดยผู้ใช้งานต้องเลือก

> 1\. Series รุ่นของ PLC ที่ต้องการใช้งาน เช่น FX5CPU
>
> 2\. Type ประเภทของหน่วยประมวลผล (เช่น FX5UJ, FX5UJC, FX5UJJ)
>
> 3\. Program Language ภาษาที่ใช้เขียนโปรแกรม ซึ่งในกรณีนี้เลือกเป็น Ladder Diagram (LD)

การเลือกซีรีส์และประเภทของ PLC ให้ตรงกับฮาร์ดแวร์จริงเป็นขั้นตอนสำคัญ เนื่องจากจะส่งผลต่อการตั้งค่าพอร์ตการเชื่อมต่อ พารามิเตอร์อุปกรณ์ และการสื่อสารระหว่าง PLC กับอุปกรณ์อื่น เช่น HMI หรืออินเวอร์เตอร์

ประเภทของ PLC Mitsubishi

1.  FX5CPU → PLC ตระกูล FX5 (ขนาดเล็ก–กลาง)

2.  QCPU (Q Mode) → PLC ตระกูล Q (ขนาดกลาง–ใหญ่)

3.  LCPU / LHCPU → PLC ตระกูล L (ประสิทธิภาพสูงกว่า FX)

4.  RCPU → PLC ตระกูล iQ-R (รุ่นใหม่ ประสิทธิภาพสูง)

5.  MX Controller / NCCPU → สำหรับระบบควบคุมเฉพาะทาง

ชนิดของ PLC

1.  FX5U → รุ่นมาตรฐาน (Standard Type)

2.  FX5UJ → รุ่นประหยัด (Compact Type) แต่ยังคงมีฟังก์ชันหลักครบ

3.  FX5S → รุ่นเล็กสุด (Basic Type) สำหรับงานทั่วไป ราคาถูก

ภาพที่ 3.5 การเลือกภาษาในการเขียนโปรแกรม (Program Language) ใน GX Works3

ภาพนี้แสดงขั้นตอน เริ่มต้นสร้างโปรเจกต์ใหม่ใน GX Works3 โดยผู้ใช้เลือก PLC รุ่น FX5UJ และกำลังเลือกภาษาที่จะใช้เขียนโปรแกรม เช่น Ladder Diagram (LD) ซึ่งเป็นขั้นตอนสำคัญก่อนเริ่มเขียนคำสั่งควบคุมอุปกรณ์จริง เช่น มอเตอร์ เซ็นเซอร์ หรือรีเลย์ในระบบอัตโนมัติภาษาที่ใช้ในการเขียนโปรแกรมควบคุม PLC

ตารางที่ 3.1 การเปรียบเทียบภาษาที่ใช้เขียนโปรแกรม PLC แต่ละชนิด

| ภาษา   | ชื่อเต็ม                                  | ลักษณะเด่น                              | เหมาะสำหรับ                        |
|--------|----------------------------------------|---------------------------------------|-----------------------------------|
| Ladder | Ladder Diagram                         | เป็นภาษาผังบันได มองเห็นลำดับการทำงานชัดเจน | ผู้เริ่มต้น, งานควบคุมทั่วไป              |
| ST     | Structured Text                        | เขียนแบบข้อความ (เหมือนภาษา C)           | งานตรรกะซับซ้อน, การคำนวณ           |
| SFC    | Sequential Function Chart              | แสดงลำดับขั้นตอนแบบกราฟิก                 | งานแบบลำดับการทำงาน (เช่น ขั้นตอนผลิต) |
| FBD/LD | Function Block Diagram / Logic Diagram | ใช้บล็อกฟังก์ชันเชื่อมต่อกัน                   | งานควบคุมที่ต้องใช้ฟังก์ชันหลายชุด         |

### 3.1.2 ขั้นตอนการติดตั้งและอัปเดตโปรแกรม GX Works3

การติดตั้งและอัปเดตโปรแกรม GX Works3 เป็นขั้นตอนสำคัญในการเริ่มต้นเรียนรู้ระบบ PLC ของ Mitsubishi ผู้เรียนจะสามารถอธิบายการจัดเตรียมเครื่องมือ การติดตั้งซอฟต์แวร์ และการตรวจสอบระบบก่อนเริ่มใช้งานงริง ซึ่งเป็นพื้นฐานสำคัญในการเรียนรู้หัวข้อต่อไป เช่น การเขียนโปรแกรม Ladder Diagram การจำลอง (Simulation) และการเชื่อมต่อกับอุปกรณ์ PLC เพื่อใช้งานในภาคอุตสาหกรรมได้อย่างมีประสิทธิภาพ

ขั้นตอนหลักในการติดตั้งมีดังนี้

1\. ดาวน์โหลดโปรแกรม – ผู้เรียนต้องเข้าเว็บไซต์ของ Mitsubishi Electric จากนั้นเลือกเมนู MELSOFT iQ Works → GX Works3 และดาวน์โหลดไฟล์ติดตั้งชื่อ sw1dnd-gxw3-e_117x

2\. แตกไฟล์และเริ่มติดตั้ง – หลังดาวน์โหลดแล้ว ให้ทำการแตกไฟล์และคลิกปุ่ม Next เพื่อเริ่มติดตั้ง จากนั้นกรอกข้อมูลผู้ใช้ เช่น Name, Company, และ Product ID เพื่อยืนยันการใช้งาน

3\. ตรวจสอบระบบและอัปเดตเวอร์ชัน เมื่อติดตั้งเสร็จ ให้ตรวจสอบความถูกต้องของไฟล์และอัปเดตระบบผ่าน Update Tool เพื่อให้โปรแกรมรองรับ PLC รุ่นใหม่ ๆ และแก้ไขบั๊กที่อาจเกิดขึ้นเตรียมความพร้อมก่อนใช้งานจริง หลังติดตั้งและอัปเดตเรียบร้อยแล้ว ให้เปิดโปรแกรม GX Works3 เพื่อตรวจสอบฟังก์ชันหลัก เช่น Project Tree, Parameter Setting, Ladder Editor และ Simulation Tools เพื่อให้มั่นใจว่าระบบพร้อมใช้งาน

## 3.3 งานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 3 เรื่องงานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3 ใช้เวลา 3 ชั่วโมง (180 นาที) ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริงกับชุดฝึก และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อม และเปิดโปรแกรม GX Works3 (10 นาที)

ขั้นที่ 2 สร้างโปรเจกต์ใหม่ เลือกชุดและรุ่น CPU ให้ตรงกับ PLC ของชุดฝึก แล้วบันทึกโปรเจกต์ (25 นาที)

ขั้นที่ 3 ตั้งค่า Connection Destination แบบ Ethernet และทดสอบการสื่อสารด้วย Connection Test (30 นาที)

ขั้นที่ 4 เขียนโปรแกรม Ladder อย่างง่าย LD X0 OUT Y0 แล้วทำการ Convert และตรวจสอบข้อผิดพลาด (25 นาที)

ขั้นที่ 5 Write โปรแกรมลง PLC แล้ว Read กลับมาเปรียบเทียบกับโปรแกรมในคอมพิวเตอร์ (30 นาที)

ขั้นที่ 6 สั่ง RUN และใช้โหมด Monitor ตรวจสอบสถานะ X0 และ Y0 พร้อมใช้ Watch Window (20 นาที)

ขั้นที่ 7 ทดสอบโปรแกรมด้วย Simulation โดยไม่ต่อกับ PLC แล้วเปรียบเทียบผลกับการทดสอบจริง (30 นาที)

ขั้นที่ 8 สรุปผล ส่งแบบบันทึกผล และเก็บอุปกรณ์ (10 นาที)

### 3.3.1 งานเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้ งานโปรแกรม GX Works3

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถสังเกตการเชื่อมต่อ PLC กับคอมพิวเตอร์และใช้งานโปรแกรม GX Works3 ตามขั้นตอนได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 3 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

### 3.3.2 งานผลการทดสอบด้วย Simulation กับ PLC จริง และสรุปข้อแตกต่าง

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถดำเนินการทดสอบโปรแกรมด้วย Simulation เทียบกับ PLC จริง และบันทึกข้อแตกต่างได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 3 และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

**1. จงอธิบายขั้นตอนการสร้างโปรเจกต์ใหม่ในโปรแกรม GX Works3**

เปิดโปรแกรม GX Works3 เลือกเมนู Project \> New จากนั้นเลือก Series และ Type ของ CPU ให้ตรงกับ PLC ที่ใช้งาน เช่น FX5CPU รุ่น FX5UJ เลือกภาษาที่ใช้เขียนโปรแกรมเป็น Ladder แล้วกด OK โปรแกรมจะสร้างพื้นที่เขียนโปรแกรมใหม่ให้พร้อมใช้งาน จากนั้นบันทึกโปรเจกต์ด้วยเมนู Project \> Save As

</details>

**2. จงอธิบายขั้นตอนการเชื่อมต่อ PLC กับคอมพิวเตอร์ผ่านพอร์ต Ethernet**

<details><summary>เฉลย</summary>

ต่อสาย LAN ระหว่างคอมพิวเตอร์กับพอร์ต Ethernet ของ PLC ตั้งค่า IP Address ของคอมพิวเตอร์ให้อยู่ในวงเครือข่ายเดียวกับ PLC จากนั้นในโปรแกรม GX Works3 เลือกเมนู Online \> Current Connection Destination เลือกการเชื่อมต่อแบบ Direct Coupled Setting (Ethernet) แล้วกด Connection Test หากเชื่อมต่อสำเร็จจะปรากฏข้อความยืนยันการสื่อสารกับ PLC

</details>

**3. จงเปรียบเทียบความแตกต่างระหว่างการเขียนข้อมูลลง PLC (Write) และการอ่านข้อมูลจาก PLC (Read)**

<details><summary>เฉลย</summary>

Write to PLC คือการส่งโปรแกรมและพารามิเตอร์จากคอมพิวเตอร์ลงไปเก็บไว้ในหน่วยความจำของ PLC ใช้เมื่อต้องการให้ PLC ทำงานตามโปรแกรมที่เขียนขึ้นใหม่ ส่วน Read from PLC คือการอ่านโปรแกรมและข้อมูลที่อยู่ใน PLC ขึ้นมาแสดงบนคอมพิวเตอร์ ใช้เมื่อต้องการตรวจสอบหรือสำรองโปรแกรมที่ใช้งานอยู่จริงในเครื่อง

</details>

**4. จงอธิบายประโยชน์ของการจำลองการทำงานของ PLC ด้วยโปรแกรม GX Simulator3**

<details><summary>เฉลย</summary>

GX Simulator3 ช่วยให้สามารถทดสอบการทำงานของโปรแกรมได้โดยไม่ต้องเชื่อมต่อกับ PLC จริง ทำให้ตรวจสอบความถูกต้องของลอจิกการทำงานได้ก่อนนำไปใช้งานจริง ลดความเสี่ยงต่อความเสียหายของอุปกรณ์ ประหยัดเวลาในการทดสอบ และสามารถฝึกเขียนโปรแกรมได้แม้ไม่มีชุดฝึก

</details>

**5. จงอธิบายการใช้งานโหมด Monitor ในการตรวจสอบและติดตามการทำงานของระบบ PLC แบบเรียลไทม์**

<details><summary>เฉลย</summary>

โหมด Monitor ใช้ตรวจสอบสถานะการทำงานของอุปกรณ์ภายใน PLC เช่น อินพุต (X) เอาต์พุต (Y) รีเลย์ภายใน (M) ตัวจับเวลา (T) และตัวนับ (C) แบบเรียลไทม์ โดยเลือกเมนู Online \> Monitor \> Start Monitoring โปรแกรมจะแสดงสถานะ ON/OFF และค่าปัจจุบันของอุปกรณ์บน Ladder Diagram ทำให้สามารถวิเคราะห์และแก้ไขปัญหาการทำงานของระบบได้สะดวก

</details>

**6. จงอธิบายขั้นตอนและข้อกำหนดเบื้องต้น (System Requirement) ในการติดตั้งโปรแกรม GX Works3 ลงในเครื่องคอมพิวเตอร์**

<details><summary>เฉลย</summary>

ก่อนติดตั้งต้องตรวจสอบข้อกำหนดเบื้องต้นของเครื่องคอมพิวเตอร์ เช่น ระบบปฏิบัติการที่รองรับ พื้นที่ว่างในฮาร์ดดิสก์ และหน่วยความจำ (RAM) ที่เพียงพอ จากนั้นเรียกใช้ไฟล์ติดตั้ง (Setup) ทำตามขั้นตอนที่โปรแกรมกำหนด ยอมรับเงื่อนไขการใช้งาน และรีสตาร์ทเครื่องคอมพิวเตอร์หลังติดตั้งเสร็จเพื่อให้โปรแกรมพร้อมใช้งาน

</details>

**7. จงอธิบายส่วนประกอบหลักของหน้าต่างโปรแกรม GX Works3 เช่น Navigation Window, Ladder Editor และ Output Window มาอย่างน้อย 3 ส่วน พร้อมหน้าที่ของแต่ละส่วน**

<details><summary>เฉลย</summary>

ส่วนประกอบหลักของ GX Works3 ได้แก่ (1) Navigation Window แสดงโครงสร้างโปรเจกต์ พารามิเตอร์ และรายการโปรแกรมทั้งหมด (2) Ladder Editor พื้นที่สำหรับเขียนและแก้ไข Ladder Diagram (3) Output Window แสดงผลลัพธ์การแปลงโปรแกรม (Compile) และข้อผิดพลาดที่ตรวจพบ และ (4) Toolbar/Menu Bar รวมคำสั่งที่ใช้งานบ่อย เช่น การเชื่อมต่อ การ Write/Read และการจำลองการทำงาน

</details>

**8. จงอธิบายขั้นตอนการแปลงโปรแกรม (Convert/Compile) ก่อนทำการ Write ลง PLC และเหตุใดจึงต้องทำขั้นตอนนี้ทุกครั้งก่อนดาวน์โหลดโปรแกรม**

<details><summary>เฉลย</summary>

การ Convert/Compile คือการตรวจสอบความถูกต้องของ Ladder Diagram และแปลงเป็นรหัสคำสั่งที่ PLC เข้าใจก่อนดาวน์โหลด จำเป็นต้องทำทุกครั้งหลังแก้ไขโปรแกรม เพราะหากไม่แปลงโปรแกรมก่อน ระบบจะไม่อนุญาตให้ Write ลง PLC และหากมีข้อผิดพลาดในโปรแกรม (เช่น การต่อวงจรไม่สมบูรณ์) โปรแกรมจะแจ้งเตือนใน Output Window ให้แก้ไขก่อน

</details>

**9. จงเปรียบเทียบความแตกต่างระหว่างการแก้ไขโปรแกรมแบบ Offline และแบบ Online ใน GX Works3 พร้อมข้อดีข้อเสียของแต่ละแบบ**

<details><summary>เฉลย</summary>

การแก้ไขแบบ Offline คือการเขียน/แก้ไขโปรแกรมโดยไม่ได้เชื่อมต่อกับ PLC จริง ข้อดีคือปลอดภัย ไม่กระทบการทำงานของเครื่องจักรที่กำลังทำงานอยู่ แต่ต้อง Write ใหม่ทั้งหมดจึงจะเห็นผล ส่วนการแก้ไขแบบ Online คือการแก้ไขขณะเชื่อมต่อกับ PLC โดยตรง ข้อดีคือเห็นผลการทำงานทันที เหมาะกับการปรับจูนระบบ แต่มีความเสี่ยงหากแก้ไขผิดพลาดขณะเครื่องจักรกำลังทำงาน

</details>

**10. จงอธิบายวิธีการสำรองข้อมูลโปรแกรมและพารามิเตอร์ (Backup) และวิธีการนำกลับมาใช้ใหม่ (Restore) ในโปรแกรม GX Works3**

<details><summary>เฉลย</summary>

การ Backup ทำได้โดยเลือกเมนู Project แล้วบันทึกไฟล์โปรเจกต์ทั้งหมด (โปรแกรม พารามิเตอร์ และการตั้งค่า) เก็บไว้ในสื่อบันทึกข้อมูล ส่วนการ Restore คือการเปิดไฟล์โปรเจกต์ที่สำรองไว้กลับมาใช้งาน หรืออ่านข้อมูลโปรแกรมและพารามิเตอร์ที่เก็บอยู่ใน PLC กลับมายังคอมพิวเตอร์ (Read from PLC) เพื่อป้องกันการสูญหายของข้อมูลกรณีเครื่องคอมพิวเตอร์เสียหายหรือ PLC ถูกเปลี่ยนใหม่

</details>
